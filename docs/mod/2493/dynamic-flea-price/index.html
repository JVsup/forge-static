Dynamic Flea Price

Dynamically changes the price of items on the flea market depending on how often players buy/sell the item

How it work?

Every time a player buys or sells an item on the flea market, the mod counts the number of those items and increases or decreases the price multiplier for those items and their categories.

The multiplier values ​​are configured through the configuration file.

When does the price up/down?

The new price for items will appear when new offers are generated on the flea market.

When does the multiplier change?

The multiplier of items reduced when players buy items from the flea market if the item/category is configured

OR

The multiplier is reduced every specified period of time and by a specific amount. The “time” values ​​and the “reduction percentage” are configurable.

How is the price calculated?

If multiplier values ​​are configured for an item, then the multiplier will be applied to the default flea price. The price of an item can increase indefinitely. The price of an item cannot be lower than the minimum price for which traders are willing to buy it.

Install
  1. unzip archive content to SPT root folder
  2. copy and rename DynamicFleaPriceConfig_example.json5 -> to DynamicFleaPriceConfig.json5
  3. change the settings in the configuration file, as the DEFAULT settings do not change anything.
Configuration

An example of the settings and their detailed description is in the file DynamicFleaPriceConfig_example.json5

The main improvement is that the data file will now store the multiplier (previously, it only stored the purchase/sales counter).

What does this mean? It allows for a smooth decrease/regeneration of the multiplier with each update. It also allows for a clearer view of the item/category multiplier.

I apologize for changing the parameters again. I hope this is the last time :) I also tried to create a soft migration to reduce file manipulation, but the more I wrote the migration code, the more difficult it became to avoid errors.
