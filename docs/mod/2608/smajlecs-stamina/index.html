Smajlec's Stamina

When you cannot sprint anymore, jog!

Smajlec

Description Versions 4

This mod allows you to run indefinitely. When stamina is depleted, your character slows down to a jogging pace, similar to how it works in Squad.

It also lowers the stamina requirement for jumping and vaulting, allowing you to get over obstacles with just a pixel of stamina. You will no longer be staring at a road barrier for 20 seconds waiting for stamina to regenerate.
