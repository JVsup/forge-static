No Aim Overswing

  • Configure the percentage of AimSwing on start-aiming, by 0~100% in F12 menu.
    Default is 10%, which already makes the swing unable to notice, whatever heavy or low ergo weapons.
  • Do not affect random shaking, only the starting aimsway.

How to Install

  • Download the zip package, open it and drag the ‘‘BepInEx’’ folder to merge into your main folder of EFT. The final DLL should locate at “Your SPT path\BepInEx\plugins\xxx.dll”
  • To uninstall, just delete the DLL file in that path.

Compatibility

This mod only affects your client.
Conflict with Custom Stances, and maybe more. Test on your own.
