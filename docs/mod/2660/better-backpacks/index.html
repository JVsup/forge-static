Better Backpacks

Huge thank you to Josh Mate for the original Better Backpacks. This mod would not be possible without their work. Send them your love! ♥

Features

Make backpacks bigger while staying in-line with vanilla gameplay balance.

  • Increases backpack grid sizes across all tiers, with buffs scaled by rarity/availability.
  • Boss backpack have been made significantly larger to fit their status.
  • The backpack grid system has been modified to allow for multi-grid backpacks to be resized properly.
  • Configurable backpack sizes with web-based user interface.

The backpack sizes have been altered from the original Better Backpacks mod due to the addition of all of the extra bags over time.

Install / Configure

Vanilla SPT:

  1. Decompress the contents of the download into your root SPT directory.
  2. Run the server.
  3. Configure the mod using the web UI here:
    https://127.0.0.1:6969/better-backpacks

Fika

If you are using Fika, this mod must be installed into the Fika server, and each client that connects to the server. The Fika documentation has a page about setting required mods on a server. The line you’re probably looking to modify in your fika.jsonc is this:

    "mods": {
      "required": ["com.refringe.betterbackpacks"],
      "optional": []
    },

If you are using the Fika headless client, this mod needs to be installed there as well.

Uninstall

It’s extreamly important to remove all backpacks from your player and stash before removing this mod. Failing to do this may result in your profile becoming corrupted.

Remove the following:

  • BepInEx/plugins/BetterBackpacks.dll
  • SPT/user/mods/BetterBackpacks
