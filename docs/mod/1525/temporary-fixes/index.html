Description Versions 1

THIS MOD IS ONLY COMPATIBLE WITH 4.0.x

This mod currently does or has contained fixes authored by Kaeno, Chomp, dirtbikercj & DrakiaXYZ

This mod is NOT their responsibility but they do deserve credit for their work.

Do not report problems to them with this mod.

  • Fix Cultist Circle Direct Rewards breaking after doing a single non-repeatable direct reward (acidphantasm)
  • Fix door on Customs not being unlockable by Military checkpoint key (dirtbikercj)

This will be obsolete if another version is released after 4.0.13.

INSTALLATION
  1. Download Temporary Fixes
  2. Open the downloaded zip file
  3. Select the BepInEx folder in the zip file
  4. Drag the user folder from zip file into your SPT folder

Demonstration Video (yoink):

UNINSTALLATION
  1. Delete /ROOTSPT/Bepinex/plugins/acidphantasm-temporaryfixes
  2. Done
