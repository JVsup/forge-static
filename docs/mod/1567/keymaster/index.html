Keymaster - V0.6.4 (BETA / WIP)

Please note, this is a very early stage, work in progress trader, expect bugs and weird behaviour.

I have done my best to make sure this is a stable build, however, it has not been tested to the absolute limit.

This mod was a personal project, but I thought it would be fun to share with you all for feedback.

The current goal is one update a week until all core features are added.

Features

  • All keys for Labs, Customs, Factory, Ground Zero, Interchange, Lighthouse and Woods.
  • Key chain, key tool and keycard holder are on sale.
  • Loyalty Level Scheme.

Planned

  • Remaining map keys to be added: Reserve, Shoreline, Streets of THE CITY.
  • All in-game keys added (V1.0.0).
  • Fully integrated quest-line. (Post V1.0.0).
  • Perfect balance for a normal playthrough.
