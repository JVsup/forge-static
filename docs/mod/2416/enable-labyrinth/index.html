Mod

Enable Labyrinth

Enables Labyrinth for PMCs and Scavs. Adds a custom exfil point for Scavs at the same location as the non-secret exfil for PMCs. Requirements for entry are removed.

Description Versions 3

Mod Features

  • Enables Labyrinth
  • Removed Labyrinth entry requirements
  • Adds Scav Exfiltration Point to Labyrinth (available immediately)
  • Adds Scav Raid Reductions similar to other maps (Based on Factory Raid Adjustments for Scav Late Spawns)
  • Is compatible with Lacyway’s PVE Tweaks
  • Configuration options available for adjusting PMC Extract on Labyrinth
  • Configuration option to force the secret exfil key to spawn on Shadow of Tagilla
INSTALLATION
  1. Download Enable Labyrinth
  2. Open the downloaded zip file in 7-zip
  3. Select the SPT & BepInEx folders in the zip file in 7-zip
  4. Drag the SPT & BepInEx folders from 7-zip into your SPT folder

Demonstration Video (yoink):

UNINSTALLATION
  1. Delete /ROOTSPT/Bepinex/plugins/acidphantasm-enablelabyrinth
  2. Delete /ROOTSPT/SPT/user/mods/acidphantasm-enablelabyrinth
  3. Done
CONFIG

Configuration

To edit the configuration run your server after installing and go to:

  • https://127.0.0.1:6969/enablelabyrinth/

All configs can be updated and edited while the server is running.

Some settings require a client restart. They are marked as such

If you are using Fika then put the appropriate IP and port instead.
