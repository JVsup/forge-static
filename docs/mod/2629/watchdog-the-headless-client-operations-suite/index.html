WATCHDOG v2.1.2 – SPT/FIKA Operations Suite

WATCHDOG is a lightweight, set-and-forget utility built to manage and stabilize an SPTarkov + Project FIKA server environment.

It monitors both the SPT Server executable and the FIKA Headless Client, fully automating startup, shutdown, crash recovery, and scheduled restarts according to your settings.

This tool is designed specifically for 24/7 dedicated servers running on a separate machine (second PC, mini-PC, old laptop, etc.).
It is not intended for local single-PC setups, if you run everything on your main gaming PC, this program is overkill.

Installation

  1. Download the release from this page.
  2. Extract the files anywhere on your dedicated server machine.
  3. Run WATCHDOG.exe.

No files need to be placed in your game folder.
Windows only some features will not work on other operating systems.

Quick Setup

  1. Open WATCHDOG and go to the Settings tab (left sidebar).
  2. Set your Server Executable and HeadlessManager Executable paths.
  3. Configure the runtime settings:
    • Headless Start Delay (seconds) — Recommended: 30–60 seconds (gives the server time to fully load, heavier mod load = more time needed).
    • Scheduled Restart Interval (hours) — Default 24. Heavily modded servers are recommended every 4–12 hours for stability and memory cleanup.
    • Monitor Check Interval (seconds) — How often the program checks process health (5–30 seconds recommended).
  4. Enable any options you want (auto-restart on crash, minimize to tray, start with Windows, Discord notifications, etc.).
  5. Return to the Dashboard and click Save Config.

Main Features

Dashboard
Core control panel showing live status cards, recent activity log, quick controls, and update checker.

Additions Tab
Simple tracker for mods, version updates, config changes, etc. Useful when installing multiple mods at once.

Issue Tracker
Designed for servers where friends or clients have remote access. They can RDP in and log issues directly; you can review and fix them later.

Appearance Dropdown Choose an App Color Scheme that matches your liking if the Default Scheme isn’t your Speed!

Discord Webhook Integration
Receive real-time notifications in your Discord server:

  • Monitor start/stop
  • Crash + auto-restart
  • Scheduled restarts
  • Next restart time

Perfect for keeping your players informed without constant messages.

Status Cards

  • Server, Headless, and Monitor status (green = running, red = stopped)
  • Next Scheduled Restart time

Set & Forget

Once configured:

  • Click Start Monitor on the Dashboard.
  • The server and headless client launch automatically.
  • WATCHDOG keeps everything alive 24/7, auto-restarts on crashes, and performs scheduled restarts.
  • If tray mode is enabled, it minimizes to the system tray. Right-click → Show to restore it.

Important: Always use the Stop Monitor button to shut everything down cleanly. Manually closing processes will cause WATCHDOG to relaunch them.

Discord Webhook Setup (Recommended)

  1. In your Discord server, create a text channel.
  2. Right-click the channel → Edit Channel → Integrations → Webhooks → New Webhook.
  3. Copy the Webhook URL.
  4. In WATCHDOG Settings, enable Discord notifications and paste the URL.
  5. Restart the Monitor, messages will start appearing.

⚠ Never share your webhook URL publicly.

Notes & Clarifications

  • This program shines when the server machine is not directly accessible (no easy monitor/keyboard & mouse switching).
  • If your dedicated machine is always right next to you & accessible, it’s still nice QoL, but the real value is for true remote 24/7 setups.
  • VirusTotal & Windows Defender flags: Some vendors & Windows Clients flag the .exe due to process monitoring and auto-restart behavior. These are false positives. The full source code is public.

Support

I’m relatively new to coding, so bugs can happen.
If you run into issues, Join the Discord & submit a report with:

  • A clear description of the problem
  • Your watchdog.log file (located in `%APPDATA%\WATCHDOG, but just click “Open Log Folder in the WATCHDOG Dashboard!)

Constructive reports only, please don’t spam. This started as a private tool for me and my friends. I released it publicly so others running dedicated SPT/FIKA servers can benefit too.
