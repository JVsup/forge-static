Description Versions 1

SPT-VR-ProVolver adds haptic feedback support for the ProVolver force-feedback gunstock in SPT-VR.

The mod detects weapon fire events in-game and translates them into physical recoil effects on ProVolver hardware. Recoil intensity is based on the weapon’s in-game characteristics. Different weapon classes feel distinct, and kick strength scales with the weapon’s recoil settings.
