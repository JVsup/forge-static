AllTheLoot Redux – SPT 3.11 Original by: BlackMamba / lElwoodBluesl & jewels Redux for 3.11 by: h3ticnade This is an updated redux of the legendary AllTheLoot mod, originally created by BlackMamba (lElwoodBluesl) and further refined by jewels. Fully compatible with SPT 3.11, this version brings the madness and variety of loot spawns back to life for the current patch.

Install Instructions

To install the mod simply download the file, extract, open it, drag and drop the “user” file into your spt directory

🔧 Features:

  • Loot pool overhaul: nearly every item in the game has a chance to spawn in the world
  • Overhauled spawn categories and probabilities
  • Balanced chaos — loot everywhere, but not too much
  • Freshly updated for SPT 3.11

📦 Credits:

  • BlackMamba / lElwoodBluesl – Creator of the original AllTheLoot mod
  • jewels – Community contributor and balance tuning
  • h3ticnade – Redux and patching for 3.11 compatibility
