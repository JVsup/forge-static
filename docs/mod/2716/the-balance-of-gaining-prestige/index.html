Prestige Conditions Override

A server mod for SPT 4.0 that brings prestige requirements closer to the original Escape from Tarkov, but without story quests that are not available in SPT.

UPD 03.06

Creator of the Content Backport mod - Prestige Updated the requirements for prestige according to the same principle as in the standards settings of this mod, now this mod can only be used to create your own balance by changing the file db.json in the mods folder

What this mod does

  • Configures prestige requirements through JSON config:
    • player level
    • rubles amount
    • skill levels
    • hideout area levels
  • Removes selected quests from prestige requirements (blacklist).
  • Overrides prestige quest start conditions (level and, if needed, prestige level).

Why

In vanilla SPT, some prestige requirements rely on quests that are missing or do not fit backport-based setups.
This mod makes progression more consistent and closer to live Tarkov, while keeping configuration flexible for your own balance.

Dependencies

These mods are required to run, it is not known whether they will work on higher versions, but there should be no problems.
