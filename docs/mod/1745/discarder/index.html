Description

Requires UI Fixes! You must have UI Fixes installed for this mod to do anything.

Adds the ability to discard multiple items at once, in and out of raid, when multi-selecting items with UI Fixes. You must have UI Fixes installed and the multi-select feature enabled (which it is by default)

This is a separate mod from UI Fixes because:

1. I wanted a proof of concept for the mulit-select interop

2. Force you to opt-in to a feature that could delete half your stash if you use it that way.

No configuration required. You will still get a single confirmation dialog when discarding items out of raid.

If you install this mod and use it to delete items, then complain that it deleted items, you have no one to blame but yourself.

Installation

Like almost every mod here, extract the zip archive into your SPT directory.

Example (thanks DrakiaXYZ for the gif)

Uninstallation

To uninstall, simply delete Tyfon.Discarder.dll from <your SPT folder>/BepInEx/plugins
