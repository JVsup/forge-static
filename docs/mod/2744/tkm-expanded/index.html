TKM Expanded

Adds expanded .366 TKM ammunition variants for the VPO-215 Gornostay rifle only.

Ammo

  • .366 TKM Hunter AP
  • .366 TKM Hunter Magnum
  • .366 TKM Match Grade

Availability

  • Hunter AP | Jaeger LVL 4 | 1,400 ₽ | Workbench Level 3 (4h)
  • Hunter Magnum | Jaeger LVL 3 | 1,000 ₽ | Workbench Level 2 (3h)
  • Match Grade | Mechanic LVL 2 | 1,250 ₽ | Workbench Level 3 (5h)

All crafts produce 100 rounds.

Installation

  1. Drag the SPT and BepInEx folders into the main SPT install directory.

Configuration

Edit user/mods/Serenity-TKMExpanded/config/config.json to:

  • Enable or disable the mod entirely
  • Enable or disable individual ammo types
  • Adjust ammo stats (damage, penetration, etc.)
  • Adjust trader price, stock count, and loyalty level per ammo
  • Adjust crafting requirements, time, and output count per ammo

Requirements

  • SPT 4.0.13
