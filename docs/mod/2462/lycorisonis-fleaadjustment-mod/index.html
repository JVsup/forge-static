FleaAdjustment - Single Player Tarkov Flea Market Adjuster

Take full control of your Flea economy with somewhat easy to use flea market price adjustments. Great tool to let you modify what you want for your flea to do for the most part.

What the hell does this mod do?

This mod allows you to set a multiplier on the flea which just will in theory let you pick the prices of any item to be cheaper or more expensive. I think you can even change modded item prices if you find their MongoID.

Features

Three Configurations

  1. Simple Multiplier

    • Applies a standard multiplier to every item on the flea.
    • Example: 1.5x (50% more expensive), 0.5x (50% cheaper), 2.0x (let it ride let it ride (Twice as expensive))

  2. Range Based Pricing

    • Define price tiers with different multipliers
    • Example: Make items under 10k cheaper (0.8x) but items over 200k more expensive (2.0x)
    • Great tool to let you modify a range of items more easily by setting different multipliers for different price tiers.

  3. Specific Item Overrides

    • Target individual items by their template ID
    • This will always apply regardless of if Simple Multiplier is used or Range Based Pricing is used.
    • Have a specific item or more you want to be cheaper or hella expensive? Use this function for that!

  4. BlacklistAdditions

    • Target individual items to add to the blacklist of the flea through their template ID
    • Target whole categories to add to the blacklist of the flea through the parent of say an ammo.

Semi Failsafes

  • Minimum price (default: 1) - I set this so shit don’t break in theory. Probably redundant though lmao
  • Maximum price cap (default: 500 million) - I set it to this cause in testing this was the most stable flea lets items be in price? Most of you probably won’t make things so expensive though.

Easy Configuration

  • Config file is included with simple multiplier set to 50% for half cheaper flea by default with some example items in there like pack of sugar, ghzel body armor and Surv12 kit at different multipliers so you can easily figure out how to add more.
  • Changes require server restart obviously

Perfect For

  • Hardcore players who want every rouble to matter modifying it to be as hard as possible.
  • Casual players - Those who just want a cheaper flea. I already set it to 50% by default so there is minimum need to change things.
  • Flea Connoisseurs - Setting up your dedicated flea experience the way you want
  • Fika Hosts - Great for fika users who want to control the flea for everybody that plays with them and keep it balanced to how they like it.

Installation

  1. Download the latest release
  2. Extract the FleaAdjustment Folder and slap the contents inside to your SPT installation Folder.
  3. Edit FleaAdjustment/Config/FleaAdjustmentConfig.json to your liking
  4. Start your server and enjoy your flea experience your way.
