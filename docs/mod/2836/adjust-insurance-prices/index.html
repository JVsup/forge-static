Adjust Insurance Prices

Easily adjust insurance prices globally, or by item category.

Description Versions 2

Ever feel like insurance cost is insignificant, or cheese deaths with Instant Insurance (like me) so you get everything back instantly, but want there to be some penalty for dying? This mod lets you adjust how much traders charge to insure your items globally, or by item category.

What you can configure in config.jsonc

Set a global multiplier for all items, and optionally override it for any of these categories:

  • Weapons
  • Weapon attachments
  • Night vision / thermal headwear
  • Body armor (vests)
  • Armor plates
  • Rigs (armored and unarmored)
  • Backpacks
  • Helmets & hats
  • Helmet attachments
  • Face masks & covers
  • Headsets
  • Eyewear

Any category you don’t override uses the global multiplier, so you only need to configure what you care about. You can even make insurance cheaper if you’re really down bad. Accepted values range from 0.1× to 25×.

Why so many categories?

Tarkov groups a lot of gear under a few broad parent types, so a single “armor” setting would group helmets, plates, eyewear and face covers all together. I also noticed some items are deceptive, such as night vision counting as a weapon mod.

Installation (server)

  • Extract the contents of the .zip into your SPT directory so it merges into SPT/user/mods/.

Important

The config.jsonc from version 1.0.0 is not compatible with this version. You will have to re-input your custom values into the new config file supplied with this release.

Changes

  • Added new insurance price override categories for armored and unarmored versions of rigs, face covers and headwear (helmets/hats). Previously, all armored and unarmored items of these types were grouped together.

  • Added config file versioning, so the use of old/unsupported config files with newer mod versions will warn the user at server start.
