Quest Experience Multiplier

Multiplies the experience amount given by quest by a factor.

This mod displayed a profile-binding notice on Forge.
Description Versions 2

The multiplier is set in the config.json. The multiplier needs to be greater than 0 and less or equal than 10. The upper limit of 10 can be ignore by setting the config “IgnoreUpperLimit” to true. Doing so and setting the multiplier too high can potentially break the mod.
