This is the first addition to my soon to release RCTA (Random Clothing to Adorn) series. This is also my first mod for Tarkov so WORK WITH ME HERE. The reason it says Alpha/Early Version everywhere is because I’m in the middle of adding LOTS of different skins and included the first version of the model I ported for feedback on which is preferred. Essentially, this mod will either be deleted at a later date or heavily updated. I’m uploading it now before I get burned out and just stop making Tarkov mods. Please give feedback in the comments on if you prefer the “C6” , or “Synaptic Rig” model.

RCTA - Synaptic Rig [CODIW]

Mod Description

  • Synaptic Rig T1 Outfit - The Synaptic Rig is ported from Call of Duty : Infinite Warfare’s multiplayer. I tried my absolute best to get the model as close as I could to match the EFT body while keeping the original models weights, style, look, and it took a VERY long time doing it.
  • C6 Rig Outfit - The second try I gave making a clothing mod for Tarkov, took me 2 hours and threw it in-game and it actually looks REALLY good but why include this if this isn’t the cleaner version? For feedback! Please let me know if you prefer the C6 version more then the Synaptic Rig T1 version. Yes they are the same model but shaped very different.
