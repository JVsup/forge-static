RaidKits — Standard-Tab Loadouts Worth Buying

Tired of digging through the flea every single wipe just to throw a half-decent kit together? Tired of dying, hitting the menu, and burning ten minutes rebuilding your loadout instead of getting back in the action? The stock starter kits on your Standard tab look convenient — one click, off the traders, done — but they ship with filler ammo that bounces off anything wearing armour, so you might as well be throwing rocks.

RaidKits fixes that. It turns those one-click loadouts into kits you’ll actually want to run — gear up, hit Deploy, and get back in the fight in seconds. Thirty-two of them, from dirt-cheap early-wipe starters to fully kitted meta builds, and every one is still buyable straight from the menu.

Why you want it

  • Get back in raid faster. No more flea-market archaeology between runs. Pick a kit, buy it, deploy. Your loadout is ready before your adrenaline wears off.
  • Kits that actually fight back. The stock kits’ biggest weakness is ammo — it’s where most of a budget loadout’s killing power lives. RaidKits reloads every kit with a proper penetrator for its calibre, so cheap doesn’t mean helpless.
  • Something for every wallet. Broke on day one? Grab a budget kit. Flush with roubles and out for blood? There’s a kitted meta loadout waiting. Thirty-two options, no fuss.
  • Still one-click cheap. Nothing exotic gets bolted on. Buying a kit sources each piece from the traders, and from the flea for anything traders don’t carry (flea unlocks at PMC level 15). The budget kits run on pure trader gear; the meta kits pull their better ammo and armour from the flea.

What you get

Open the Standard kits tab and everything’s been reworked.

  • Twelve vanilla kits, rebuilt. Same weapons, same gear, same trader-friendly price — rebranded and reloaded with the best budget round their calibre offers. Flechette in the shotguns, PBM in the Makarovs, BP in the 5.45 and 7.62x39 rifles. The difference between a kit you bin on sight and one you happily run early wipe.
  • Twelve meta kits, added. Fully built rifles with optics, class 5 body armour and a helmet, loaded with top-tier rounds — for when you want to kit up properly in a single click.
  • Eight competitive-budget kits, added. Cheaper weapons paired with strong ammo and lighter class 4 armour — affordable loadouts that still hold their own when it counts.

The line-up

Reworked vanilla kits — Poacher, Sentry, Hustler, Breacher, Partizan, Deadeye, Maverick, Stalker, Recon, Operator, Ranger, Bruiser.

Meta kits — Spartan (M4A1), Crusader (HK 416), Vanguard (AK-74N), Warlord (AK-103), Sovereign (AK-12), Reaper (RD-704), Phantom (SR-25), Specter (RSASS), Titan (SCAR-H), Wraith (MCX .300), Shadow (VSS), Overwatch (SVDS).

Competitive-budget kits — Minuteman (ADAR), Comrade (SKS), Loyalist (AKM), Conscript (AKS-74), Enforcer (MP-153), Outlaw (Saiga-9), Drifter (VPO-209), Reverend (Mosin).

Requirements

  • SPT 4.0.x — server mod, no client plugin, no BepInEx.

Installation

  1. Download the latest release.
  2. Extract the RaidKits folder into <SPT>\user\mods\.
  3. Restart the server — RaidKits loaded shows in the console once the kits are in place.
  4. If the game was already running, restart the client so it loads the new kit list.

Configuration

config.json in the mod folder:

  • Enabled — master switch. false leaves the standard kits as they ship.
  • RenameKits — toggle the RaidKit names on the twelve vanilla kits.
  • UpgradeAmmo — toggle the budget-ammo swap on the twelve vanilla kits.
  • AddExtraKits — toggle the twenty new kits

RaidKits

Reworks the default loadouts on the character screen’s Standard tab and adds a stack of new ones, so the kits you can buy in one click are actually worth running.

The stock starter kits pull cheap gear off the traders, which is why they’re easy to buy — but they ship with filler ammo that bounces off anything with armour. RaidKits keeps the trader-friendly idea and builds on it: the twelve vanilla kits get rebranded and rebuilt around the best budget round their weapon can chamber, and another twenty kits are added on top — twelve kitted meta loadouts and eight cheaper competitive ones.

It’s a server mod — a single DLL plus a data file, no client plugin and no profile edits. It rewrites the default equipment presets in memory when the server starts.

What you get

Twelve reworked kits — same gear, same price, better ammo. Each one is renamed and reloaded with a trader-grade penetrator in its own calibre (buckshot becomes flechette, 9x18 P becomes PBM, 5.45 SP becomes BP, and so on).

Twelve meta kits — fully built weapons with optics, class 5 body armour and a helmet, loaded with top-tier ammo: M4A1, HK 416, AK-74N, AK-103, AK-12, RD-704, SR-25, RSASS, SCAR-H, MCX, VSS and SVDS.

Eight competitive-budget kits — cheaper weapons with strong ammo and lighter class 4 armour: ADAR, SKS, AKM, AKS-74, MP-153, Saiga-9, VPO-209 and a scoped Mosin.

Every kit is still buyable. When you buy one the game sources each piece from the traders and, for anything traders don’t stock, the flea market (flea needs to be unlocked at PMC level 15). The reworked and budget kits lean on trader gear; the meta kits will pull their better ammo and armour from the flea.

Install

  1. Drop the RaidKits folder into <SPT>\user\mods\.
  2. Restart the server. The console shows RaidKits loaded with a count of what changed.
  3. If the game was already open, restart the client so it picks up the new kit list.

Requires SPT 4.0.x.

Config

config.json:

Key Default What it does
Enabled true Master switch. false leaves the standard kits alone.
RenameKits true Apply the RaidKit names to the twelve vanilla kits.
UpgradeAmmo true Swap the vanilla kits’ loaded ammo for the budget round.
AddExtraKits true Add the twenty new kits.
