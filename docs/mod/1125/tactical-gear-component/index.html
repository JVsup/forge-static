Overview

THIS MOD IS NOT MAINTAINED BY ME ANYMORE! I will not continue making item mods. Kobe Thuy (@kobethuy) is now keeping Painter and TGC alive.

Tactical Gear Component (TGC) is a big mod for unique custom gear, attachments, and more. 100+ new items were added through many hours inside Blender, Substance Painter, and Unity.

This is a preview of the items that will be added for an even bigger mod that will be released in the future, Welcome to Tarkov (WTT). Check the item list in tab menu above to see every attachment available.

How you install this mod:

Download Painter

Drag the folder in the zip file into your SPT directory

Download this mod

Drag the folder in the zip file into your SPT directory

You did it!

If you use custom load order, you have to make sure Painter is loading before my other mods.

FAQ

Q: Can I rename the folders of your mods?

A: No, you will get errors and you should only do it if you know what you’re doing.

Q: Why do I get assort error?

A: You didn’t load Painter before my mods that require him / you didn’t follow the install instructions / in VERY rare occasions mods can conflict with each other.

If you use custom load order: If a mod maker names his folder as I do with Painter with “a” before the mod name, you should not load that mod last in the order stack. Try to respect the mod maker’s decisions to load mods first or last. “A” means load first, “Z” means load last. SAIN has z in the beginning of the folder name because the mod author wants it to load last. Q: Are these items compatible with Realism mod?

A: Yes with realism patches made by the community.

Q: I get server errors?

A: You edited the load order and you didn’t load Painter before Tactical Gear Component, or you installed TGC incorrectly.

Q: I get doge cubes instead of your items?

A: You didn’t download Painter. You didn’t load Painter before my mods that require him (Keeping the naming structure of my mod folders to default should be enough). You run a dinosaur version of SPT. There could be a mod conflict. Remove mods one by one to figure out which ones are conflicting with each other.

Q: Armored rigs and other items have the wrong weight in the inspect screen when browsing Painter’s barters?

A: It’s an SPT/EFT bug. If an item weighs above 15kg, then it’s probably the bug doing it. Once you buy the item, the correct weight will be shown.

Q: Should I edit load order to get this mod to work?

A: No, only if you have problems. By default the SPT server reads mod folders inside user/mods from A-Z. This is why some modders name their mod folder aaaMod or aMod. Most modders know about this. So editing load order by yourself can create problems. But sometimes it is required if mods start conflicting with each other.

Q: I run Fika or similar mod, and now I get errors in your mods?

A: My mods are made for SPT. I will ignore any errors posted relating to Fika.

Before posting your error code IN SUPPORT THREAD, read the overview and FAQ carefully. Thank you!
