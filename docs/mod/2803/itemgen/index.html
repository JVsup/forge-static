ItemGen - Custom Item Framework

ItemGen is a server-side framework for SPTarkov that lets anyone create custom items - quest items, keys, containers, and stims - using simple JSON packs, no programming required. Custom 3D models and use animations are supported through the included client bundle injector.

What It Does

  • Loads item packs from user/mods/ItemGen/items/
  • Clones existing item templates and overrides names, descriptions, stats, prices, and stack sizes
  • Registers custom items with the item database, handbook, and flea market
  • Supports Quest Items, Keys, Containers, and Stims with category-specific behavior
  • Adds custom items to vanilla traders with configurable prices, loyalty levels, and stock
  • Handles all item registration, validation, and locale injection internally
  • Includes a client-side bundle injector for custom 3D models and use animations via BepInEx/plugins/Serenity-ItemGen/bundles/

Web Tool

Create item packs visually with the ItemGen Tool - pick a base item template, set your custom stats and details, configure traders, drop in custom bundle files, and export a ready-to-use zip.

Installation

  1. Drag the SPT and BepInEx folders from the mod archive into your SPT installation directory.
  2. Start the server. ItemGen loads automatically and waits for item packs.

Making an Item Pack

  1. Open the ItemGen Tool.
  2. Select a base item template, set your custom name, description, and stats.
  3. Configure traders and, if needed, drop custom bundle files into the Bundles tab for custom 3D models.
  4. Click Export to download a zip.
  5. Drag the SPT folder (and BepInEx if bundles are included) into your SPT install to test (ALWAYS use a new temporary profile when testing).

Tip: Always test on a new developer profile (and make sure to clear temp cache) so you can verify trader listings, item rendering, and bundle injection without affecting your main save.

Publishing an Item Pack Addon

The ItemGen Tool export zip is already structured for distribution, users just drag the SPT folder into their install directory.

When publishing:

  1. State the dependency: Your add-on pack requires ItemGen v1.0.0 for SPT 4.0.13.
  2. Do not include the ItemGen DLL or other authors’ packs in your zip.
  3. Test by extracting and running the server before publishing.

Dependencies

  • SPTarkov 4.0.13
