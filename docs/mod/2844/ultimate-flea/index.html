UltimateFlea

Server-side flea market mod for SPT 4.0.

Control what can be sold, set prices yourself, pull live averages from Tarkov.dev, and run a local supply/demand economy with early-wipe scaling.

Features
  • Item pool — blacklist / whitelist by item ID or category
  • Pricing — fixed prices, global/item/category multipliers
  • Tarkov.dev prices — uses avg24hPrice from json.tarkov.dev (with cache fallback)
  • Local economy — buys raise demand, sold player offers raise supply
  • Early wipe — temporary price multiplier based on character age (RegistrationDate)
  • WTT-friendly — can unblacklist custom items so they appear on the flea

Configured entirely through JSON. No in-game UI.

Install
  1. Extract the archive to the game folder
  2. Edit configs in config/ next to the DLL
  3. Start the server

Default configs use a realistic flea preset (Tarkov.dev prices + mild economy).

Config
File Purpose
mod.json Master switches, price source, flea behavior
pool.json What can / cannot be listed
pricing.json Fixed prices and multipliers
economy.json Supply/demand simulation and wipe settings

Item IDs: https://db.sp-tarkov.com/

Economy state is saved to data/economy_state.json. Tarkov.dev prices are cached under data/ as well.

How to configure

Edit JSON files in SPT/user/mods/UltimateFlea/config/, then restart the server.

Quick start

  1. Leave the default realistic preset if you just want live-ish prices.
  2. Set "priceSource": "tarkovdev" for Tarkov.dev averages, or "local" for SPT handbook/prices.
  3. Use pool.json only if you want to force-add/remove items.
  4. Use pricing.json for fixed prices or multipliers.
  5. Tune economy.json if prices move too fast/slow or wipe feels too strong.
  6. After big economy changes, delete data/economy_state.json for a clean start.

mod.json

Field What it does
enabled Turns the whole mod on/off
enablePoolManager Enables pool add/remove rules
enablePricing Enables custom price rules
enableEconomy Enables supply/demand simulation
priceSource local or tarkovdev
pvePrices If using tarkovdev: use PvE prices instead of regular
preserveBasePrices Stops SPT from rebuilding prices from handbook
disableTraderPriceFloor Allows flea prices below trader buy prices
exactOfferPrices Removes SPT’s 0.8–1.2 offer price spread (affects whole flea)
debug Extra logging

pool.json

Field What it does
mode blacklist or whitelist
add / remove Specific item TPLs
addCategories / removeCategories Direct parent category IDs
  • Blacklist: keeps the normal SPT pool and only changes listed items/categories.
  • Whitelist: only items in add / addCategories are allowed; everything else is blocked.
  • Item rules beat category rules.
  • If WTT blacklists a custom item, putting it in add also clears that blacklist/cache so offers can spawn.

pricing.json

Field What it does
globalMultiplier Multiplies all prices
fixedPrices Hard RUB price; economy never changes these
itemMultipliers Multiplier by item TPL
categoryMultipliers Multiplier by parent category

economy.json

Field What it does
simIntervalMinutes Minutes between economy ticks
demandPerBuy Demand added when buying from flea
supplyPerSell Supply added when a player offer sells
priceElasticity How hard supply/demand push the target price
decayPerTick How fast demand/supply fade each tick
settleSpeed How quickly current price moves toward the target
noise Random market noise around the target
minPriceFactor / maxPriceFactor Floor/ceiling vs base price
wipe.enabled Early-wipe multiplier on/off
wipe.startLengthDays How long the expensive early-wipe phase lasts
wipe.startMultiplier Multiplier on day 0; fades to 1.0 by the end

Wipe age uses the character’s RegistrationDate, not mod install time. With multiple profiles, the oldest PMC is used.
