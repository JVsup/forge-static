Loot Search Speed

Loot Search Speed is a lightweight client-side mod for SPT that allows you to independently configure both the initial container search delay and the item reveal delay while preserving vanilla gameplay.

Features

  • Configurable container & corpse search speed
  • Configurable item reveal speed
  • Vanilla-friendly behavior
  • Configuration Manager (F12) support
  • Lightweight Harmony patches
  • Open source

Configuration

InitialSearchDelayMultiplier

Controls how long the initial Searching… animation takes.

Value Result
1.0 Vanilla
0.5 2× faster
0.25 4× faster
0.0 Instant

ItemRevealDelayMultiplier

Controls how quickly items appear after opening a searched container.

Value Result
1.0 Vanilla
0.5 2× faster
0.25 4× faster
0.0 Instant

Compatibility

  • SPT 4.0.13
  • Client-side only
