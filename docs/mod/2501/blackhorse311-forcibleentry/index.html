Blackhorse311-ForcibleEntry

Force open any locked door by breaching it multiple times.

How It Works

  1. Find a locked door in-raid
  2. Use the breach (kick) action on the door
  3. Repeat 5 times consecutively (within 10 seconds)
  4. The door is forced open!

Features

  • Any Locked Door - Works on all locked doors, not just specific ones
  • No Items Required - Uses the existing breach/kick mechanic
  • Configurable - Adjust breach count (1-20) and timeout (5-60 seconds)
  • Client-Side Only - No server mod needed

Configuration

After first run, edit BepInEx/config/com.blackhorse311.forcibleentry.cfg:

Setting Default Description
BreachesToUnlock 5 Breaches required to force open a door
BreachTimeout 10 Seconds before breach counter resets

Installation

  1. Extract the archive to your SPT root folder
  2. Start SPT and play!

Requirements

  • SPT 4.0.x
  • BepInEx 5.4.x (included with SPT)
