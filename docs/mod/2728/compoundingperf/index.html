Description Versions 2

CompoundingPerf stacks several small, independent server-side optimizations under one config. Each feature is individually toggleable, and everything is designed to coexist with other mods. No client plugin, it’s FIKA-safe by design.

What it does

Feature What you get
Calm flea updates Removes vanilla’s forced, blocking full garbage-collection when flea offers expire, a recurring multi-second freeze. Measured: 54 forced GCs skipped in one session, worst stall ~8s → ~1.7s.
Response cache Fifteen static-after-load endpoints (item DB, handbook, hideout recipes, globals…) cached after first request. Noticeably snappier stash, hideout, and menu loads.
Fast compression Server responses compressed for speed instead of vanilla’s slowest setting: several times less CPU per response, output unchanged.
Profile save coalescing Rapid-fire profile saves get merged, at most one in flight plus one trailing per profile. The trailing save always captures the latest state, so nothing is ever lost.
Idle save skipping Skips the periodic profile save when nothing has changed, instead of re-serializing the whole profile every tick.
Single-pass sanitizer Replaces five regex passes per response with one zero-allocation scan. Identical output.
Thread-safe RandomUtil & caches Fixes latent thread-safety hazards in the server’s shared RNG and three internal caches, prevents intermittent “collection was modified” crashes under load.
Isolated bot randomisation Fixes a vanilla bug where night-raid equipment modifiers leaked into shared bot config and compounded across bots and raids.
Calm notifier Websocket sends stop holding the global lock during network I/O, and the notify long-poll frees its thread between checks. Most valuable for FIKA hosts.

How it plays with other mods

Server features use SPT 4.0’s DI override mechanism instead of replacing methods, so other mods’ Harmony patches on the same classes keep working on top. Per-session endpoints (profile, quests, flea search) are never cached. Every override matches the vanilla DI lifetime, and the mod warns at boot if another mod displaces one of its overrides.

Compatibility

  • Works on unmodded SPT 4.0.13
  • Works with FIKA 2.3.x (fixes the 2.3 /fika/api/players crash some hosts hit)
  • Server-only - no BepInEx plugin, nothing client-side to install, configure, or diverge between players
  • Every feature has an Enabled flag in config.json - flip any of them independently

Install

Drag the archive onto SPT Mods Installer, or extract it over your SPT install root. It installs one folder:

SPT/user/mods/CompoundingPerf/ → CompoundingPerf.dll + config.json

No BepInEx plugin. Upgrading from 1.2.x? Delete the old BepInEx/plugins/CompoundingPerf.Client/ folder — 1.3 is server-only and doesn’t use it.

Version

1.3.0

21 June 2026
SPT 4.0.13 Fika: compatible 3,714 downloads27.3 KB

New

  • S8 CalmRagfairServer — vanilla forces a blocking, compacting full GC every time enough flea offers expire, a recurring multi-hundred-ms-to-multi-second stall. This runs the exact same expiry sequence minus the forced collect. In a measured session it skipped 54 forced GCs and the worst frame-pause dropped from ~8s (mod off) to ~1.7s.
  • S9 FastCompressionHttpListener — responses compressed at zlib Fastest instead of vanilla’s slowest SmallestSize: several-fold less CPU for a few percent more bytes that only cross localhost/LAN. Output is byte-compatible.
  • S10 ThreadSafeCaches — serializes access to three SPT caches (handbook prices, item base classes, item blacklists) that vanilla writes at runtime while parallel ragfair tasks read them. Prevents an intermittent concurrent-collection crash.
  • S7 FastHttpResponseUtil — replaces five regex passes per response with one zero-allocation scan. Identical output.

Removed

  • The log-filtering pair (S3/C4) — dropped close to nothing on default setups and made other mods’ bug reports worse. The mod is now server-only! No BepInEx plugin ships, which also clears the client/server GUID-mismatch warning in check-mods.

  • Upgrading from 1.2.x? Delete the old BepInEx/plugins/CompoundingPerf.Client folder. It is no longer needed
