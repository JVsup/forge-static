QuickSellFlea

Tired of placing orders on the flea? Tired of having to install 20 mods to quick sell on flea? Now you can instantly place it with the average price - with just ONE click and no other mods needed!

Description Versions 8

When in your main menu stash, or hideout, hold CTRL (default, can be changed) and right-click an item to post it on the flea with the average price. 100% client-sided, no server mod or other dependencies needed.

You can toggle whether to show listing price or average price in the tooltip in the F12 menu.

The idea came from Simdola, who tried other similar mods. The problem is that they require either a server side component, or another mod to be used. This mod is very simple, performant, safe and has very little interference with base game logic.

New with 1.3.0

  • Added UIFixes multi-select integration (thank you tyfon for being awesome)
  • Added 2 new options:
    • Bypass Limit: The mod will now ignore your post limit on the flea
    • Hotkey: The hotkey to hold down to show the interaction

New with 1.1.3

  • You can now choose the currency you want to list in
    • The mod automatically calculates the average price of the currency

New with 1.1.0

  • You can now hold SHIFT while posting to post all items of similar type

The text will show ([1s, 10x] 1000) where S represents stacks, X amount (e.g. for stackable ammo) and 1000 is the total gain from posting it (or listing price, depending on your settings).

Limitations:

  • You can only place the same amount that you are restricted to on the flea (the button won’t appear otherwise)
  • If you right-click a stacked item, it will always place the full stack. Split before posting
  • This does not let you post normally flea-restricted items
  • This does not bypass FiR requirements for the flea

Bugs:

  • Sometimes the SPT server doesn’t execute the callback properly, this happens even without the mod. If you see a flashing item you need to restart the game. This needs to be fixed by the SPT development team. (as of 1.3.1 this has been fixed with a workaround)
