BossNotifier

Know your enemies before they know you! BossNotifier alerts you to boss spawns at raid start and displays real-time 3D markers above their heads.

Supported Bosses: Reshala, Tagilla, Killa, Glukhar, Shturman, Sanitar, Zryachiy, Kaban, Kollontay, Partisan, Goons, Cultists, Rogues, Blood Hounds, Santa Claus, Punisher, Legion

📖 Description

Notifications

  • Get notified which bosses spawned when the raid begins
  • See where bosses spawned (e.g., “Reshala has been located near Dormitory”)
  • Get alerted when you enter a boss’s vicinity (✓ checkmark)
  • Press O anytime to see current boss locations
  • Lock features behind Intel Center levels for progression

3D Markers

  • Floating markers above boss heads that update in real-time
  • Show/hide distance and boss name
  • Full RGB color customization
  • Option to only show markers when you can see the boss
  • Press P to toggle markers on/off
⚙️ Configuration

All settings configurable via F12 menu:

General

  • Keyboard Shortcut (default: O)
  • Show Bosses on Raid Start

Intel Center Unlocks (set to 4 to disable)

  • Notification unlock level
  • Location unlock level
  • Detection unlock level

Boss Markers

  • Enable/Disable markers
  • Toggle markers key (default: P)
  • Show through walls
  • Customizable marker: ▼ ▽ ↓ ● ◆ ★ ⚠ ☠ ◉ ▲
  • Show boss name
  • Show distance
  • Font size
  • Base/Max scale
  • Visibility distance
  • Marker color
📥 Installation
  1. Download the latest release
  2. Extract the archive
  3. Copy BepInEx folder to your SPT directory
  4. Start the game and configure via F12

🎮 Fika Sync

Playing with Fika? Install the BossNotifier - Fika Sync Addon for multiplayer support!

Features:

  • Boss locations sync from host to all clients
  • Boss death status syncs to all players
  • Press O on any client to see boss notifications

Requirements:

  • Both host AND clients need:
    • BossNotifier v1.1.1+ (this mod)
    • BossNotifier - Fika Sync Addon
    • Fika 2.1.0+
