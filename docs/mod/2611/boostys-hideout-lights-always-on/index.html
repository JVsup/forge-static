Boosty’s Hideout Lights Always On

Overview

This mod allows hideout lighting to function without generator fuel while preserving normal hideout progression and user light settings.

What It Changes

  • Removes the fuel requirement for hideout Illumination.
  • Keeps standard progression behavior:
    • Illumination still needs to be built/upgraded normally.
  • Keeps user-selected light mode behavior (it does not force a custom light level preset).

Compatibility

  • SPT target: ~4.0.0
  • Works in single-player and Fika setups.
  • Fika note:
    • Server part must be installed on the host/server.
    • Client DLL must be installed on each player client.

Installation

  1. Close server, launcher, and game.
  2. Extract the release zip into your SPT folder.
  3. Confirm files:
    • BepInEx/plugins/BoostysHideoutLightsAlwaysOn.Client.dll
    • SPT/user/mods/boostys-hideout-lights-always-on/BoostysHideoutLightsAlwaysOn.dll
  4. Restart server and game.

If your setup is single-root (no nested SPT folder), use:

  • user/mods/boostys-hideout-lights-always-on/BoostysHideoutLightsAlwaysOn.dll

Verify It Loaded

  • Server log should include:
    • [BoostysHideoutLightsAlwaysOn] Illumination no longer requires generator fuel.
  • Client BepInEx/LogOutput.log should include:
    • Client patch enabled (light gating override).

Uninstall

  1. Remove BepInEx/plugins/BoostysHideoutLightsAlwaysOn.Client.dll
  2. Remove SPT/user/mods/boostys-hideout-lights-always-on (or user/mods/... on single-root setups)
  3. Restart server and game.
