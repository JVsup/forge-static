This mod was built to be extremely simple with as little impact as possible. The default configuration effectively halves the speed of the QTE, and doubles the size of the success window.

  2. Select the SPT folder in the 7z file in 7-zip

CONFIG

SPT/user/mods/acidphantasm-simpleworkoutqte/config/config.json

Configuration Options

EasyMode

Enable

Enables or disables Easy Mode.

  • false = normal configurable system
  • true = simplified easy training mode

NumberOfReps

Number of repetitions used when Easy Mode is enabled.

NonEasyMode

NumberOfReps

Number of repetitions used in standard mode training.

StartSpeed

Initial speed of the QTE indicator.

EndSpeed

Final speed of the QTE indicator.

  • Lower values = slower movement
  • Higher values = faster movement over time

StartX

Starting X-axis value (controls QTE size/position scaling).

EndX

Ending X-axis value (controls QTE size/position scaling).

  • Lower = smaller
  • Higher = larger

StartY

Starting Y-axis value (controls success window size).

EndY

Ending Y-axis value (controls success window size).

  • Lower = smaller window
  • Higher = larger window

ProgressionType

Defines how difficulty scales over time.

  • “Exponential” = accelerates over time
  • “Linear” = constant rate progression

MusclePainTime

Duration of muscle pain after training.

  • Value is in seconds
  • Example: 43200 = 12 hours

SuccessEnergyCost

Energy lost on successful QTE completion.

  • Negative values reduce energy
  • Example: -2 = lose 2 energy

SuccessHydrationCost

Hydration lost on successful QTE completion.

  • Negative values reduce hydration
  • Example: -2 = lose 2 hydration

FailureEnergyCost

Energy lost on failed QTE completion.

  • Negative values reduce energy
  • Example: -4 = lose 4 energy

FailureHydrationCost

Hydration lost on failed QTE completion.

  • Negative values reduce hydration
  • Example: -4 = lose 4 hydration

SkillLevel0ExpMultiplier

XP multiplier at skill level 0+.

SkillLevel10ExpMultiplier

XP multiplier at skill level 10+.

SkillLevel20ExpMultiplier

XP multiplier at skill level 20+.

SkillLevel30ExpMultiplier

XP multiplier at skill level 30+.

SkillLevel40ExpMultiplier

XP multiplier at skill level 40+.

SkillRewardWeights

Defines probability weighting for skill gains.

  • Higher value = more likely to be selected
  • 0 = disabled

Example:

Strength: 25
Endurance: 25
Others: 0

SkillReferenceSheet

Reference list of valid skill enum values used in SkillRewardWeights.

https://wiki.sp-tarkov.com/en/modding/references/skills-reference
