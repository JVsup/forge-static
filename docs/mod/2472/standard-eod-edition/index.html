A mod that adds some Edge of Darkness features to the standard edition, namely:

  1. Protected Gamma container.
  2. Expanded TUE pockets.
  3. The Nostalgia quest chain.
  4. Increased purchase limits from merchants by 20%.
  5. Accelerated insurance refund.
  6. Access to unique crafts in the shelter.
