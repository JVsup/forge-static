Toxic Bullet

As you know, there’s a bunch of hooded lunatics in THE CITY who come out at night and love stabbing people with their signature poisoned daggers. But with this mod, You’ll tell them what is the most effective way to get toxins into someone’s body.

Features
  • Includes two types of toxic bullet: 5.56x45 and 9x19 toxic. They will cause the same effect to human body as the cultist’s dagger.
  • Supports customization of ammo ID and buff type configuration. In theory, you could even make bullets that can heal your enemies by attaching stimulator like protital’s buff.
For Modders

To add new ammo-buff mapping:

  • Ammo ID and buff type mapping defined in [Your Game Folder]/BepInEx/plugins/Mass.BulletWithBuff/BulletBuffConfig.json
  • You can also change “Description” value (NOT description in locales) in ammo’s item template to a buff name start with “Buffs_”
  • Buff mapping defined in BulletBuffConfig.json will be used preferentially.
  • MAKE SURE THE ENTRY YOU ADDED REFERENCING A VALID BUFF.

To add new buff:

  • If your want to add new buff types, an example file is provided in [Your Game Folder]/SPT/user/mods/ToxicBullet/buffs folder. Every .json file under this path will be loaded as buff defination data with the buff name being the file name respectively.
Fika

To use with Project Fika:

  • Install this mod on every client including headless.
  • Make sure everyone has the same BulletBuffConfig.json file.
