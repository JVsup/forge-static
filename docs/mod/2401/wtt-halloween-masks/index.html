Introduction

Yea so basically BSG’s halloween masks are for babies.

IF YOU HAVE TRYPOPHOBIA, BLOOD MAKES YOU SQUEAMISH, HATE NEEDLES, OR MANY EYES BOTHER YOU DO NOT DOWNLOAD!

Adds 10 Halloween masks available at Ragman level 2 for between 12k and 26k roubles. They are also available on the flea.

One of the masks is animated. If you want the animations to work, please download and install Animator Enabler

There will be pictures in the Gallery.

How To Install and Compatibility

How to install:

  1. Download the latest version.
  2. Open the downloaded zip file with your choice of archive manager (Like 7zip or WinRar, DO NOT USE BASE WINDOWS FILE MANAGER)
  3. Put the contents of the zip file into your SPT folder.
  4. Enjoy!

Compatibility:

  • Most other content mods work with this, report any that don’t.

Incompatibility:

  • If you are not using a patch for this mod with realism you will have many issues.

The standard way to troubleshoot this mod is as follows:

  1. If you have issues when you install this mod, try making a new profile (preferably a dev bear profile) and make sure your game works. I do this by standard with my mod prior to release anyways, so it should always work.
  2. Add your previously used mods and boot the game and run a raid after each installed mod. This is to see if anything is conflicting with my mod. Tell me what is conflicting and what your error message is so that I can verify whether it can be fixed or if it just needs to be added to incompatibilities.
  3. IF YOU HAVE “MISSING PACKAGE JSON” ERROR YOU INSTALLED IT WRONG
  4. If you are using something that is already listed as an incompatibility I am not going to help you.
