AddMissingQuestRequirements

Server-side SPT 4.x mod that auto-expands quest weapon requirements to include modded clones.

A server-side SPT mod that automatically includes modded weapons and attachments in base-game quest conditions.

Every vanilla quest that says “kill 10 PMCs with an AK-74” implicitly means “any modded AK-74 clone too” but the game only counts the specific weapon IDs BSG listed. This mod fixes that at server startup: it figures out what category each weapon and attachment belongs to, then expands quest conditions to include every same-category item installed on your server.

No in-raid cost. Everything happens once, when the server boots. Nothing is patched on the fly.

For an expanded set of fine-tuned configurations and overrides, see the addon: https://forge.sp-tarkov.com/addon/74/amqwr-patches-addon#description

Install

  1. Build or download the release. Drop the whole folder into SPT/:

    SPT/user/mods/GuiltyMan-AddMissingQuestRequirements/
    AddMissingQuestRequirements.dll
    config/
        config.jsonc
    MissingQuestWeapons/
        QuestOverrides.jsonc
        WeaponOverrides.jsonc
        AttachmentOverrides.jsonc

  2. Start the SPT server. You should see one line in the server console:

    AddMissingQuestRequirements ready in 1047ms — 20 of 49 weapon-quests changed (50 of 918 conditions). Weapons: 203 items across 66 types. Attachments: 1990 items across 1338 types.

  3. Launch the game. Quest kill counts should now tick on modded weapons of the same type.

Nothing to configure to use the mod — defaults cover all vanilla quests. Read on only if you want to customize behaviour or add support for your own mods.

Getting help

Turn on "debug": true and restart the server once, then open an issue with:

  1. Your config.jsonc, WeaponOverrides.jsonc, QuestOverrides.jsonc, AttachmentOverrides.jsonc.
  2. AddMissingQuestRequirements-debug-report.json and AddMissingQuestRequirements-debug-report.html from next to the DLL.
  3. AddMissingQuestRequirements.log from next to the DLL.
  4. A description of the quest / weapon / attachment that’s misbehaving.

More information at github: https://github.com/theGuiltyMan/SPT-Add-Missing-Quest-Weapon-Requirements

Changelog

2.0.0 — SPT 4.0 rewrite

Full C# port of the TypeScript mod. Targets SPT ~4.0.0.

Migration from 1.5.0

Drop your old config/ and MissingQuestWeapons/ files in as-is — they will be migrated automatically on first load. Migrated files are rewritten in the new format and stamped with a version field; the old format is treated as v0.

What the migrator does:

  • config.jsonc: fixes the categorizeWithLessRestrive typo, drops the unused delay field.
  • OverriddenWeapons.jsonc → WeaponOverrides.jsonc: Override block becomes manualTypeOverrides, CustomCategories becomes customTypeRules.
  • QuestOverrides.jsonc: structure preserved, version stamped.
  • New AttachmentOverrides.jsonc is optional — defaults cover the full attachment tree.

No manual edits required for a stock 1.5.0 install.

New

  • Attachment-condition expansion (weaponModsInclusive / weaponModsExclusive) — supports mod-added quests with no weapon array.
  • Rule-chain type detection — bolt-action / pump-action / revolver / caliber checks are config, not code.
  • Per-condition override matching by structural properties, not only condition ID.
  • Opt-in bestCandidateExpansion and validateOverrideIds.
  • Inspector CLI + local web UI for offline iteration on configs without launching SPT.

Removed

  • delay config field (was a no-op).
  • logType — replaced by always-on file log + SPT console, gated by debug.
