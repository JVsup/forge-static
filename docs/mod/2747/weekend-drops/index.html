Weekend Drops

Weekend Drops gives you a set of challenges to work through each weekend, daily quests for the rest of the week, to earn (GP) and spend in the shop.

I made it because twitch drops in live EFT are kinda neat but since you cant get them in SPT i though this could be a version of gaining twitch drops in SPT

Daily challenges

Five quests a day, every day, each one pays GP. These run all the time, not just on weekends, so there’s always something small to do. Finish all five for a bonus.

GP and the shop

GP is a virtual balance, you earn it from challenges, and you can also deposit GP coins you find in raid straight into your balance (there’s a slider so you can bank some and keep the rest for REF).

The shop sells storage cases, Arena crates and a few rarer barter items. Things go on a cooldown after you buy them so you can’t just spam-buy.

The Weekly challenges
  • PMC, Scav and boss kills
  • Headshots and grenade kills
  • Surviving X minutes, extracting, extracting from a specific map
  • Play-as-Scav quests (extract as a Scav, finish Scav runs, kills across Scav raids)

Contracts
  • Contracts a new menu tab (in drops menu). Each board offers a few sealed contracts; you pick one. Its target spawns on your next raid of that map, and clearing the objective pays GP, Two kinds of Bounties exist so far: (hunt a specific crew or boss) and Supply Runs (wipe the crew to call in an airdrop on their position). Accepting or abandoning spends your pick, and a fresh board rolls in after a few days.
Translating Weekend Drops

Everything the mod shows you lives in en.json. To add a language, copy that file, rename it, and translate the values. No code, no build, no rebuild of the mod.

Adding a language

  1. Copy en.json to <code>.json using the game’s own language code:

    Code Language Code Language Code Language
    en English ge German jp Japanese
    ru Russian fr French kr Korean
    ch Chinese es Spanish pl Polish
    cz Czech it Italian po Portuguese
    hu Hungarian ro Romanian sk Slovak
    tu Turkish es-mx Spanish (LatAm)

    Note these are Big Silly Goose’s codes, not ISO: German is ge (not de), Chinese is ch, Japanese jp, Korean kr.

  2. Translate the values on the right. Never touch the keys on the left.

  3. Drop the file in BepInEx/plugins/WeekendDrops/locales/ and restart the game. It is picked automatically when the game is set to that language.

Anything you leave untranslated (or delete) falls back to English, so a partial translation is perfectly usable. You can ship 50 lines and add more later.

Rules

Keep {0}, {1} exactly as they are. They are filled in at runtime:

"ui.notif.claimBoth": "{0} daily and {1} weekly waiting to claim"

You may reorder them if your language needs a different word order ("{1} weekly and {0} daily ..."), but you may not invent new ones or drop the existing ones. A mismatch shows the wrong number on screen.

Keep the colour tags. The tutorial text contains markup like <color=#CD8532><b>GP</b></color>. Translate the words between the tags, leave the tags themselves alone.

Keep it short. Most strings sit in fixed-width buttons and chips. German and Russian run roughly 30% longer than English, and long text gets clipped rather than wrapped. If a line does not fit, prefer a shorter phrasing over an exact translation.

ALL CAPS is intentional on headers and buttons. Match it where your script has capitals; ignore it where it does not (Chinese, Japanese, Korean).

Fonts (important for Chinese, Japanese, Korean)

The panel is drawn with Unity’s built-in font, which has Latin and Cyrillic but no CJK glyphs - they render as empty boxes. Fix it by naming a system font in your locale’s _meta block:

"_meta": {
  "name": "简体中文",
  "credit": "your name here",
  "font": "Microsoft YaHei, SimHei"
}

Comma-separated, tried in order, so you can list a fallback for older Windows installs. Leave font empty for Latin and Cyrillic languages - the default is fine.

Changing the font needs a game restart. Changing text does not. Testing your file

Set Language in the F12 config to your code (instead of auto) to force it on without changing the whole game’s language.

if you got python installed you Then can check if the file is well-formed useing:

python tools/check-locale.py

It reports missing keys, keys that no longer exist, and broken {0} placeholders.

What the key prefixes mean

Prefix What it is
ui.* Menu, buttons, notifications, the tutorial
challenge.* Weekly and daily challenge descriptions
shop.* Shop item names and descriptions
contract.* Bounty names, objectives, and radio chatter
ui.map.*, ui.zone.* Map and landmark names - use the game’s own wording

For map and location names, copy whatever Escape from THE CITY itself calls them in your language rather than translating the English literally.

New

  • language i added a new sub folder directory named locales feel free to translate it to your language if there is a error in your translated locales it will load all the texts in English thats not a bug thats just a safe guard to not break anything
  • 65 new challenges across the weekend and daily pools - easier opening rungs for the categories that only ever offered hard ones (a single grenade kill, 2 headshots, one clean extract, a first Raider or Rogue), more per-map extracts, and fuller ladders for the survive-a-raid, loot and single-raid-spike categories that used to have one entry each. The melee-kill stunt stays a one-off oddity and now shows up less often than before, not more.

Changes

  • shop got a lil overhaul you can now buy a few new thing and barter for some supplys
  • Marksman rifles added to the Cleanup Crew’s arsenal - the M1A, HK G28 and RSASS in 7.62x51, plus the SVDS in 7.62x54R. Roughly one crew member in eight now carries a DMR, so expect to be reached from further out.
  • Cultist challenges are no longer a wall on a fresh profile. Hunting cultists needs a night raid and night vision, but the challenge picker treated them as an everyday category, so one landed on roughly 45% of weekends - a slot a new player simply could not finish. They now share a slot with the other rare-target hunts instead of holding one of their own, which drops them to about 26% of weekends, and the entry rung is a single cultist rather than three. The 8- and 12-kill versions are gone. The same rebalance spreads every other category more evenly, so weekends repeat themselves less.

Fixes

  • Depositing GP coins no longer destroys the ones you kept. Handing in 50 coins out of a stack of 200 credited the 50 correctly, but the leftover 150 disappeared: the deposit removed the whole stack and put a copy of the remainder back, and while your client showed those coins, the server had never agreed they existed, so they were gone at the next sync. Deposits now move whole stacks only, and the amount selector offers stack-sized amounts to match (two stacks of 100 offer 100 or 200). It is a coarser choice than before, but nothing can be lost. A smaller partial deposit would need the game to split a stack in a way that actually sticks, which i have not found a reliable route to yet.
  • Fixed three “kill X enemies in a single raid” challenges whose titles, ids and actual targets disagreed (two both read “Kill 12”, and one titled 18 only wanted 8). They are now a clean 6 / 10 / 15 / 20 ladder.
  • Supply Run crews now spawn on the drop instead of hiking to it. They were spawning anywhere in a zone that spans several hundred metres and walking in as a group, which is where they ran into trouble. They now start posted around the crate.
  • Fixed the Supply Run crew being sent to the wrong place entirely. The crew’s hideout was rolled from the map’s hideout list with no regard for where the crate was coming down, so you could get a Broken Village drop guarded from USEC Base. Worse, the crew could split, half holding the hideout while the rest walked off to the crate. Their posts are now always built around the rolled landing site. A Supply Run you already accepted repairs itself on the spot, so you don’t have to abandon it (and burn your board pick) to get the fix. also sorry for does who ran around the map trying to find them i did a terrible job adding the crew it should be now much better i hope at least…
