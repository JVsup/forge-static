Description Versions 1

This is a simple pack that adds a set of semi automatic, burst, and automatic variants of guns in line with the general theme of escape from tarkov. I tried to be as accurate as possible in naming these but some of these just don’t exist so i kept the general naming vibe so it doesn’t seem off.

to install, put the user file in your spt directory, also includes an optional realism patch

credit to steak au povire for allowing me to build off their burst m4 mod

lmk if you have any issues or suggestions, possibly going to try and add caliber conversions next
