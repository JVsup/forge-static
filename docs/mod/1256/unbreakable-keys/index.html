Unbreakable keys

Makes keys and keycards unbreakable.

Description Versions 1

Tired of monitoring the status of keys? Do you also think that the keys used to be better? Don’t you think the keys are too weak right now? This mod aims to fix this.

Previously, almost all keys had a large number of uses, but with the latest patches, some keys have become unnecessarily fragile, and keycards have only 10 uses at all, which is why they have dropped in price.

This mod allows you to make the keys unbreakable.

The mod also contains a configuration file. You can:

  • Make all regular keys unbreakable.
  • Make all marked keys unbreakable.
  • Make all regular key cards unbreakable.
  • Make all colored key cards unbreakable.

Installation

Extract “SPT” folder to SPT root directory
