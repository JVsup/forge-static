Description Versions 1

This mod adds a new trader that sells all food & drink items.

The prices are 100% Base Price from handbook.

Installation

  1. Open the downloaded zip file
  2. Select the SPT folder in the zip file
  3. Drag the SPT folder from zip file into your Game_folder

Recommended Mods
