bushtail here! I decided to switch up the names of my utility mods to be more indicative of what they do.

This one allows you to edit the whitelist (accidental misnomer when I was writing it) of the shelves in the Hall of Fame (PlaceOfFame in Big Silly Goose naming). Axes of items are not changed, so not everything will look as they should.

The config file is generated with a set of default values at first start (all armbands in the small shelf slots, and the GPU in the large shelf slots’ whitelist). Please lint your config JSON before reporting any issues.
