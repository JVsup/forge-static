Sharper Tarkov Better Life

A simple and lightweight ReShade preset that improves visibility and enhances the overall look of EFT by making the game sharper without over-sharpening it or making UI elements an eyesore to look at.

Description Versions 4

Hey! This is NOT A MOD. This is a ReShade preset, meaning this is compatible with all versions of SPT/EFT.

Drag and drop the contents of the SharperTarkovBetterLife.7z file into your root game folder so that dxgi.dll is in the same directory as EscapeFromTarkov.exe.

If you wish to uninstall, delete the files that are added by this preset.

You do not need any mods such as Amand’s Graphics to use this preset, However, it is highly recommended. I wouldn’t recommend using any other methods of sharpening such as any present in EFT’s settings and so on. This doesn’t reduce performance unless you are GPU bottlenecked.

ReShade 6.5.1.2008 is PREINSTALLED. Press HOME to open the overlay menu.
