Description Versions 1

Adds caliber to ammo names, while keeping them short enough to read in your inventory.

Most naming abbreviations are vanilla friendly, so if you’re used to seeing the different ammo types in the game, they should still be easily recognizable to you.

The one exception to this is 7.62x51. I renamed it to 308 to differentiate it from the other 7.62 ammos. (Yes, I know .308 and 7.62 NATO are technically not the same thing, no I don’t care, change it in the config if you don’t like it.)

If you’re unhappy with my naming, want to change the language the changes are applied to, etc., visit the config.json file.
