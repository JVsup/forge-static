Description Versions 6 Addons 3
English

The mod aims to simplify the process of adding new items in SPT by encapsulating item creation interfaces, and provides comprehensive documentation that systematically organizes data resources and explains the function of various properties and fields. The accompanying Wiki offers complete API references and item creation guides, helping developers and players use the mod more efficiently and rapidly expand SPT’s item database.

Tag Explanation:
The mod uses semantic versioning (x.x.x). The Wiki (available as a separate download from the mod plugin) is also released with semantic versions but is uniquely identified by Wiki Tags. A Wiki tag follows the format Wiki_Year_Month_Day_Hour_Minute and is used consistently for labeling and linking within the local Wiki documentation.

Download Instructions:
Starting from version v0.1.0, to reduce package size, the default download link only provides the mod itself. The Wiki is no longer bundled with the mod.

  • If you need only the mod, download it directly from this page.
  • If you want to download or update the Wiki, get it separately from the mod plugin page.

After extracting the mod, you will find one folder:

  • SPT/user/mods/SptItemCreator: The main mod

New Cache System (v0.1.0+):

  • Output directory: [Game Root]\SPT\user\mods\SptItemCreator\StatsCache
  • Contents: Based on the entire SPT database, the mod generates a categorized list for each type, including all property names and all values that have appeared.
  • Purpose: Serves as a reference when creating new items, and provides a foundation for creating scripts to calculate frequencies, value distributions, averages, etc.

How to Use the Wiki:

  1. (Optional) Move the Wiki folder to any location you prefer — except inside any SPT 4.0 mod folder.
  2. Navigate into the Wiki folder.
  3. Double-click index.html.
  4. Starting from Wiki_26_02_02_18_20, the Wiki supports both Chinese and English bilingual content. You can switch between languages directly within the Wiki interface.

Note:
Since the mod and Wiki are now distributed separately (starting from v0.1.0), the server warning about “No Assemblies found” mentioned in previous versions no longer occurs. You can safely place the Wiki folder anywhere outside the SPT mods directory.

  • Added [UsedImplicitly] attribute to INewItem.PropertyOverride property to eliminate warnings

  • Removed the $type field from item templates (backward compatible reading retained)
  • Type mechanism clarification: Item properties are determined by the actually assigned Info fields, independent of baseInfo.type
  • Data files now support JSONC comments (single-line // and multi-line /* */), added StripJsoncComments method to DataLoader with state machine parsing logic

New Features

  • Support for Chinese rarity keys (Common, Rare, Super Rare, Nonexistent)
  • Support for Chinese item sound keys

Configuration Updates

  • Added requiredItemIds configuration option to validate existence and enabled status of required items

Validation System

  • Built a unified validator system, implementing IValidator interface and chaining calls
  • Added BaseInfoValidator: validates required fields, MongoId format, type validity
  • Added AttributeInfoValidator: validates positive integer dimensions, rarity, sound type
  • Added BuffsInfoValidator: validates Buff effect configurations
  • Added MedicalInfoValidator, DrinkFoodInfoValidator, AmmoInfoValidator: respectively validate medical, food/drink, and ammunition configuration logic
  • Removed invalid negative weight validation logic
  • Enhanced error collector to carry item path information for easier problem localization

Architecture Optimization

  • Changed UpdateProperties and UpdateDatabaseService methods to protected, restricting external calls
  • Enhanced null validation logic for BaseInfo and BuffsInfo
  • Improved deserialization error logging, added complete exception stack traces
