Overview

This mod introduces the QBZ-03, a Chinese-made conventional rifle chambered in 5.56×45mm, ported from Insurgency: Sandstorm.

- Comes with modern, fictional SEK modification parts.

- Fully modular: from standard infantry rifle to highly customized tactical platform.

- Base animations adapted from the AKM set to fit the AR-style magwell.

> Update v1.2.0:

> Use the new SEK modification kit to unlock the rifle’s full potential.

Features

- Lightweight M-LOK handguard with multiple mounting slots.

- Ergonomic pistol grip designed to prevent finger strain and sharp-edge cuts.

- ACR-style stock — yes, it fits anything.

- Ambidextrous fast mag release for quick reloads.

- Ergonomic charging handle for improved handling.

- AR-15 buffer tube adapter included to support alternate stock options.

> SEK parts were created by the talented modeler YLdcmy

> [Visit YLdcmy on ArtStation](https://www.artstation.com/yldcmy)

Setup and Usage

1. Unzip the downloaded files.

2. Drop the mod folder into your SPT directory.

3. Launch the game.

4. Visit Mechanic’s shop or the Flea Market to find the QBZ-03 and its attachments.

**Note for MPT/Fika users:**

If you experience white textures or bundle errors:

- Copy /user/mods/Mass\_QBZ03/Mass\_QBZ03/bundles

- Merge into /user/cache/ under the matching folder.
