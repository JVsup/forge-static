Softcore Meds

Description Versions 3

Features

1. Restore Limbs with Stims

Now you can restore destory limb with stimulator, just that simple. Current only apply to “eTG-change regenerative stimulant injector”.

Balance

Not without some debuff to balance gameplay, Include side effect:

  • Hands Tremor (60s)
  • Tunnel Effect (60s)
  • Energy Drain (equals the amount of limb max health, reduced by the “Metabolism” skill)
  • Hydration Drain (equals the amount of limb max health, reduced by the “Metabolism” skill)

2. Quick Access Limb Selector

Also works with limb selection via the quick access slot.

3. Multi-Limb Surgical Restoration

Restore multiple destroyed limbs with a single surgical action, consuming resources based on the number of limbs. Currently applies to “Surv12” and “CMS”.

Other

FIKA + Headless

It runs without errors or crashes, but player state syncing has not been tested, as I only have one PC. This plugin is 100% client-side and does not need to be installed on the Headless instance.

Compatibility
  • Continous Healing (just disable “Heal Limbs” option in that mod )
  • Healing AutoCancel
  • Any other mod that add “New Container”, could not work with QOL feature, let me know when it happen
How to install

Download the zip and copy (drag) the BepInEx folder in package, to your SPT main folder (where EscapeFromTarkov.exe locates)

Uninstall

Just remove the dll file in YourSPT/BepInEx/SoftCoreMeds/SoftCoreMeds.dll

Feedback

If you encounter any issues, please report them on GitHub Issues with log, it’s easier that way.
