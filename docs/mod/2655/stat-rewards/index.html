Overview

Every raid you run racks up stats — kills, distance walked, blood lost, armor shredded. But those numbers just sit there doing nothing.

StatRewards turns your profile stats into repeatable milestones that send you random loot via mail. Kill 25 PMCs? Prapor sends you a weapon. Walk 25km? Jaeger mails you food and drinks. Lose 50 liters of blood? Therapist questions your biology and sends meds.

Key features:

  • 48 milestones out of the box — kills, headshots, damage, healing, looting, exploration, economy, and every weapon type
  • Random rewards by category — meds, ammo, gear, keys, barter items, money, food, drinks
  • Repeatable — milestones trigger every N stats, forever
  • Global threshold multiplier — one slider to make rewards more or less frequent
  • Fully configurable — add, remove, or tweak milestones and reward pools via JSONC config
  • Safe for existing profiles — first install seeds milestones to current stats, no retroactive reward flood
Installation

Extract the zip in your SPT root folder.

No client plugin needed — this is a server-only mod.

Configuration

Edit SPT/user/mods/StatRewards/config/mod_config.jsonc:

Global settings:

Setting Default What it does
debug false Verbose server logging (shows seeding and trigger details)
threshold_multiplier 1.0 Scales all milestone thresholds. 0.5 = rewards twice as often, 2.0 = half as often

Per-milestone settings:

Setting Description
id Unique identifier
stat_key Profile stat to track (see DESIGN.md for the full list)
stat_subkey Optional second key (e.g. "Survived" for exit status)
every Trigger every N of this stat (repeatable)
divisor Set to 100 for float-type counters (damage, heal, blood loss)
sender Trader ID who sends the mail
message Mail message text
reward_count How many items to pick per trigger
reward_pool Weighted list of reward categories or specific items

How It Works

Install → play. That’s it.

After each raid, when you return to the main menu, the mod checks your profile’s overall stats against all configured milestones. When a threshold is crossed, random rewards are generated from the milestone’s reward pool and sent via in-game mail from the configured trader.

First install: All milestones are seeded to your current stats. You won’t receive a flood of retroactive rewards — only new progress counts.

Progress tracking: A small JSON file per profile is saved in user/mods/StatRewards/progress/. Delete it to re-seed.

Nothing is permanent. Remove the mod and nothing changes in your profile. The mod only reads stats and sends mail.

Addons

You can create addons for StatRewards — no code needed. An addon is simply a modified mod_config.jsonc that adds or tweaks milestones.

What you can do:

  • Add new milestones with custom stat triggers, thresholds, messages, and reward pools
  • Change existing milestone thresholds, rewards, or trader senders
  • Create themed packs (e.g. “Hardcore Mode” with higher thresholds, “Casual Mode” with lower ones)

How to create an addon:

  1. Copy the default mod_config.jsonc
  2. Add, remove, or modify milestones
  3. Share your file — users just replace theirs with yours

Available stats for milestones: see the full list in DESIGN.md — 100+ trackable profile stats including kills by weapon type, kills by faction, damage types, looting, economy, exploration, and more.

Example — adding a custom milestone:

{
  "id": "my_custom_milestone",
  "stat_key": "KilledWithTemplate",
  "stat_subkey": "5cadfbf7ae92152ac412eeef",  // specific weapon template ID
  "every": 10,
  "sender": "5a7c2eca46aef81a7ca2145d",
  "message": "You really love that gun.",
  "reward_count": 2,
  "reward_pool": [
    { "category": "ammo", "weight": 5 },
    { "category": "weapon_preset", "weight": 3 }
  ]
}

See “Configuration” tab

What is it?

Your profile tracks hundreds of stats — kills, headshots, distance walked, blood lost, armor destroyed — but they just sit there. StatRewards turns them into repeatable milestones that send you random loot via trader mail.

Highlights

  • 48 milestones out of the box covering combat, weapon types, factions, health, survival, looting, economy, and exploration
