Description

This mod allows you to reduce the rain drops on your screen if you are wearing a forward facing cap with a brim as if you were wearing glasses, or disable it altogether when the cap is on.

Config

The config can be found in the BepInEx menu under F12, the only option is to toggle the caps to prevent the rain drops altogether

Mod compatibility

The only caps which should work with this mod are the ones from WTT-Backport as their IDs are the same as live.
