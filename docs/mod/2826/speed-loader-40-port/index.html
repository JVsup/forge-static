SPT 4.0 port of watsy’s Speed Loader mod. Credits to watsy and Nootropix. Original mod: https://forge.sp-tarkov.com/mod/1310/speed-loader

Modify the speed at which you can load/unload/check magazines in-game.

To install: Dragging the SPT folder from 7zip directly into your SPT directory should add it into the necessary folders in your server mods directory, just like any other server mod.

Configuration: In the folder SPT/user/mods/SpeedLoader/config you will find “config.json”. Open that file in a text editor and edit the values as you need.

Config Values:

enabled - Enable/disable the mod. Accepts true/false values.

smallestCapacityMagazineToSpeedUp - Decides which magazines to enable the mod for based on # of bullets they hold.

loadUnloadSpeed - Value to decide how fast magazines load/unload. The lower the values into the negatives it goes, the faster the load/unload speed (Making this value too low may cause errors.)

magCheck - Value to decide how quickly your magazine gets checked. Same concept as the loadUnloadSpeed config value.
