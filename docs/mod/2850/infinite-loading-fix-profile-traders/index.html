Infinite Loading Fix (Profile & Traders)

Profile stuck on loading forever? Traders opening empty? Both come from the same race: the game builds the menu before its data arrives. This mod waits for it instead of breaking. One file, no server mod, no profile edits, nothing to configure.

Description Versions 4

Two failures, one cause.

On a heavy modlist the client can finish building the main menu before the data that menu depends on has arrived. Nothing catches that, so you get one of two symptoms:

The profile never loads. You pick your profile and the loading screen stays there. The game is responsive, the server log looks perfectly healthy, but nothing ever happens. Traders open empty. The trader screen comes up blank, item interaction breaks, and it stays broken for the rest of the session. A restart fixes it — until next time. Both are timing races, which is why they are intermittent and why the usual advice (“clear your stash”, “remove a mod”, “edit your profile”) sometimes appears to work and then stops working.

What this mod does

It makes the client wait instead of breaking. When the menu is ready before its data, the mod holds that step back and runs it the moment the data lands. When a trader screen lost its reference to the item database, the mod hands it back so the screen builds normally.

If something genuinely cannot be recovered, the mod says so plainly in the log and tells you to restart — it will not quietly leave you with a half-working hideout and call it a success.

Installing

Drop the archive into your SPT folder. One plugin file, no server-side part, no profile changes, no dependencies. Everything is configurable, but the defaults are what you want.
