Ammo Weight Modifier v1.0.0

A server-side mod for SPT 4.0+ that allows you to adjust the weight of all ammunition in the game via a configurable percentage multiplier.

Features

  • Adjustable ammo weight through a simple config file
  • Each ammo type maintains its relative weight (heavier ammo stays heavier)
  • Server-side implementation ensures compatibility with Fika and all clients
  • Set to 0% for completely weightless ammo, or any percentage you prefer

Installation

  1. Download AmmoWeightModifier-LumurkFox.zip
  2. Extract to your SPT root directory (it will place files in SPT/user/mods/)
  3. Edit SPT/user/mods/AmmoWeightModifier/config/config.json to set your desired weight percentage
  4. Start your SPT server

Ammo Weight Modifier v1.0.0

A server-side mod for SPT 4.0+ that allows you to adjust the weight of all ammunition in the game via a configurable percentage multiplier.

Features

  • Adjustable ammo weight through a simple config file
  • Each ammo type maintains its relative weight (heavier ammo stays heavier)
  • Server-side implementation ensures compatibility with Fika and all clients
  • Set to 0% for completely weightless ammo, or any percentage you prefer

Installation

  1. Download AmmoWeightModifier-LumurkFox.zip
  2. Extract to your SPT root directory (it will place files in SPT/user/mods/)
  3. Edit SPT/user/mods/AmmoWeightModifier/config/config.json to set your desired weight percentage
  4. Start your SPT server

Configuration

Open config/config.json and set weightPercentage:

  • 0.0 = Weightless (default)
  • 0.5 = 50% of original weight
  • 1.0 = 100% (unchanged)

Restart the server after changing the config.
