one of my favorite mods has always been Leaves’ Progressive Container

that doesn’t work with 4.0, so i made my own without any coding experience. welcome s3til’s craftable containers. it’s the same concept, but with my own code and recipes using the WTT library

features:

-craft containers (wow)

-fully customizable in db/CustomHideoutCrafts/[[Containername]].jsonc

recipes are as follows by default (without listing specific items bc im lazy)

  1. waist bag -> alpha @ lavatory 1
  2. alpha -> beta @ workbench 2
  3. beta -> epsi @ workbench 2
  4. epsi -> theta @ intel 1
  5. theta -> gamma @ medstation 3
  6. gamma -> gamma+ @ workbench 3

6b. get the kappa from collector

  1. kappa -> kappa+ @ intel 3

-trade in your starting container at Ragman 1 for a waist bag!

config in config/barter.jsonc

change “ContainerForTrade” string to the container your edition starts with (alpha, beta, gamma, unheard gamma) and Ragman will trade that starting container for a waistbag at LL1

recommended mod pairings (aka also what i play with):

SVM to change containers to be different (gamma and gamma eod, kappa and kappa desecrated, etc)

profile modifier to give yourself a waistbag at the start

profile modifier to give yourself The Collector at the start

any problems and i guess lmk and ill try to fix it ive literally never coded anything before so this was all taken in chunks from WTT and SPT documentation
