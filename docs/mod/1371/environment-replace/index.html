Description

CHECK INSTALL TAB FOR REQUIRED DEPENDENCY!

Replace splash screen: put videos (mp4, gif) or pictures (jpeg, png, webp, etc.) into the “splash” folder.

Every game restart will have a randomly selected splash screen.

The video volume can be adjusted in the BepInEx F12 menu in-game.

Replace environment: put videos (mp4, gif) or pictures (jpeg, png, webp, etc.) into the “environment” folder.

Every game restart will have a randomly selected wallpaper.

(Download the above image here)

Install

THIS MOD REQUIRES EFTApi 1.1.4 or later - INSTALL IT FIRST

Extract BepInEx folder from 7z to Game Root directory

(Yes it’s QuestTracker, it works the same for this mod)

Issue

First, did you install EftApi? If not, install it.

If nothing, create a support thread. Describe your game version, what other mods you have installed, and what error(s) you are getting. If possible, attach a link to your LogOutput.log
