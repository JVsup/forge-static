Repair Skill Extension

Custom higher buff chance for repairing armor & weapon. Repair skills work on all armor items. Fully repaired at once.

Description Versions 4

What This Mod Does

  • Change the enhancement chance & buff effect while repairing by Kit.
  • Allow repair skills gain EXP and add DmgReduce for repairing Facecover, Visor.
  • Items get full durability by one repairing, no need to repair again and again.

My preset value:

You can edit buffs.jsonc in mod’s folder to change buff chance & effect.

  • linearly increase buff chance from 35% to 100% at corresponding skill Lv.10-51 (If <Lv.10, no buff allowed by vanilla EFT)
  • Armor & weapon keep buff in longer durability (80-95% of total)
  • Armor’s damage reduce is normal=10-15%, rare=25-30%
  • Weapon’s spread decrease is normal=10-15%, rare=25-30%
  • Weapon’s malfchance decrease is normal=20-25%, rare=40-50%

How to install

Download and drag files to your EFT folder, you should see dll and jsonc config in
Your_EFT_Folder\SPT\user\mods\RepairSkillExtension\

How to remove

Just delete this folder in user\mods. You can leave any buffed items in inventory.
