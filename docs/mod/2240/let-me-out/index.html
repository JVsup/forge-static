LET ME OUT

Stops transit interaction from disabling all the other exfils. I want out, let me out!

acidphantasm
Downloads
7,291
Favourites

55
Description Versions 3

All this does is allow you to exfil from other points on the map if you happen to accidentally interact with a transit.

Transits still work with this mod. Probably. I tested one transit and it loaded.

Whether or not this allows you to actually utilize the transit “send stuff to stash” if you choose not to transit - I have no idea. If your stuff goes poof that’s on you.

Whether or not this works with Fika - I have no idea. If your raid blows up, or your Fika server crashes, or if Fika staff come to your house and beat you senseless, that’s on you. (If it works - great, let me know in the comments… if it doesn’t work - I’ll fix it eventually, maybe, or maybe not)

INSTALLATION

Installation

  1. Download LET ME OUT
  2. Open the downloaded zip file in 7-zip
  3. Select the BepInEx folder in the zip file in 7-zip
  4. Drag the BepInEx folder from 7-zip into your SPT folder

Demonstration Video (yoink):

UNINSTALLATION
  1. Delete /ROOTSPT/Bepinex/plugins/acidphantasm-letmeout
  2. Done
