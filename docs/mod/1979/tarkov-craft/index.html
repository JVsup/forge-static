Basics

Try the tool HERE

Tarkov Craft is a web-based tool to create and customize crafting recipes and barter trades. With an intuitive interface, you can experiment with ingredients, tools, and crafting times while generating JSONs for easy integration into your projects.

JSON Structure

Each craft is exported as a JSON object following SPT’s hideout recipe format:

{
  "_id": "507f1f77bcf86cd799439011",
  "areaType": 10,
  "requirements": [
    {
      "areaType": 10,
      "requiredLevel": 2,
      "type": "Area"
    },
    {
      "templateId": "5c0e874186f7745dc7616606",
      "count": 2,
      "isFunctional": false,
      "isEncoded": false,
      "type": "Item"
    }
  ],
  "productionTime": 7200,
  "needFuelForAllProductionTime": false,
  "locked": false,
  "endProduct": "5c0e874186f7745dc7616606",
  "continuous": false,
  "count": 1,
  "productionLimitCount": 0,
  "isEncoded": false,
  "isCodeProduction": false
}
Usage

Option 1 — Use with TarkovCraft Loader (no coding required)

If you don’t want to write a mod from scratch, use TarkovCraft Loader — drop your exported JSON file into the mod’s folder and it will inject your custom crafts into the SPT server automatically.

Option 2 — Use the JSON in your own mod

If you’re building your own mod, copy the exported JSON and push the recipes into SPT
