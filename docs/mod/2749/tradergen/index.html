TraderGen - Custom Trader Framework

TraderGen is a server-side framework for SPTarkov that lets anyone create custom traders using simple JSON files, no programming required.

What It Does

  • Loads trader packs from user/mods/TraderGen/traders/
  • Registers traders, assort items, loyalty levels, and custom quests automatically
  • Supports story quests with multiple objectives (kill, handover, survive/extract)
  • Handles all image routing and locale registration internally

Web Tool

Create trader packs visually with the TraderGen Tool — fill in forms, upload images, and export a ready-to-use zip.

Installation

  1. Drag the SPT folder from the mod archive into your SPT installation directory.
  2. Start the server. TraderGen loads automatically and waits for trader packs.

Making a Trader Pack

  1. Open the TraderGen Tool.
  2. Fill in trader details, loyalty levels, items, and optional quests.
  3. Click Export to download a zip.
  4. Drag the SPT folder into your SPT install to test (ALWAYS use a new temporary profile when testing).

Do not rename any files or images after exporting. The mod references them by their generated names (e.g., avatar.jpg, tpl_*.jpg) - renaming will break the pack.

In-Game Export Feature

This allows you to export weapon builds, as well as armour, rig setups, and even containers with items in them and import them into the web app to add to your trader, making the process far easier.

Read about it here.

Publishing a Trader Pack

The TraderGen Tool export zip is already structured for distribution — users just drag the SPT folder into their install directory.

When publishing:

  1. State the dependencies: Your add-on requires com.serenity.tradergen v2.0.3+ and com.wtt.commonlib v2.0.20+ (WTT - CommonLib)
  2. Do not include the TraderGen/WTT-CommonLib DLL or other authors’ packs in your zip
  3. Include your assets: Ensure assets/avatar.jpg and any quest icons are present — do not rename them, the mod references them by their generated names

Dependencies

  • SPTarkov 4.0.13
  • WTT - CommonLib 2.0.20+
