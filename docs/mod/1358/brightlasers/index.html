Description Versions 5

I only created this because both prior mods that updated laser level are outdated, and I wanted to learn how to do bundles.

Installation
  1. Download BrightLasers
  2. Open the downloaded zip file
  3. Select the SPT folder in the zip file
  4. Drag the SPT folder from zip into your root SPT folder

Demonstration Video (yoink):

UNINSTALLATION
  1. Delete /ROOTSPT/SPT/user/mods/acidphantasm-brightlasers
  2. Done
