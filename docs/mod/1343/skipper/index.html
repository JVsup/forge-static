Skipper

A small client mod for conveniently skipping quests

Terkoiz acidphantasm
Downloads
299,757
Favourites
203
Mod lists
290
Description Versions 3

Simply adds a “Skip” button next to quest conditions in the trader quest screens, letting you easily autocomplete any task.

The default hotkey to make the Skip buttons appear is Left Control!
(you need to hold the button down)

The binding can be changed in the F12 menu.

Huge thanks to Amands2Mello for the awesome mod icon

Big thanks to Hazel for compiling the 3.9 and 3.10 releases of this mod

Known issues:

  • Toggling the mod via configuration manager requires you to navigate away and back to the quest task screen for changes to apply
  • Quest condition completion status isn’t saved to profile for now. Please only autocomplete conditions when you’re ready to actually complete the quest, otherwise the skipped conditions will reset to previous values after a raid or game restart!

Self-control not included
