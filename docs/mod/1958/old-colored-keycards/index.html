Old Colored Keycards

Changes colored keycards back to their infinite use state and returns their high flea pricing. Can also be customised to make them a certain limited amount of uses you decide.

IMPORTANT - If you use LiveFleaPrices and intend to use the (default) setting of updating the prices of the keycards to the old Flea values, please read below. If you do not do what is documented, it will NOT update the prices.

With this mod you are able to change the amount of uses a colored labs keycard has and also change the Flea Market value of it to that of pre 0.15. By default, the keycards will be unlimited use and cost a lot more to purchase on the flea, see the full values below.

CONFIGURATION

Inside the mod folder you will find a config folder followed by config.json. In here you can change two fields.

customUses -> (Int eg 40): Change the amount of max uses you want your keycards to have. Note that setting it to infinite negates this.

infiniteUse -> (Bool eg true) [Enabled by default]: If you wish to make your keycards infinite (or not) set this to true or false depending. As this mod focuses on reverting this change, this is enabled by default

updatePrices -> (Bool eg true) [Enabled by default]: True will replace the existing keycard prices with ones from July-August 2024 (end of 0.14 wipe, just before keycard value was nuked and limit on use was implemented in 0.15)

Current base prices are:

TerraGroup Labs keycard (Blue): ₽6,100,000

TerraGroup Labs keycard (Red): ₽11,300,000

TerraGroup Labs keycard (Green): ₽11,500,000

TerraGroup Labs keycard (Black): ₽1,650,000

TerraGroup Labs keycard (Violet): ₽4,000,000

TerraGroup Labs keycard (Yellow): ₽2,300,000

IMPORTANT IF YOU USE LIVEFLEAPRICES & OLDCOLOREDKEYCARDS UPDATED KEYCARD PRICES

You must change your config\blacklist.json in LiveFleaPrices to include the keycard IDs. Basically, if you don’t blacklist anything, it should look like:

[ “5c1d0c5f86f7744bb2683cf0”, “5c1d0efb86f7744baf2e7b7b”, “5c1d0dc586f7744baf2e7b79”, “5c1d0f4986f7744bb01837fa”, “5c1e495a86f7743109743dfb”, “5c1d0d6d86f7744bb2683e1f” ]
