Overview

Collection of most of saintdeer’s mod posted.

Included Weapons:

  • 🔹 QBZ-191 5.8x42 Assualt Rifle
  • 🔹 MCX Virtus 5.56x45/.300blk Assualt Rifles
  • 🔹 Mk47 Dissent 7.62x39 Assualt Rifle

All sound bundles have been rebuilt to fix the issue where gunfire sounds did not change according to the environment (indoor/outdoor)

Installation

Decompress and put the folder SPT under [Your EFT Directory]/

Notice

  • If you installed MassivesoftTrader, things this mod added will show up in the new Trader’s page.

  • To disable a certain component, remove the coresponding folder under SaintDeerWeapons/subs/

  • Theoretically compatible with Fika and WTT-armory. Not fully tested. No guarantee.
