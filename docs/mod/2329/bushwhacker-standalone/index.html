BushWhacker - Standalone

Disables the slowdown effect of bushes and swamps

Description Versions 2

Have you ever been running from a squad only to run right into a bush and die because you couldn’t sprint through it? Then this mod is for you. BushWhacker disables all bush and swamp slowdown effects, allowing you to sprint through them as if they don’t exist.

This mod has been made standalone and is distributed with permission from the original author.
