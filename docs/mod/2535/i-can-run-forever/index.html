Description Versions 1

A lightweight client-side plugin for Single Player THE CITY that provides the player with infinite stamina.

Key Features

  • Infinite Sprint: Leg stamina remains at 100%.
  • Player-Only: The logic specifically targets the local player, meaning AI Scavs and PMCs will still tire and breathe heavily as usual.
  • Live Toggle: Enable or disable the mod instantly during a raid using the BepInEx Configuration Menu (F12).
