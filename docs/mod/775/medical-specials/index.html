Description Versions 1

This is my very first mod, so if there are errors please let me know. Open to feedback, both positive and negative.

I created this mod to make all healing/injector items fit into special slots. I loved the mod “Special Slots” by jbs4bmx. But it felt too much like cheating as I could carry 4 backpacks, rigs, armors, etc. Never-the-less the mod is inspired by him so go check his version out too. Jbs4bmx - Special Slots. I use this mod with Realism so being able to store meds in your special slots (as well as an injector case) made more sense to me. Keeps me honest lol I hope all others enjoy as well. I have updated this mod to also be compatible with GoblinKing meds and the Medical SICC (MICC) Case.

I run this mod with 35 other mods so it SHOULD in theory be compatible with every mod EXCEPT those that also change special slot parameters.

P.s. just got note this still works with 3.7.2. I haven’t had any time to update the client version so you may have to change that for it to not show as outdated.
