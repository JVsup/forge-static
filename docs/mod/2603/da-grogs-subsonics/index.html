Description Versions 4

This mod adds clones of base ammo with altered stats to provide subsonic velocities with end game tier penetration. The reasoning is because SAIN does actually provide an option on hearing range based on suppressor usage and suppressor + subsonic usage, or maybe you just want to be more accurate in your kit and it bothers you that all most base subsonic offerings in this game are low tier ammos.

YOU NEED TO HAVE WTT-COMMONLIB 2.0.15 or NEWER FOR THIS MOD TO WORK

NO NEW MODELS ADDED, all ammo is top tier or near top tier for their caliber platform:

Please note any incompatibilities but install at your own risk, I try to fix errors as reported and when I find them but I am limited in skill and time. Appreciate the understanding.

Install = Download .7z file, extract to your maile SPT directory Uninstall = Start SPT, delete all ammo from mod in your inventory, then Follow Path in directory SPT>user>mods> then DELETE DaGrogsSubsonics folder. Done.
