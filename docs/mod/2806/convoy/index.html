Check out Quartermaster!

the client-side companion app for the Quartermaster control panel.

Features

Currently only syncs client mods from the server to the client.

How it works

  1. Fetches the mod catalog from your Quartermaster server (with ETag caching)
  2. Diffs against local state to determine what needs to be installed, updated, or removed
  3. Downloads changed mods as a batch ZIP, extracts, and verifies SHA-256 hashes
  4. Prompts for a restart if any BepInEx plugin files changed (they’re already loaded by the time Convoy runs)

Planned Features

  • optional mod groups
  • per-user mods that are managed and updated by the server, then pushed to the user
  • server-authorative mod configs
  • client setting backup (keybinds, graphics settings, etc.

Feel free to open an issue on github for any bugs or feature requests!
