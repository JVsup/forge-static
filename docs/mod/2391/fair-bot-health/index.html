Fair Bot Health

Boss HP is stupid. Make them hurt again.

Description Versions 3

Bosses, raiders, etc. have way too much health. This mod sets the health values of all bots that have higher HP than the player to the player’s values (including an optional multiplier).

Version

1.0.1

23 October 2025
SPT ~4.0.0 Fika: unknown 165 downloads9.8 KB

Added config support. You can now set the multiplier used for bot health. The default config uses a 1x multiplier and the behaviour will be the same as version 1.0.0

  • Example 1

    • Player Stomach = 70HP
    • Boss Stomach = 200HP
    • Multiplier = 2.0
    • Boss Stomach after mod ajustments = 140HP (70 x 2)

  • Example 2

    • Player Stomach = 70HP
    • Boss Stomach = 200HP
    • Multiplier = 0.5
    • Boss Stomach after mod ajustments = 35HP (70 x 0.5)

  • Example 3

    • Player Stomach = 70HP
    • Random bot Stomach = 60HP
    • Multiplier = 1.0
    • Boss Stomach after mod ajustments = 60HP (unchanged because it is lower than Player Stomach * multiplier)
