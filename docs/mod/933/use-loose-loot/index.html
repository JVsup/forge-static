Use Loose Loot

Use meds and food direct from the world instead of only your pockets. ;)

gaylatea DrakiaXYZ

Description Versions 7

Are you tired of having to drag that Alyonka into your inventory in order to taste its chocolatey delight? Are you tired of bleeding out because you have to shuffle your pockets to fit that Car medkit you just found? Look no further, friend, than this mod.

Food items will be entirely eaten with the “Use” prompt; meds will be used as if you had done so from your inventory screen. If med resources are left after usage, the loose item will remain where it is so you can use it again.

Install Instructions

1) Open the downloaded zip file in 7-zip

2) Select the folders in the zip file in 7-zip

3) Drag the selected folders from 7-zip into your SPT folder
