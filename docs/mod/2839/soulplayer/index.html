SoulPlayer

Development discontinued

SoulPlayer will remain available in its current form for SPT 4.0.13, but active development and support have ended.

There will not be an SPT 4.1 version or additional compatibility updates.

Thank you to everyone who downloaded SoulPlayer, shared feedback, reported issues, or supported the project.

SoulPlayer is an in-game local music player for SPT 4.0.13.

It adds a THE CITY-styled music library and persistent mini-player to the out-of-raid menus, allowing you to listen to music stored on your own computer without leaving the game.

SoulPlayer does not stream, upload, modify, or redistribute your music. Everything remains local on your computer.

Important: SoulPlayer 0.7.0 is built and tested for SPT 4.0.13.
It is not compatible with SPT 4.1.
Do not install older SoulPlayer releases made for SPT 3.9.8.

Features

  • Plays local MP3, FLAC, OGG, and WAV files.
  • Recursively scans one or more music folders.
  • Adds a persistent mini-player across the out-of-raid menus.
  • Includes a full music-library interface.
  • Search tracks, artists, and albums.
  • Add or remove music folders directly in-game.
  • Shuffle, repeat, seek, and volume controls.
  • Dedicated keyboard Play/Pause, Stop, Next, and Previous media-key support.
  • Optional additional hotkeys through the BepInEx configuration menu.
  • Keeps music playing while matching and loading into a raid.
  • Fades music when deployment begins.
  • Suspends hidden SoulPlayer interface work during raids.
  • Supports separate playlists for survived and failed raids.
  • Optional post-raid autoplay.
  • Preserves your configuration when reinstalling the same version.

Installation

  1. Download SoulPlayer-v0.7.0.zip.
  2. Close Escape from THE CITY, the SPT Launcher, and the SPT Server.
  3. Extract the ZIP directly into your SPT installation folder.
  4. Confirm the final plugin path is:

<SPT>/BepInEx/plugins/SoulPlayer/Soulplayer.dll

The following files must be together:

  • Soulplayer.dll
  • NAudio.Core.dll
  • NAudio.Flac.dll

Start the SPT Server and Launcher normally.

A successful startup should add this message to BepInEx/LogOutput.log:

SoulPlayer 0.7.0 loaded. Library scan started.

Using SoulPlayer

  1. Start SPT and enter the main menu.
  2. Select MUSIC from the bottom toolbar.
  3. Select ADD MUSIC FOLDER.
  4. Choose a folder containing your music.
  5. Wait for the background library scan to finish.
  6. Select a track or press Play to shuffle your library.

The compact mini-player remains available throughout the out-of-raid interface.

It hides when a real raid begins and returns after the raid.

Raid music

Open RAID MUSIC inside the SoulPlayer window to configure separate folders for:

  • Survived raids
  • Failed raids

Enable AUTOPLAY to automatically begin an outcome-specific track when the post-raid results screen appears.

Configuration

Press F1 to open the BepInEx configuration interface, then select SoulPlayer.

Available settings include:

  • Music folders
  • Volume
  • Shuffle
  • Repeat mode
  • Mini-player visibility
  • Media-key support
  • Post-raid autoplay
  • Raid fade-out duration
  • Post-raid track fade duration

Music folder management and the main playback settings are also available directly inside the SoulPlayer interface.

Reinstalling

No additional SoulPlayer updates are planned.

To reinstall version 0.7.0, close SPT and extract the release over the existing SoulPlayer files.

Your configuration is stored at:

<SPT>/BepInEx/config/com.kelorein.soulplayer.cfg

Reinstalling the plugin does not normally remove your settings.

Uninstalling

Close SPT and remove:

<SPT>/BepInEx/plugins/SoulPlayer

Optionally remove the following file to erase all saved settings:

<SPT>/BepInEx/config/com.kelorein.soulplayer.cfg

Troubleshooting

The MUSIC button or interface is missing

Confirm that these files are together:

  • Soulplayer.dll
  • NAudio.Core.dll
  • NAudio.Flac.dll

Also confirm that you installed SoulPlayer 0.7.0 for SPT 4.0.13.

Check BepInEx/LogOutput.log for dependency, plugin-loading, or Harmony patch errors.

No music appears

  • Confirm the selected folder exists.
  • Confirm it contains MP3, FLAC, OGG, or WAV files.
  • Wait for the background scan to finish.
  • Remove and add the folder again.
  • Select RESCAN LIBRARY.
  • Check BepInEx/LogOutput.log for SoulPlayer messages.

The mini-player is missing

Open SoulPlayer or the BepInEx configuration menu and confirm that Show mini player is enabled.

Two soundtracks play together

SoulPlayer and THE CITY’s built-in menu music are separate.

Set THE CITY’s in-game Music volume to 0 if you only want to hear SoulPlayer.
