Can you not help but rage Alt+F4 any time you get smacked in the face by Tagilla? Hate yourself for all the cheese you consume any time you die?

Well cheese no more, with NoCheese, the simple and effective solution to your cheesing problems.

What’s it do?

NoCheese enables SPT’s built in anti-cheesing functionality, essentially wiping your profile on raid start, and restoring it on successful raid end. This means if you alt+f4, you no longer complete the raid, and your character loses all of their equipped items.

This functionality is behaviorally identical to what I was doing in older versions of NoCheese, just in a more simplistic manner.

What if I crash though?

This is the downside to stopping yourself from cheesing, because SPT is offline, there is no server to reconnect to. In the event you crash, it will be treated the same as if you hit alt+f4, and you will lose what you went into the raid with.

In dire situations (Such as those caused by consuming cheese while lactose intolerant), you can still alt+f4 and then restore a backup of your profile from the SPT/user/profiles/backups/ folder, so you can then go suffer the consequences of your cheese ingestion

Installation

1) Open the downloaded zip file in 7-zip

2) Select the folder in the zip file in 7-zip

3) Drag the selected folder from 7-zip into your SPT folder
