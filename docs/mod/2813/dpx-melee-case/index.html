DPX Melee Case

DPX Melee Case adds a custom storage container dedicated exclusively to melee weapons.

Features

  • Custom 3D model and AssetBundle
  • Custom inventory icon
  • Stores melee weapons only
  • External size: 4x2
  • Internal storage grid: 8x8
  • Available from Jaeger LL1
  • Default price: 250,000₽
  • Default stock: 999
  • Fully configurable through config.json

Configuration

The following options can be changed:

  • Enable or disable the mod
  • Trader
  • Loyalty level
  • Price
  • Stock quantity
  • External case size
  • Internal storage size
  • Debug logging

Installation

Extract the archive directly into your SPT installation folder.

The archive contains both the required server mod and BepInEx client plugin.

Compatibility

  • SPT 4.0.13
  • EFT 0.16.9.40087

Feedback and Bug Reports

If you encounter any bugs, errors, compatibility issues, or unexpected behavior, please report them in the comments section.

When possible, include:

  • A clear description of the issue
  • The steps needed to reproduce it
  • Your SPT version
  • Your server logs
  • Your BepInEx logs

Known issues and useful feedback are always welcome and help improve future versions of the mod.

DPX Melee Case v1.0.5

Fixed

  • Rebuilt the custom prefab using the native EFT Weapon Case rendering structure.
  • Fixed the inventory icon remaining stuck in an infinite loading state.
  • Restored native 3D icon generation for the inventory and trader screens.
  • Replaced the incorrect generic shader with the native opaque EFT shader.
  • Fixed the washed-out, overly bright and partially transparent appearance.
  • Fixed flickering in trader and preview interfaces.
  • Removed the obsolete DPX-MeleeCaseIconFix BepInEx plugin.
  • Removed the embedded Sprite and PreviewPivot.overrideIcon workaround.

Important update note

EFT/SPT stores generated inventory icons in a persistent cache. After updating from an older version, the previous bright or white icon may remain temporarily.

Restart the client first. If the old icon remains, the specific cached icon entry may need to be regenerated.

Do not reinstall the old DPX-MeleeCaseIconFix plugin.

Unchanged

  • External size: 4x2
  • Internal grid: 8x8
  • Melee weapon filter
  • Trader offers and prices
  • Existing gameplay balance
