Player Boss Scav

Standalone component from APBS. Allows your scav to generate as a boss with a configurable chance.

Description Versions 2

THIS IS NOT COMPATIBLE WITH APBS

This feature is already in APBS.

Default chance is 5%

Player Scav can be any of these bosses:

  • bossBoar
  • bossBully
  • bossGluhar
  • bossKilla
  • bossKillaAgro
  • bossKnight
  • bossKojaniy
  • bossKolontay
  • bossPartisan
  • bossSanitar
  • bossTagilla
  • bossTagillaAgro
  • bossZryachiy
  • followerBigPipe
  • followerBirdEye
  • sectantPriest

Bosses can be removed from the list via the Config.

Please copy and paste, if you don’t then it’s not going to remove it.

INSTALLATION

Installation

  1. Download Player Boss Scav
  2. Open the downloaded 7z file in 7-zip
  3. Select the SPT folder in the 7z file in 7-zip
  4. Drag the SPT folder from 7-zip into your root SPT folder

Demonstration Video (yoink):

UNINSTALLATION
  1. Delete /ROOTSPT/SPT/user/mods/acidphantasm-playerbossscav
  2. Done
