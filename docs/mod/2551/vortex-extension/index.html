Description Versions 1

This is vortex extension allowing you to manage mods in a modern way. Just add game in vortex, drag & drop your downloaded mod archives and you’re ready to go.

Installation:

Open Vortex. Go to Extensions tab. Drag & drop downloaded archive of extension into the Drag & Drop area. Install extension. Restart Vortex. Go to Games tab. Search for SPT. Click on manage in found SPT extension. Select folder with SPT, click Next until you have added managed game.

How to install mods:

Select game you added and drag & drop downloaded mods archives into drag & drop area below.
