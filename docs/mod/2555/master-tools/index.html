Master Tools - Features Guide

Please read the version tab to learn more about the updates.

To install, simply extract the “master.dll” file to “SPT\BepInEx\plugins”

⌨️ Controls

• INSERT: Open/Close the Mod Menu.

• NumpadKeys

🛡️ General Cheats

• GodMode: Makes your character immune to all forms of damage. You will not take damage from bullets, falls, or explosions.

• Infinite Stamina: Keeps your Leg Stamina, Arm Stamina (Aiming), and Oxygen levels at 100% at all times.

• No Weight Penalties: Removes movement speed and stamina drain penalties caused by carrying heavy gear or loot.

• Unlock All Doors: A powerful utility that instantly unlocks every locked door and container on the map during a raid. No keys required.

👥 Player ESP

Visualizes all players and bots through walls with the following features:

• Faction Identification: Different colors for BEAR, USEC, Bosses and Savages (Scavs/Raiders).

• Distance Tracking: Shows the exact distance in meters to each target.

• Customizable Colors: Full RGB sliders to change faction colors in real-time.

• Performance Control: Adjustable Update Rate (FPS) slider to balance between smooth visuals and CPU performance.

• Distance Filter: Set a maximum range to avoid screen clutter.

📦 Item & Container ESP

Advanced loot tracking system optimized for high performance:

• Loose Item ESP: Shows items lying on the ground.

• Container Item ESP: Shows items hidden inside crates, jackets, safes, and dead bodies.

• Multi-Filter System: Search for specific items by entering names or IDs. Supports comma-separated lists (e.g., LedX, GPU, Salewa).

• Optimized Performance: Uses a smart caching system for containers and squared-distance calculations to ensure zero FPS drops even on loot-heavy maps.

• Update Rate (FPS): Independent refresh rate control for loot visuals.

⚙️ Technical Details

• Optimization:

  • Features a container caching system that refreshes every 10 seconds to maintain high frame rates.

  • Culling provides a small performance boost by disabling meshes at distance. ⚠️ However, this may cause bots to appear instantly once they enter the configured range.

• Config file on -> “SPT\BepInEx\config\com.master.tools.cfg”

Patch Notes — UI Tabs Update

This update introduces a new Tab-based menu layout, splitting the mod features into organized sections for easier navigation and configuration.

General Tab

  • God Mode

    • You take no damage while enabled.
    • Disable it to receive damage again.

  • Infinite Stamina

    • Stamina no longer decreases while running or aiming.
    • Breath stamina stays full.

  • No Weight Penalties

    • Removes armor and weight-related movement penalties.
    • Prevents weight effects from slowing you down.

  • Show Status Window

    • Displays a status panel showing which features are enabled/disabled.

  • Show Weapon Info in Status

    • Shows your current weapon and magazine ammo count in the Status Window.
    • Requires Status Window enabled.

  • Unlock All Doors in Raid

    • Unlocks all doors during the raid.

  • Enable Bot Distance Culling

    • Disables bot-related rendering/AI elements at distance to improve FPS.
    • This can significantly increase performance, but please report any bugs or unusual behavior.

Player ESP Tab

  • Enable Player ESP (Text)

    • Shows player/bot information as text:
      • Name, faction, and distance
    • You can now customize:
      • Font size
      • Text transparency

  • Chams (NEW)

    • Highlights bots through walls using a chams-style effect.
    • Note: this feature may temporarily affect some textures/materials.
    • Colors are intentionally strong for better visibility.
    • Still needs improvements and fixes.

Item ESP Tab

  • Same as the previous update.
  • Container cache refresh time is now set to 5 minutes (improves stability and performance).

Visual Tab

  • Thermal Vision

    • Full-screen thermal vision mode.

  • Night Vision

    • Full-screen night vision mode.

  • Teleport Filtered Items to Me (NEW)

    • When Item ESP filters are enabled, this button teleports loose items to your location.
    • Container items will NOT teleport (only items already outside containers).
    • Recommendation: enable God Mode, because teleporting many items at once may cause damage in some situations.
    • I’m working on fixes and improvements for this feature.

Troll Tab

  • SpeedHack

    • Increases movement speed heavily.
    • Warning: you can glitch/fly depending on speed values.
    • Recommended: enable God Mode while testing.

  • Teleport All Enemies to Me

    • Teleports enemies within range (up to ~3m) to a position in front of you.
    • Warning: using this without God Mode can get you killed instantly.

  • Big Head Mode

    • Multiplies bot head size.
    • The most fun feature in the mod.

Configs Tab

  • Configuration keybinds
