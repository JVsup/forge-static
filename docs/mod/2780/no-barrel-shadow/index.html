Description

Removes the distracting barrel shadow that flashlights and other weapon Light attachments cast onto nearby surfaces.

Also Adjust brightness and intensity of each individual flashlight via the sliders in F12.

Install Instructions
  1. Extract the archive
  2. Drop the BepInEx folder into your SPT root directory
  3. Launch the game — no configuration needed, works automatically
Known Limitations / Bugs

  • On the MP7A1 and MP7A2, switching your flashlight to a different rail mid-raid will cause the shadow to reappear. Toggle the light off and back on once to fix it immediately.

  • There’s Now an API for other mod authors to create addons for their custom flashlights they make, so if you have modded lights and they don’t make an addon then you won’t be able to adjust your light, but it’ll retain its default values.
