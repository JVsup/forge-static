Ref - SPT Friendly Quests

Converted all the Arena specific quests for Ref into SPT quests. Rewards the same things as Live, with an added Lega Medal to each quest. Includes the sword unlock and secure container.

This mod displayed a profile-binding notice on Forge.
Description Versions 10

SPT 3.9.5 added these quests but they are for Arena, so when you unlock these you will also unlock the Arena versions. There is not a quick fix for this without potentially breaking profiles - use the mod Skipper for the time being to skip the Arena versions.

INSTALLATION

Installation

  1. Download Ref - SPT Friendly Quests
  2. Open the downloaded 7z file in 7-zip
  3. Select the SPT folder in the 7z file in 7-zip
  4. Drag the SPT folder from 7-zip into your root SPT folder

Demonstration Video (yoink):

UNINSTALLATION

NOTE: Deletion may not be possible because this mod adds quests. You may need to start a new profile. If you insist on removing it, you can do the following.

  1. Delete /ROOTSPT/SPT/user/mods/acidphantasm-reffriendlyquests
  2. Done
