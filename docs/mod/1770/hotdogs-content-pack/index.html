Description Versions 2

This mod (as of writing) includes seven new items. The items added are all retextures of previously existing items.

What’s new?

  1. Stanag mag covered in dog stickers - HotDoggoMag
  2. MUR-1S upper that says “EAT SHIT” on the dust cover - Spicy Mur1S
  3. A custom Saker suppressor with a picture of a leaping cat on the end - Leaping Floof!!!
  4. An RVG foregrip with a selfie of a PMC wearing a respirator with no filters - RVG Respirator
  5. A VHS tape containing a movie that never came to be… except for the music… that’s on Spotify!
  6. A modified REAP-IR
  7. A modified Vortex Razor HD Gen.2

Images (not all items are shown)

Installation

  1. Click “Download”
  2. Open the zipped file
  3. Open “Hotdog-Content-(version number)”
  4. Drag “Hotdogs Content” into your USER/MODS folder

This will be fixed to have the “user/mods” folders in the download for easier installation with the next update (if I remember).
