Compatibility update of Adjustable Trader Rows for SPT 4.x.

Original mod by JustNU. Ive made this for myself as I have 42 traders in my game, I though the community might enjoy it awell.

This is a small client-side BepInEx/Harmony UI plugin that changes the number of trader cards displayed per row.

You can configure with f12 the number of traders per row that you want, on the picture it is set to 9.

100% Compatible with Kaeno-TraderScrolling mod
