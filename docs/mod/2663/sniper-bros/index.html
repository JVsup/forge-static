Sniper Bros

Sniper Scavs are bros to all bots.

Shibdib

Description Versions 4

This mod is simple. It makes Marksman/Sniper scavs non-hostile to other AI bots. Why? Because the AI bots would annoyingly get stuck staring at ceilings trying to find them before.

Why not just not spawn in marksman you ask? Because how would you do those annoying tasks that require kills for them.

Install:

Extract the mod into the main folder of your game install.

FIKA/Headless:

This mod only needs to be on the host. So if you use a headless it only needs to be there.

Compatibility:

Should work with everything.

How’s it work?

On bot spawn in it’ll add bots to the allies list of marksman and vice versa.
