Description

Original Mod by SamSWAT

A BepInEx mod that adds Insurgency-style fire support options into Escape From THE CITY. Currently there is an A-10 autocannon strafe and a Black Hawk helicopter extraction available.

How it works

  1. Have the ingame rangefinder in your inventory before loading into a raid
  2. Load into a raid, and equip the rangefinder
  3. Open the gestures menu (default input: double tap Y key)
  4. Select a support option in the radial menu
  5. Point at a location and click LMB to confirm
  6. For A-10 strafe, you will need to confirm the direction, which can be done by moving the mouse left or right and confirming with LMB
  7. If you want to cancel the support request before you’ve confirmed it, press ALT + RMB, or equip a different weapon/item

Settings can be changed in the BepInEx configuration manager (F12 key).

Read full article on the Github page for more information:

https://github.com/ArysWasTaken/SamSWAT.FireSupport.ArysReloaded#readme

How to install

- HOW TO INSTALL

1. Download the .7z archive and unzip it

2. Drag and drop the two folders BepInEx and SPT into your game directory.

3. That is all
