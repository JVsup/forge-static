Overview

Tarkov has hundreds of quests. Even without mods, the quest list quickly becomes overwhelming — you don’t know what to prioritize, which weapon to bring, or which map to play.

MissionControl picks 3 random quests from the ones you’ve unlocked and hides the rest. Complete one, a new one appears from your unlocked pool. Stuck? Buy a reroll at Prapor to get fresh picks.

By default, only vanilla quests are filtered. Modded quests are always visible and don’t consume slots. You can change this in the config.

Key features:

  • Only 3 quests visible at a time, randomly picked from your unlocked quests
  • Complete a quest → a new random one appears instantly
  • Reroll at Prapor — buy the Mission Reroll item to get 3 fresh picks. Stuck quests stay visible but stop consuming slots
  • Trader whitelist — some traders’ quests are always visible (configurable by name)
  • Per-profile persistence across server restarts
  • Safe for existing profiles — remove the mod and all quests come back

The client plugin handles quest list refresh after completing a quest and after purchasing a reroll.

Configuration

Edit SPT/user/mods/MissionControl/config/config.jsonc:

Setting Default What it does
max_slots 3 How many quests you see at once (in-progress + available)
filter_modded_quests false Only vanilla quests are filtered. Set to true to also filter modded quests
trader_whitelist ["Kolya", "Guiding Light"] These traders’ quests are always visible (case-insensitive, works with modded traders)
reroll_cost 50000 Rouble price for the Mission Reroll item at Prapor
debug false Verbose server logging
debug_refresh false Clear all saved selections on server start (dev only)

If a trader name in the whitelist is not found, the server log will list all available trader names.

Reroll

Buy the “Mission Reroll” item at Prapor (Loyalty Level 1, 50,000₽ by default).

What happens:

  1. Your current in-progress quests become exempt — they stay visible but stop counting toward the slot limit
  2. 3 fresh random quests are picked from your unlocked pool
  3. The game reloads your profile automatically

Why? If you’re stuck on 3 difficult quests and can’t progress, the reroll lets you get new ones without abandoning the old ones. You temporarily have more than 3 active quests until you finish the old ones.

How It Works

Install → play. That’s it.

From all the quests you’ve unlocked (met the level/prerequisite requirements), MissionControl randomly picks a few and hides the rest. The selection is persistent — you see the same quests until you complete them or buy a reroll.

Quest slots:

  • You have 3 slots (configurable). In-progress and available quests both count
  • 0 quests accepted → 3 random available quests shown
  • 1 quest accepted → 2 random available quests shown
  • 3 quests accepted → no new quests shown until you complete some
  • Complete a quest → a new random one fills the slot immediately
  • Failed quests stay in their slot (restart from the UI)

After a reroll:

  • Old in-progress quests stop counting toward slots (they’re “exempt”)
  • 3 new quests fill your slots
  • Finishing an exempt quest → it disappears, no new slot opens
  • Finishing a new quest → a fresh random one takes its place

Modded quests (default behavior):

  • Modded quests are always visible and never consume slots
  • Only vanilla quests are subject to the slot limit
  • Change this with filter_modded_quests: true

Nothing is permanent. Remove the mod and all quests return to normal. Safe for existing profiles.

Compatibility
  • SPT 4.0.x
  • Works with any quest mod — modded quests are detected automatically
  • Works with custom traders — whitelist by name
  • Safe for existing profiles — if you have more quests accepted than max_slots, no new quests are shown until you drop below the limit

MissionControl v1.0.0 — Focus your quests

Too many quests? MissionControl limits your quest list to just 3 quests at a time, randomly picked from the ones you’ve already unlocked. Complete one, a new one appears. Simple.

By default, only vanilla quests are filtered. Modded quests remain fully visible.

How it works

  • From all the quests you’ve unlocked, only 3 are shown at a time (configurable)
  • Complete a quest → a new random one is picked from your remaining unlocked quests
  • Accepted quests count toward the limit — if you have 3 active, no new ones appear until you finish some
  • Failed quests stay in their slot so you can restart them

Reroll

Stuck on difficult quests? Buy the Mission Reroll item at Prapor (50,000₽ by default).

  • Your current in-progress quests stay visible but stop counting toward the slot limit
  • 3 fresh random quests are picked from your unlocked quests
  • Once you finish the old ones, you’re back to the normal 3-slot flow

Edit SPT/user/mods/MissionControl/config/config.jsonc to customize.
