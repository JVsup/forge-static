FoldThatStock 1.0.0 (SPT 4.0.13)

FoldThatStock adds working fold behavior to supported non-vanilla folding stock setups.

This 1.0.0 release expands the supported stock list and adds AK-platform folding support. Player folding animation is not implemented yet, and some vanilla stocks that are foldable in real life are still outside the supported list.

Features
  • Adds foldable behavior to supported weapons and stock setups
  • Supports the current FoldThatStock custom stock bundle set
  • Uses server-side template patching for foldable behavior and folded inventory size
  • Uses client-side bundle overrides for supported stock visuals
Featured Stocks
  • SIG Sauer Thin Side-Folding Stock
  • SIG folding knuckle
  • PMM ULSS stock
  • SIG telescoping stock
  • SIG MPX/MCX early type stock
  • SIG MPX brace
  • SIG stock locking hinge assembly
  • UTG SFS AK adapter
  • Magpul Zhukov-S AK stock
Featured Weapons
  • SIG MCX .300 Blackout
  • SIG MPX 9x19
  • AK-74N 5.45x39 with ME4 buffer tube adapter
  • AK-74 5.45x39 with ME4 buffer tube adapter
  • AKM 7.62x39 with ME4 buffer tube adapter
  • AKMN 7.62x39 with ME4 buffer tube adapter
  • VPO-136 Vepr-KM 7.62x39 with ME4 buffer tube adapter
  • VPO-209 .366 TKM with ME4 buffer tube adapter
  • RD-704 7.62x39 with ME4 buffer tube adapter
Notes
  • Player fold/unfold animation is not implemented yet
  • Some vanilla stocks that should logically be foldable are yet to be supported
  • Future updates will focus on additional supported stock bundles, visual polish, and animation work
Customization
  • Edit SPT/user/mods/FoldThatStock/config.json to customize server-side template patches
  • Set a weapon or stock patch Enabled value to false to stop that config entry from being applied
  • Restart SPT Server after changing config.json
  • Bundle files in BepInEx/plugins/FoldThatStock only control client-side visual overrides; removing a bundle can help disable or test a visual replacement, but it does not edit server-side behavior
Installation
  1. Download the release file
  2. Extract it directly into your SPT installation folder
  3. If Windows asks about existing files while updating, choose to replace all files
  4. Start the game
  5. Restart server after changing weapon category settings
Updating
  • Updating is the same as installing: extract the new release into your SPT installation folder and replace all existing files
  • The release includes the current SPT/user/mods/FoldThatStock/config.json; choosing replace all updates it
  • If you intentionally skip replacing that file, new default stock and weapon entries are not merged automatically
Uninstall

Delete:

  • SPT/user/mods/FoldThatStock
  • BepInEx/plugins/FoldThatStock

If you uninstall the mod, weapons already folded in your profile may keep their saved state until they are updated again by the game.

FoldThatStock 1.0.0

FoldThatStock 1.0.0 expands the supported folding stock list and moves the mod out of its initial soft-launch version range.

Highlights

  • Added support for the full current FoldThatStock stock set:
    • SIG Sauer Thin Side-Folding Stock
    • SIG folding knuckle
    • PMM ULSS stock
    • SIG telescoping stock
    • SIG MPX/MCX early type stock
    • SIG MPX brace
    • SIG stock locking hinge assembly
    • UTG SFS AK adapter
    • Magpul Zhukov-S AK stock
  • Added supported AK-platform weapon patches for ME4 buffer tube adapter setups:
    • AK-74N 5.45x39
    • AK-74 5.45x39
    • AKM 7.62x39
    • AKMN 7.62x39
    • VPO-136 Vepr-KM 7.62x39
    • VPO-209 .366 TKM
    • RD-704 7.62x39
  • Applies server-side template patches for foldable behavior, folded slot handling, folded inventory size, and supported stock fold compatibility.
  • Uses client-side visual handling and bundle overrides for supported stock visuals where custom bundles are included.

Notes

  • Built for SPT 4.0.13.
  • Player fold/unfold animation is not implemented yet.
  • Support is intentionally limited to the configured weapon and stock list.
  • Edit SPT/user/mods/FoldThatStock/config.json to customize server-side template patches. Bundle files in BepInEx/plugins/FoldThatStock only control client-side visual overrides.

Installation

Extract the release archive into your SPT installation folder, replace all existing files if Windows asks, then start SPT normally.

The release includes the current SPT/user/mods/FoldThatStock/config.json; choosing replace all updates it. If you intentionally skip replacing that file, new default stock and weapon entries are not merged automatically.
