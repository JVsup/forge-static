Overview

Installing quest mods (custom traders, quest overhauls, etc.) adds thousands of extra XP that breaks the vanilla progression curve. You level up too fast, outpacing your trader reputation — you have the level for LL3 gear but haven’t unlocked it yet.

FairProgression fixes this automatically. It runs after all mods have loaded, analyzes every quest in the database, and scales XP rewards so the progression curve matches vanilla — no matter how many quest mods you have installed.

Key features:

  • Detects vanilla vs modded quests automatically
  • Scales XP per bracket aligned with trader loyalty unlocks (LL2/LL3/LL4 phases)
  • Buffs under-rewarded quests where difficulty far exceeds the XP reward
  • Analyzes quest objectives (boss kills, map difficulty, restrictions, skills, etc.)
  • Detailed dashboard in server logs
  • Safe for existing profiles — only modifies rewards in memory
  • Works with any quest mod — no configuration needed
Installation

Extract the zip in your SPT root folder. Start the server. That’s it.

Configuration

Edit SPT/user/mods/FairProgression/config/config.jsonc:

  • mode — "scale_all" (default) reduces all quests proportionally. "scale_modded_only" only reduces modded quests.
  • level_brackets — "trader" (default) auto-computes from vanilla trader loyalty levels. Or use a JSON array like [5, 10, 20, 30, 40].
  • min_coefficient — 0.25 (default). Quest XP never drops below 25% of original.
  • buff_under_rewarded — true (default). Increase XP for quests where difficulty far exceeds the reward (capped at x2).
  • buff_gap_threshold — 5 (default). Minimum level gap between difficulty and XP to trigger a buff.
  • enable_dashboard — true (default). Print the rebalancing dashboard in server logs.
  • dry_run — false (default). Calculate and log everything but don’t modify any rewards.
  • verbose — false (default). Log every modded quest with difficulty scores, per-trader breakdown, and under-rewarded details.

How It Works

Install quest mods → FairProgression handles the rest.

When you add quest mods, the extra XP makes you level up too fast. You reach level 30 but your traders are still LL2 because you haven’t done enough vanilla quests to unlock them.

FairProgression solves this by:

  1. Detecting which quests come from mods and which are vanilla
  2. Estimating when you’ll realistically complete each quest based on its objectives, prerequisites, and reward
  3. Reducing XP from quests that would over-level you
  4. Boosting XP from quests that are harder than their reward suggests

The XP budget is split into phases matching vanilla trader unlock levels — so your level always stays in sync with what you can actually buy.

Example: You have 934 modded quests adding 24.6M extra XP. FairProgression scales this down to keep you on the vanilla curve, while buffing 185 quests that were under-rewarded for their difficulty.

Nothing changes on disk. All adjustments are in memory. Remove the mod and everything goes back to normal. Safe for existing profiles.

Compatibility
