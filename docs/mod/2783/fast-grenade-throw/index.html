Description

Brings back the classic instant grenade quick throw from earlier THE CITY patches. Press a key and your grenade flies — no equipping, no holding, no waiting.

Features

  • Instant overhand throw — one key press, grenade gone
  • Instant underhand throw — separate keybind for low trajectory tosses
  • Your normal grenade key is untouched — no conflicts with vanilla controls
  • Backpack, armband, and secure container support — finds grenades anywhere on you, not just your rig/pockets
  • Use Items Anywhere compatible — detects UIA and hooks into its slot system instead of conflicting with it

How it works

The mod uses the game’s built-in QuickGrenadeThrowHandsController — the same system Big Silly Goose originally built for fast throws. It automatically finds the highest-priority grenade you’re carrying and throws it instantly, then returns you to your previous weapon.

Install Instructions
  1. Extract the archive
  2. Drop the BepInEx folder into your SPT root directory
  3. Launch the game — default keybinds are G (overhand) and H (underhand), configurable via F12

⚠️ Recommendation: If your normal grenade keybind is also G, change one of them to avoid conflicts. Either rebind your vanilla grenade key in-game, or change the quick throw key in the F12 config menu.

Known Limitations / Bugs
  • Conflicts with Janky’s Visual Assist: its Grenade Arc feature overrides the real throw with its own predicted trajectory, which can be stale during a quick throw. Symptom: the grenade appears to vanish, then explodes far away instead of where thrown. Workaround: disable “Grenade Arc” in Janky’s Visual Assist’s F12 settings.
