Progression Tracker

My mod is a *great mod* that does per profile progression tracking. For some things. In a blazor page.

acidphantasm

Description Versions 4

Currently tracks:

  • Collector quest progression & item requirements
  • Hideout construction requirements

Enjoy.

Notes:

  • This works with vanilla SPT. If you are using a mod to change the item requirements for any of the tracked features then it maybe will work for you, but the images definitely won’t load for items that weren’t original requirements.
  • If it doesn’t work for you because you’re using a mod to change those requirements - I don’t care, I might fix it or I might not. Who knows!
INSTALLATION

Installation

  1. Download Progression Tracker
  2. Open the downloaded .7z file in 7-zip
  3. Select the SPT folder in the .7z file in 7-zip
  4. Drag the SPT folder from 7-zip into your SPT folder

Demonstration Video (yoink):

UNINSTALLATION
  1. Delete /ROOTSPT/SPT/user/mods/acidphantasm-progressiontracker
  2. Done
BLAZOR PAGE

Run the server and go to:

  • https://127.0.0.1:6969/progressiontracker/

If you are using Fika then put the appropriate IP and port instead.
