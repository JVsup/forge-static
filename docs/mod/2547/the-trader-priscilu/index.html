Priscilu Origins v2 is a server-side trader mod for SPT 4.0.11.

This mod adds a custom trader called Priscilu Origins with a custom avatar, a large custom assortment and several configurable systems.

Important: This mod is made for Single Player Tarkov only. It is not made for live Escape From Tarkov and must not be used with live EFT.

ABOUT THE MOD

Priscilu Origins v2 adds a custom trader to SPT.

The trader includes:

  • Custom trader profile
  • Custom trader avatar
  • Large custom assortment
  • Level-based unlock system
  • Optional unlock by default
  • Flea Market integration option
  • Unlimited stock option
  • Random out-of-stock option
  • Global price multiplier
  • Custom item price generation
  • Repair service
  • Insurance service
  • Optional debug logging

The mod is fully server-side and does not require any client-side files.

HOW TO INSTALL
  1. Backup your profile before updating or installing.
  2. Close the SPT server.
  3. Delete any previous version of the mod completely.
  4. Clear your caches if needed.
  5. Download the mod.
  6. Extract the ZIP.
  7. Copy the mod folder into your SPT user mods folder:

<SPT>/user/mods/Priscilu_Origins

For the packaged release ZIP, extract it into your SPT root folder so the final path looks like this:

SPT/user/mods/Priscilu_Origins_v2

  1. Start the SPT server.
  2. Check the server console for errors.
CONFIG

The main configuration file is:

config/settings.json

Current default settings:

Setting Default
MinLevel 5
UnlockedByDefault false
TraderRefreshMin 1800
TraderRefreshMax 3600
AddTraderToFleaMarket true
InsurancePriceCoef 50
RepairQuality 0.8
RandomizeStockAvailable false
OutOfStockChance 15
UnlimitedStock true
PriceMultiplier 1.0127
DebugLogging false

MinLevel Sets the player level required to unlock the trader.

UnlockedByDefault If enabled, the trader is unlocked immediately.

TraderRefreshMin / TraderRefreshMax Controls the random restock timer range in seconds.

AddTraderToFleaMarket Allows Priscilu Origins offers to appear on the Flea Market.

UnlimitedStock Makes trader offers effectively unlimited.

PriceMultiplier Applies a global multiplier to trader prices.

DebugLogging Enables extra logs for troubleshooting.

BUG REPORTING

When reporting a bug, please include:

  • Your SPT version
  • Your Priscilu Origins v2 version
  • A clear description of the issue
  • Your server console error, if available
  • Your debug.log, if debug logging was enabled
  • A list of other installed mods, if the issue may be related to compatibility

Please make sure you are using the correct SPT version before reporting issues.

KNOWN ISSUES

If the server logs show missing soft armor inserts, make sure the slot names in assort.json are written exactly as required.

Correct slot names:

  • Soft_armor_front
  • Soft_armor_back
  • Soft_armor_left
  • soft_armor_right

Slot names are case-sensitive.

If the mod does not load:

  1. Make sure you are using SPT 4.0.11.
  2. Make sure the mod folder is inside user/mods.
  3. Make sure the final folder contains the mod files directly.
  4. Check the SPT server console for errors.
  5. Enable DebugLogging in config/settings.json.
  6. Check debug.log inside the mod folder.

Fixes & Improvements

New Config

"MinLevel": 5, //[Level Requirement] The minimum level required to access the trader's level 1 loyalty.   
"UnlockedByDefault": false, //[Unlock] If true, the trader is unlocked immediately regardless of level.
"TraderRefreshMin": 1800, //[Restock Timer] Minimum and Maximum time (in seconds) for trader restock. 1800s = 30 min, 3600s = 60 min. The system picks a random time between these two.
"TraderRefreshMax": 3600,
"AddTraderToFleaMarket": true, //[Flea Market] If true, Priscilu's offers appear on the Flea Market search.
"InsurancePriceCoef": 50, // [Insurance] Price multiplier for insurance. 25 = 25%. Higher is more expensive.
"RepairQuality": 0.8, // [Repair] Quality of repairs (0.0 to 1.0). 0.8 is High Quality (loss accumulation is lower).
"RandomizeStockAvailable": false, //[Stock] If true, some items will randomly be out of stock each reset.
"OutOfStockChance": 15, //[Stock] The percentage chance (0-100) that an item is out of stock (if Randomize is true).
"UnlimitedStock": true, //[Stock] If true, all items have infinite stock. Overrides randomization. Note: Refilling issues are currently being patched by auto-clearing BuyRestrictions.    
"PriceMultiplier": 1.0127, //[Pricing] Global multiplier for all item prices. 1.0 = standard price. 1.0127 = +1.27%.    
"DebugLogging": false //[Debug] Enables detailed logs in the server console for troubleshooting.

Code Cleanup

  • Removed Inspector: Deleted unused Inspector/ tool from the project source.
  • Refactoring: Renamed TraderUnlockCallback.cs to TraderUnlockService.cs to properly reflect its class name and purpose.

Targeting SPT 4.0.11+
