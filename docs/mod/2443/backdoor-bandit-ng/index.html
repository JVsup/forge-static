An updated and overhauled version of RaiRaiTheRaichu’s Backdoor Bandit mod

Usage:

  • You need to add both WEAPONS and AMMO into the list in order for them to work.
  • WEAPONS go into various weaponList
  • AMMO go in whitelistedRounds list
  • blacklistedRooms will block all rounds.
  • C4 will breach ALL doors
