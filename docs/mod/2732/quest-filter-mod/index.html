Description Versions 5

A mod for sorting standard or modded quests, removing conditions, binding to a merchant, location, and randomizing.

A random generator of standard tasks, across various locations, conditions, and reward settings.

Linear tasks with new tasks unlocking as you complete them.

Removal of temporary and arena quests.

For a full description, read README.md for the basic setup, and RandomQuests/README.md for the random quest setup.

This mod does not save created quests, their order, or filtering. It creates a temporary quest list for each SPT server launch.

Report any bugs, errors, or problems you notice. Happy hunting.

Version 1.0.2
