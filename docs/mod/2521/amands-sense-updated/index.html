Description

Sense shows icons over interactable items within a range, such as Loot, Containers, and Dead Bodies. There are unique highlights for Kappa, Quest and Wishlist Items. It will also show an icon and distance to map extracts, along with extract status.

Activate Sense key is Double Click F by default.

Colors, Audio, Keybind, Cooldown, Speed, Duration and Radius can all be changed in the F12 menu

Installation

1) Open the downloaded 7z file in 7-zip

2) Select the folder in the 7z file in 7-zip

3) Drag the selected folder from 7-zip into your SPT folder
