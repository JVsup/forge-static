Features

Features

“Lotus” currently features the following things :

- 340+ Custom Quests

- 900+ Sold / Bartered Items, including a lot of Items that are not available on traders, good ammo and good armor plates

- A Custom Keycard that grants you infinite Labs access for free, unlocked by Quests

- A very cute face

You might not be able to finish all Quests in a single playthrough unless you use Profile Editor to unlock the failed Questlines

This is not the final version of the mod, with all the updates I try my best to adjust Lotus to be up to date with new content, quests, balancing, etc.

See “Planned Features” tab for future plans

Installation ( Please Read )

Installation

Step 1.

  • Download Lotus

  • Download WTT-commonlib if you are on 4.0.x, if you are on 3.11.x or lower, download Virtual’s Custom Quest Loader instead

Step 2.

  • Unzip the files ( preferably with 7zip )
  • Drag the “BepInEx” and “user” folders from the Lotus and VCQL zip files directly into your SPT install ( like most other mods )

Step 3.

  • Start your game and have fun

You should use 7zip and should avoid using some form of mod-installer / mod-manager to prevent possible issues

Known Issues

Known Issues

Conflicts with certain settings in Server Value Modifier [SVM], those would be :

  • Enabling “Remove Filters” for the following cases ( Case Space Manager )
    - WZ Wallet
    - Wallet
    - S I C C Case
    - Documents Case
    - Keycard Holder
  • Enabling “Remove key-card requirement to access laboratory” ( Raid Settings )
  • Enabling “Unlock trader offers behind quests” ( Traders )

Conflicts with Lotus’ Weapon-Assembly Tasks :

  • Enabling the Attachment changes in SPT Realism Mod will likely make all of Lotus’ gunsmith tasks not work at all
  • Kalashnikov Enhanced Modding might make the AK-builds from the solutions not have the correct stats or work at all, the quests will likely still be possible to complete

Too many mods that add traders are installed and Lotus can’t be accessed anymore :

  • Solution A would be installing Kaeno-TraderScrolling
  • Solution B would be enabling the “Trading Intermediate Screen” in the default THE CITY ingame settings

BTR Driver having a messed up dialog screen :

  • Being able to start more than 1 BTR quest at a time mixes up all the dialog options, from my experience this shouldn’t break anything, just ruins the immersion

Modded Weapons / Gear not working for quests :

  • Sadly how EFT quests work, modded items have different IDs and don’t count towards these quests by default, I might make some sort of compatibility / config for that in the future but it would be a ton of work

Quest Guide

Lotus has some Quests that tell you to do something while wearing “specified Gear”, what is this gear and how do I know what is required?

That is simple, I made sure to drop as much information as possible in the description, you will need to scroll down to see it for some Quests however.

The “specified Gear” for this Quest:

The purpose of this is to give more information since some quests give you multiple options for gear, and to have a shorter objective length,

so it does not look like this abomination ( Test Drive - Part 1 )

There are a lot of Quests where I need to find and handover items, how do I know what actually needs to be “found in raid”?

Very simple again, the objectives always tell you if something needs to be found in raid or not.

If it only tells you to “Obtain xyz” and / or just “Hand over xyz” without mentioning anything about “in raid”,

it doesnt need to be FiR.

If a quest needs items found in raid, it usually tells you that in the objective like “Find xyz in raid” and then “Hand over xyz”

There are a few questlines where you need to choose a specific trader for the questline that you want

The 2 big questlines that you can pick are for either Prapor or Peacekeeper / Skier.

You can choose the questline you want after accepting the quest “For The Motherland” from Prapor, after accepting it you should get a quest from Peacekeeper called “Keeping The Peace”.

> Completing the quest from Peacekeeper will get you his questline with 16 Quests ( 13 from PK and 3 from Skier )

> Completing the quest from Prapor will get you his questline with 17 Quests

Then there are a few smaller quests, you will get a quest called “New Dealer In Town” from Lotus. Accepting it will give you a quest from Skier, completing the quest for their respective trader will give you another quest for the trader that you picked.

The objectives of the quests that you will get after are identical, with the only difference being the rewards and the trader they are on.
