The primary goal is the automation of the mod process — covering the stages of searching, downloading and installing— for a more efficient experience.

Description

Current Feature

  • Ability to seek out and integrate multiple SP-THE CITY instances
  • Change the mod load order
  • Search for mods
  • Support of direct downloads (from GitHub, Dropbox, direct Download, Google Drive, MegaNz)
  • Automated download and installation process
  • Light and Dark theme
  • Includes a Top-Rated section showcasing the most recommended mods
  • (SP-EFT Manager) Automated updates for new releases, directly from GitHub
  • Extension of pages and incorporation of pagination from the SP-THE CITY Hub

Experimental Features:

  • Start server
  • Enable / Disable installed mods — Thanks to glo

Planned Features:

  • Start launcher
  • Basic version verification feature for instances and mods
  • ‘Checking for new version’ functionality
  • ‘Preinstall Check’ for a smoother installation process
  • ‘Revert-Changes’ functionality
  • Remove installed mods
  • and more …
