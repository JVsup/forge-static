Description

Original Mod by SamSWAT

A BepInEx client mod that adds DayZ-inspired helicopter crashes to SPT.

— FIKA USERS —

You need the Fika Sync addon to make the mod work on Fika. Please follow the install instructions on the Fika Sync addon’s page.

————————

Helicopter crash sites have a configurable spawn chance (default is 10%), and can spawn with a lootable crate (the default crate spawn chance is 100% and is also configurable).

This mod was originally made by SamSWAT, was updated by Tyrian for 3.7.x and now I’m maintaining the mod, for the foreseeable future.

Installation
HOW TO INSTALL
  1. Download and install the dependency mod UnityToolkit
  2. Download this mod and open the file with 7-Zip
  3. Drag and drop the BepInEx folder into your game folder (not the SPT folder inside your game folder!)
