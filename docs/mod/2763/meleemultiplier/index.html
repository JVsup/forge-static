Description Versions 3

Damage multiplier for melee weapons (stab, slash). Default x10.

Install
Extract zip content to root game folder

Config
.\SPT\user\mods\MeleeMultiplier\Config\MeleeMultiplierConfig.json5 change “meleeDamageMultiplier” value to any integer number

{
  // damage multiplier x10 by default
  "meleeDamageMultiplier": 10,
 
  // List of item template IDs to exclude.
  // https://db.sp-tarkov.com/search (root.item._id)
  "excludedMeleeItems": [
    "6087e570b998180e9f76dc24", // Tagillas Superfors DB 2020 Dead Blow Hammer
    "5fc64ea372b0dd78d51159dc" // Сultist knife
  ],
}
