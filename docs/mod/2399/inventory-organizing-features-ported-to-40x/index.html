Inventory Organizing Features (Ported to 4.0.x)

Adds several inventory organizing features which rely on item tags, such as sort locking, move locking and container organizing. Also adds a button to take out all the items from a container.

Frequent Usages:

  • @o —— Organize. Makes a container pull items which can fit into it. Items which are being pulled are determined by container’s filters and parameters which user has specified.
  • @o <category>; —— Collects the specific category only. Like “@o money;” (without quotes). NOTICE the SEMICOLON is important, and the bracket isn’t needed.
  • @o !<category>; —— Collects everything except the specific category. Like “@o !ammo;” (without quotes), which collects everything except ammo.
  • @o n:<item name>; —— Collects items which name contains the given string. Like “@o n:5.45;” (without quotes), which collects all items with “5.45” in their name.
  • @o <condition 1>|<condition 2>; —— Collects items matching either condition 1 or condition 2. Like “@o n:7.62|n:5.45;” (without quotes), which collects all items with “7.62” or “5.45” in their name.

See full documentation and explanation of all the features here: 3.11.x and original
