Description Versions 3

Adds an item named Canted Aim, can be found on the flea for extremely cheap. Goes in place of your scope, and any other scope you want to use gets attached to it.

The bundle comes from Pluto’s old Echoes of THE CITY project, thank you Pluto for allowing me to use it.
