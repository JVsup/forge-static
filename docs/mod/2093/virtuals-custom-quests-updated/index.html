Overview

A custom set of 40 quests that range in difficulty to vary the playthrough of THE CITY just a little bit more. The quests are relatively lore-friendly, some are an addition to the game’s current set of lore-based quests and appears just as new content (A new player wouldn’t be able to tell they aren’t the base game content). The rest is a mastery set that requires the player to move through different levels of elimination quests with various weapons and yield some worthy rewards.

Originally by Virtual, updated with his permission.

Contains translations for German users.

Installation

Download the file for your version of SPT and extract to your SPT install. The files will then be placed in their relevant locations.

If you are using the version for SPT 3.* you will need VCQL.

If you are using the version for SPT 4.* you will need WTTCommonLib.
