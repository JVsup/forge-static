TYFONS WEAPON CUSTOMIZER IS REQUIRED FOR MAKING A GOOD AMOUNT OF ATTACHMENTS FIT WELL IN THIS MOD

====================================================================== This mod adds no new attachments, just moves some filter lists around to allow some guns and attachments to use reasonable attachments. I literally cannot explain all the changes but like 90% of vanilla guns are affected by this change, I made this for myself to not make all these changes by hand like I used to every time the game updated but I figured others may enjoy this.

This is a very jank mod so please expect some clipping hence why the above mod is recommended!!!

Examples of changes:

  • Glock 18c and pistols with actual muzzles, foregrips, slide sights
  • Shorty shotguns and rifles
  • Low customization guns now with some attachments
  • 9mm muzzles on ALL 9mm guns (like the sr3m or vsk with muzzle attachments)
  • too much to list seriously

This mod does affect my other mods, and mods that use the same vanilla attachments- so balancing of guns are affected since some mods just make guns better. I have not seen a conflict yet but as I said, without the above recommended mod then some customizations are unusable. It will be a lil groggi so you have been warned, install at your own risk. DO NOT USE WITH REALISM if its even out yet

TO INSTALL JUST UNZIP TO YOUR MAIN SPT DIRECTORY path is SPT > user > mods > (THREE FOLDERS) DaGrogsVanillaAttachmentPart1Remix, DaGrogsVanillaAttachmentPart2Remix, DaGrogsVanillaWeaponRemix

TO UNINSTALL JUST DELETE THE THREE FOLDERS IN mods AS I LAID OUT IN THE PATH ABOVE
