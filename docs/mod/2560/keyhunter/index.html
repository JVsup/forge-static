Description Versions 5

Tired of endlessly searching for keys? KeyHunter provides a smarter and more natural way to find keys and keycards while respecting Tarkov’s loot system.

Inspired by the original KeysInLoot concept by MusicManiac, KeyHunter v2 introduces a fully reworked, dynamic implementation for SPT 4.x.

Features

  • Automatic key and keycard discovery directly from the game database

  • Progression-based spawning – players at lower levels mostly encounter common keys, while rarer keys become available as progression advances

  • Smart rarity system (Common, Rare, Super Rare, Keycards)

  • Optional map-based key routing – keys are more likely to appear on their associated maps

  • Automatic price adjustments to reduce economic impact

  • Configurable behavior without hardcoded key ID lists

Notes

This version is a major rewrite and is not compatible with previous configurations

Please remove the old KeyHunter mod folder completely before installing v2

If you encounter any issues or unexpected behavior, feel free to leave a comment.

Overview

KeyHunter has been completely reworked in this release to provide a smarter, more natural way of finding keys without relying on hardcoded ID lists or breaking the overall loot flow.

Instead of static configuration, keys and keycards are discovered dynamically from the game database. Their availability scales with player progression, meaning players at lower levels mostly encounter common keys, while higher-level players gradually gain access to rarer and more valuable ones. This creates a smoother sense of progression without sudden loot spikes.

Loot Behavior

Key spawns can optionally be influenced by map routing, allowing keys to appear more frequently on their associated locations.

To prevent key flooding from destabilizing the economy, the mod also includes an automatic price adjustment system for traders and the flea market.

Internally, keys are categorized by rarity tiers (Common, Rare, Super Rare, and Keycards), allowing the system to make more informed decisions about when and where keys should appear.

Important Notice

This version is a major rewrite compared to v1.x and is not compatible with previous configurations. Please remove the old KeyHunter mod folder completely and extract the new version.
