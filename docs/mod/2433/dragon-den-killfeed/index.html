Dragon Den - Killfeed

Features and Usage

Features

  • Killfeed showing every kill in a corner
  • Displays attacker, victim, weapon, ammo type, body part and distance
  • Includes faction icons for USEC, BEAR, Scav, and Unknown
  • Customizable layout: choose top/bottom left/right corner
  • Adjustable margins, font size, color, and spacing between lines
  • Configurable display duration and fade-out speed for each kill
  • Set max number of killfeed lines (if shown more than max, it removes oldest ones)
  • Option to include or hide kills from other players and bots
  • Text format using tokens: {attacker}, {victim}, {bp}, {weapon}, {ammo}, {dist}
  • Adjustable faction icon tint and toggle for visibility
  • Semi-transparent background for readability
  • All settings configurable directly through BepInEx menu
