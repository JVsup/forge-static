Item Valuation

Lightweight quick reference valuation tool. Items will be coloured based on configurable values (price, armour class, penetration, etc). Automatically works natively with Live Flea Prices.

Description Versions 6

ColorConverterAPI is required if you want to use custom colours.
Without ColorConverterAPI, colours will default to hardcoded values.

This mod allows you to:

  • Adjust thresholds for ammo, weapons, armour, and items.
  • Customise colours for ammo, weapons, armour, and items.
  • Enable/disable colouring for specific item types.
  • Enable/disable colouring for Flea Market banned items.
  • Automatically works with Live Flea Prices.

The background colours update after the next raid or client restart.
Item descriptions require a client restart to refresh.

Special thanks to DRAKIA!

Installation
  1. Download Item Valuation
  2. Open the downloaded 7z file in 7-zip
  3. Select the SPT folder in the 7z file in 7-zip
  4. Drag the SPT folder from 7-zip into your root SPT folder

Uninstallation
  1. Delete /ROOTSPT/SPT/user/mods/acidphantasm-itemvaluation
  2. Done
