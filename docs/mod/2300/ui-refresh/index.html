Description Versions 5

A collection of menu edits made to my tastes.

Layout Changes:

  • Menus have been refreshed. Mostly deactivating, moving, and scaling UI elements.
  • Feature to switch background scenes per map.

Map button on Taskbar:

  • Adds a button to the taskbar that brings you right to the location select map as a PMC.

Clock Widget:

  • A clock can be added to your inventory screen. The clock can be set to raid time or system time. The clock is automatically compatible with Immersive Day Night Cycle.

Options to disable various UI elements:

  • Top Glow
  • PVE button.
  • Version Label.
  • Orange beta banner.
  • Group Widget on taskbar.
  • Show game through the raid-pause and settings screen.

HUD Options:

  • Disable the Stance Silhouette.
  • Move the Health widget to where the stance widget was.
  • Phrase Prompt opacity slider.
  • Ammo/Sighting Range opacity slider.
  • Minimal Stamina Bars: Hides the movement volume icon and speed and stance slider.

Beta features:

  • Option to skip Raid Settings and Insurance screen.
  • Option to show the hideout when in the main menu. (This will automatically load the hideout. Still in beta. While fairly stable, it does not have all the features I want.)

Quick video: https://youtu.be/vVQKzB5EMqo

Please Note!

  • Compatible with Moxo Pixel’s Main Menu Overhaul. The main menu layout in the video is just MoxoPixel’s mod.
  • If you want something to be configurable, let me know. Making an F12 settings takes extra work, so I won’t do it for everything by default, but if it’s requested, it’s easy enough make.
  • This mod was designed in 16:9 aspect ratio. Some UI elements may be misplaced in widescreen. Please report anything weird and I will do my best to fix it.
  • Changes to the raid loading screen background only work in English. (for now)
  • If skipping Raid Settings and Insurance, do not hit ESC at the Raid Confirmation page. Use the Back Button or Taskbar, or else you’ll be cursed with a double menu. It’s does not require a restart though, just navigate through the menus again.
