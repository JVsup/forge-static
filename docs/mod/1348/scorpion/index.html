Installation
  1. Download and Install CommonLib FIRST THIS IS REQUIRED
  2. Download Scorpion
  3. Open the downloaded 7z file in 7-zip
  4. Select the user folder in the 7z file in 7-zip
  5. Drag the user folder from 7-zip into your SPT folder
