Description Versions 3

Special thanks to the SPT devs for everything they’ve done for this game and its playerbase!

As of version 1.2.0, I believe everything is up to date except we are still missing accurate trader data, so I have only put in the MXLR trade at Jaeger 3 and the trades for the ammo at Mechanic and Jaeger.

Installation:

Download the .zip file, extract all, and drag and drop the contents into your root SPT install directory.

Uninstalling:

If for whatever reason you need to remove this mod, make sure you delete any new items that this mod adds from your inventory before you delete the mod folder!
