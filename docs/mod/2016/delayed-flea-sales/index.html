Delayed Flea Sales

If you are tired of having your flea offers being sold instantly, maybe you don't like money - I don't know, this mod is for you.

Description Versions 4

Very simply allows configurable delayed sales for flea offers. If you don’t want instant sales when you sell at average price or lower, then use this mod.

Adjust the instant sell chance, minimum delayed sale time, and maximum delayed sale time.

If you don’t want instant sales at all, change that in the config to 0.

If an offer is marked to sell before the minimum delayed sale time, then it will roll a random time between the minimum and maximum.

Default Values

Instant Sell Chance: 25%

Minimum Sale Time: 60 seconds

Maximum Sale Time: 900 seconds

Installation
  1. Download Delayed Flea Sales
  2. Open the downloaded zip file
  3. Select the SPT folder in the zip file
  4. Drag the SPT folder from zip file into your root SPT folder
