Compatibility Highlighter

Highlight compatible mags ammo and attachments.

awnova
Downloads

Description Versions 2

What it does:

  • Shows all items compatible with the hovered item in both directions
  • Hover over ammo → compatible magazines and guns light up
  • Hover over a magazine → compatible guns and ammo light up
  • Hover over a gun → compatible attachments, ammo, and magazines light up

Key features:

  • Configurable highlight color (default: green)
  • Adjustable hover delay before the highlight appears
  • Can toggle container items (backpacks, rigs, cases) on or off
  • Option to use vanilla highlighting when you’re actively dragging items
