GFLVoices

Adds the dolls’ voices from GFL2 to THE CITY

Recommend you use SchizoPMC because since there isnt a lot of voice files to work with, I just decided to use the triggers from that mod.

Im considering having bots use them but Im not sure how to do it without splitting this into 50+ different mods per voice lmao

Voice List

So far everyone currently released in gfl2 except for Soppo(Im sad), Mityl, Faelynn and Welrod

Installing

  1. Download the mod.
  2. Extract the archive using 7-Zip or WinRAR.
  3. Place the extracted folder into your main SPT directory.
  4. Launch the game.

Uninstalling

  1. Change your selected voice back to a default voice.
  2. Delete the GFLVoices folder from your SPT installation.

Issues

If there are any, just put it in the comments. Ill try my best to fix it.

P.S. Idk why but I had to restart my game for some voice changes to take effect, if u somehow still have the voice of a previous character after switching, just restart ur game.
