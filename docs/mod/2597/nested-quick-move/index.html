Description Versions 1

Quick move (CTRL+CLICK) extends to nested containers. When you quick-move an item into a container, the mod will also check all nested containers within it - merging into existing stacks or placing into free slots at any depth. Stash containers are excluded to prevent items from landing in random bags.
