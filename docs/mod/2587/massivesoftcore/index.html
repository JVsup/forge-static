Overview

MassivesoftCore is a library required for my mods to fuction. Basically it functions as an item loader and compatibility solver.

You can use it as a dependency to build your own mod but no support or documentation will be provided.

Installation

Decompress and put the folder MassivesoftCore under [Your EFT Directory]/SPT/user/mods

For versions later than 1.0.2: Decompress and put the folder SPT under [Your EFT Directory]/
