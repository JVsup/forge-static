Description Versions 1

A content pack aiming to provide vanilla weapons rechambered in .366TKM. No new models although some attachments are remixed, a small preview into the customization I aim to provide in another mod. I highly recommend using Tyfon’s weapon customizer with this mod since some attachments are finicky. Nonetheless, what is added is:

-Molot VPO 208 series (SKS in 366, a base, OP-SKS, and OP-SKS Auto version) -Molot VPO 209 series (VPO-209 but automatic and a AKS-74UN in 366) -RPDN in 366 with associated attachments -Mk47 in 366 with associated attachments

All weapons and parts are on the flea; however if you use SVM, you can add the following to the Trader Assort Section in advanced features to buy them from skier or change it however you want (SVM has a FAQ section on what the codes mean) however this does make some vanilla items available as well like the mk47 receiver so if you don’t want that, edit as you need:

LINES SHOULD BE STACKED ON TOP OF EACHOTHER WITH NO SPACES ABOVE OR BELOW AND NOT SIDE BY SIDE IN SVM

To install simply unzip and place the SPT folder where your SPT is installed so the path is SPT installation > SPT > user > mods > 366TKMContentPack

To uninstall, enter your profile and delete all weapons from the pack in the profile and any unique items from the pack (barrels for example) FIRST and then delete the pack from your mods folder -> done

I have not found any compatibility issues so far but as stated I may not be able to fix any if any arise, so install at your own risk.
