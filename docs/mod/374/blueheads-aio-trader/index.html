Description Versions 13

Installation

  • copy BlueheadsAIOTrader folder into [SPT_INSTALL_FOLDER]/SPT/user/mods

Usage

  • buy everything in game database from AIOTrader
  • get AIOKeysCase, AIOAmmoCase, encoded DSP Transmitter by send message to Commando, see how to use Commando[https://wiki.sp-tarkov.com/en/SPT_and_Commando_Bots]
  • send aio give key to get a case include all key
  • send aio give ammo to get a case include all ammo with 99999 stacked
  • send aio give dsp to get a encoded DSP Transmitter

Configuration

Edit BlueheadsAIOTrader/data/config.json

   enable_aiotrader: toggle trader
   realistic_price.enable: toggle the realistic_price
   custom_price: force aioTrader to sell specific items at the price you specify
   hide_no_price_item: let aiotrader not sell items without realistic or custom price

   hide_all_ammo_ammopacks: hide ammo & ammopacks from aiotrader to make it load faster
   hide_all_keys_cards: hide keys & cards from aiotrader to make it load faster
   hide_all_builtin_inserts: hide armor vest builtin inserts from aiotrader to make it load faster

4.0.2

23 September 2024
SPT 3.9.8 Fika: unknown 4,612 downloadsUnknown size

update for apt 3.9.8

Since Tarkov has more and more items, AIOTrader is loading slower and slower, so I optimized trader loading speed by:

1. Remove all keys & cards from AIOTrader since you can buy them from bluehead trader

2. Remove all ammo & ammo packs from AIOTrader since you can buy all ammo from bluehead trader

3. Remove all built-in plates of armor vest from AIOTrader since you can not customize them anyway.

4. Sell all mod parts separately in AIOTraderPart2

5. All these features can be toggled via the config

Let me know your thoughts on these changes by leaving a comment, good luck : )
