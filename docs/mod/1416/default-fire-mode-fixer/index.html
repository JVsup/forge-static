Default Fire Mode Fixer

Fixes weapons to default to full auto instead of single fire. Shotguns default to double instead of single if available. SMGs default to Full Auto over Single / Burst

acidphantasm

Description Versions 5

This mod was built to be extremely simple with as little impact as possible. It just sorts the weapFireType by key length, which makes for a much better sorting system for the fire types than default.

If you want this to impact non-vanilla weapons, you will need to adjust your load order to put this mod below the custom weapon mods.

This only impacts weapons that you buy from traders and find in raid.

SPT will still remember your previous FireMode selection on raid exit and set it accordingly on the weapon.

Same with AI in raid, if they switch to Single Fire, it will be Single Fire until it’s changed in raid.

INSTALLATION
  1. Open the downloaded 7z file in 7-zip
  2. Select the SPT folder in the 7z file in 7-zip
  3. Drag the SPT folder from 7-zip into your root SPT folder

Demonstration Video (yoink):

UNINSTALLATION
  1. Delete /ROOTSPT/SPT/user/mods/acidphantasm-defaultfiremode
  2. Done
