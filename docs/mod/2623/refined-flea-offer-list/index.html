Refined Flea Offer List

Description Versions 2

Abstract

Smarter and easier view of flea!
Help you hide those duplicate offers when linked search or browse categories.
Can manually show additional cheapest Ruble offers or full-state items in list.
Different weapon or armor builds are identified and shown together.

Customize functions in F12 menu

  • Main Activation
  • No GP Offer
    Hide all GP coin offers on normal flea page.
  • Page Capacity
    Overwrite the vanilla num of flea offers per page.
  • Retain Full-condition Offer
    Retain cheapest full durability offer when browse >1 type of items.
  • Retain Ruble Offer
    Retain cheapest Ruble offer when browse >1 type of items.
  • Single Item Offers Quantity
    When select one specific item, show the N cheapest offers.
  • Vanilla Single Item Page
    When select one specific item, show all offers in original arrangement.

How to install

Download the zip and copy(drag) the BepInEx folder in package, to your SPT main folder (where EscapeFromTarkov.exe locates)

To uninstall

Just remove the dll file in YourSPT/BepInEx/plugins/RefinedFleaOfferList.dll
