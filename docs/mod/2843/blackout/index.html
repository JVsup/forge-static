Description

Recreates the live EFT “Blackout” event on Labs. Seconds into the raid the generators die, the lights go out, and you run the facility on emergency power while the Wedge and his Black Division hold the floors.

Configure event roll chance in the config.json

The blackout

  • Darkness Done in my own image. BSGs version and settings for darkness were unobtainable (by me at least)
  • The live event’s power-cut sound and intercom announcement through the map’s own PA speakers
  • Amber emergency floods at the real event positions, keycard LEDs stay lit like live keeps them
  • Extract lockdown: only the two gates are live, and one press of the Arsenal Storage Room switch opens both
  • Keycard doors take a fresh 4-digit code each raid instead of swipes, written on the admin office whiteboard in the event’s own marker digits

Wedge and Black Division Guards

  • The Wedge holds Labs every raid with 4-5 Black Division Guards, no waves, our own bot types
  • He and his guards are friendly toward WTT’s separate Black Division mod, so you can run both
  • His real live loadout: the MP7A1 “Wedge” preset with the suppressor always on, his own face, clothing and voice lines from the live files, the M53A1 gas mask, EXFIL helmet and LV-119 Icebreaker
  • SAIN runs their combat when installed (the Wedge under Bosses at boss grade, his guards under their own “Black Division” tab at raider grade)
  • The Wedge always carries the TerraGroup Labs arsenal storage room key - single use, and the door can’t be breached. Killing him is the way in
Recommended

-WTT Black Divsion: Set LabsStartchance to 100 and LabsGateChance to 100

Install Instructions
  1. Extract the archive
  2. Drop the BepInEx and SPT folders into your SPT root directory
  3. Requires WTT-CommonLib, WTT-ContentBackport, and MoreBotsAPI (client + server halves). SAIN recommended.
  4. Load into Labs
Known Limitations / Bugs
  • Should be compatible with the Wedge Mod. Mine controls labs and his every other map. we compared factions, enum values and everything to make sure they don’t conflict for now.

2.1.0

28 July 2026
SPT 4.0.13 Fika: compatible 924 downloads5.9 MB

Fika co-op support

Blackout now runs the same for everyone in a Fika raid. The lights cut for the whole group at once, the admin office switch opens the gates for every player instead of only the one who pulled it, and a keycard door someone else opens with the emergency code is open for you too.

Which downloads do I need?

Playing with Fika: this version plus the separate Blackout Fika addon, under the Addons tab on this page. Both are needed. The addon is a single file and there is nothing to configure. It requires Blackout 2.1.0 or newer, so update the mod first.

Playing solo: just this version, and you are done. Everything above sits inactive without the addon, so nothing about your raids changes. It is worth updating anyway, since it is what makes co-op possible if you ever want to run the event with friends later.

Also in this version

  • The emergency code is rolled by the server instead of by each player, so everyone in a raid reads the same four digits off the same whiteboard
  • The server log is down to two lines instead of six. A clean start is quiet now, and each raid gets one line saying whether it rolled a blackout
  • The F12 menu is gone. blackoutChance in config.json already did the same job, and setting it to 0 switches the event off entirely

Install

Extract and drop the BepInEx and SPT folders into your SPT root. The archive layout has not changed since 2.0.0, so you can install straight over the top without deleting anything first.

Requirements

  • WTT-CommonLib 2.0.22 or newer, both halves
  • WTT-ContentBackport 1.1.0 or newer, both halves
  • MoreBotsAPI, both halves
  • Fika only if you want co-op, and only with the addon

Version

2.0.0

25 July 2026
SPT 4.0.13 Fika: incompatible 2,334 downloads5.9 MB

Dependencies changed

  • WTT-ContentBackport 1.1.0 or newer (both halves, server and client)
  • WTT-CommonLib 2.0.22 or newer (both halves)

Content Backport 1.1.0 backported the same live items Blackout was shipping: the MP7 ARS adapter and FX-KPOS stock, the SF3P flash hider, the ComTac VI, the EXFIL helmets and the Wedge cover, the LV-119, and Wedge’s face, clothing and voicelines. Two mods adding the same things meant duplicate items in the handbook and a stack of errors on every server start. Blackout now points at theirs, so there is one copy of everything and it stays in sync with whatever they ship.

Removed

  • Every asset bundle. The download went from about 61 MB to under 6 MB
  • Wedge’s gear items, his clothing, his head and his voice, all of which Content Backport provides now
  • The custom black Team Wendy helmet that only existed to hold the helmet cover. Content Backport adds the cover slot to the normal black one, so it earns its keep no more

Updating from 1.1.0 or older

Delete both of these folders before you extract:

  • BepInEx/plugins/Blackout
  • SPT/user/mods/Blackout

Then drop the BepInEx and SPT folders into your SPT root as usual.

This matters more than it normally would. 2.0.0 ships no bundles at all, so installing over the top leaves roughly 60 MB of old bundle files behind, and those now fight with Content Backport’s copies of the same assets. Deleting first is the whole fix.

Fresh installs can ignore all of that and just extract.

1.1.0

SPT 4.0.13 Fika: unknown 232 downloads60.9 MB

Added

  • The blackout is a per raid roll now instead of firing on every Labs run, so you never know which one goes dark until the lights cut. 25% by default. Set blackoutChance in SPT/user/mods/Blackout/config.json to change it, or put it to 100 if you want the old behaviour back

Changed

  • The LV-119’s soft armor inserts are built in and can no longer be left out, the same as every other armor in the game

Fixed

  • The Wedge’s armor was spawning with their plates but no soft armor, so he was taking full damage anywhere the plates didn’t cover. He gets his inserts now
  • The vehicles at the hangar and parking gates were disappearing the moment the lights went out, collision and all, so you could walk straight through where a car was parked. They stay put now, and they still stop bullets

Updating

Extract and drop the BepInEx and SPT folders into your SPT root, straight over the top of 1.0.0. Nothing was renamed or moved, so there is nothing to delete first. The only new file is config.json.
