Lacy's PvE Tweaks

Several options to make PvE less annoying. Want to go to Labyrinth without using the transit? Now you can queue right into it! Want to make quests less grindy, or less restrictive? Now you can!

Description Versions 11

This mod contains several options to tweak the PvE experience to be less annoying and more fun.

  • Ref Changes: Makes all Ref changes actually PvE, and removes all arena quests (automatically disabled if Acid’s Ref mod is loaded)
  • Remove Transit Quests: All transits quests are removed and turned into normal quests.
  • Remove Recipes: Removes all redundant recipes that clogs hideout crafting, e.g. arena crates
  • Enable Labyrinth: Enables Labyrinth on the map screen, making it more approachable. It still requires the key, like Labs
  • Quest Tweaks: Makes some quests less grindy
    • Currently: Test Drive Part 2, 3, 4 & 5, Hunter, Gendarmerie - Mall Cop
  • Add Recipes: Adds new recipes to the hideout
    • Currently: Labrys keycard (requires level 2 Intelligence Center)
  • Remove Map Limitations: Removes map limitations from certain quests (e.g. not on Factory)
    • Currently tweaks: Punisher Pt. 6, Insomnia, Surv Path - Zhivchik, Surv Path - Eagle-Owl
  • Tweak Extracts: Makes certain extracts less annoying (mainly for the use with Fika)
    • Currently changes Labyrinth to:
      • 5 minutes until it opens, down from 15
      • No longer shared and can be reused
      • No longer deactivates after 5 seconds even if not used
  • Hideout Customizations: Allows you to unlock otherwise unobtainable hideout customizations from events, i.e. Kindergarten and Minotaur room kits
    • Both have their own, unique requirements to unlock
  • TweakASVal: Makes the VSS/VAL not overheat as fast by reducing the heat per shot, and nerfing the heat per shot on various 9x39 ammo

Every option can be enabled/disabled in the configuration file. All are disabled by default. I might add suggestions, but I will not change existing options. This was made for me and my group of friends that I play with, and I decided to share it with like-minded individuals.
