Cobra’s Ammo Stack

Take complete control over ammunition stack sizes in SPT 4.0.13.

Cobra’s Ammo Stack is a lightweight server-side mod that allows you to configure ammunition stack sizes by caliber, support custom ammunition from other mods, and override individual items using a simple JSON configuration.

Features

  • Configure stack sizes by caliber
  • Support for vanilla ammunition
  • Support for modded ammunition
  • Custom caliber support
  • Individual item overrides
  • Configurable default stack size
  • Lightweight server-side implementation
  • No client installation required

Installation

  1. Download the latest release.
  2. Extract the ZIP file.
  3. Drag the included SPT folder into your SPT installation.
  4. Allow Windows to merge the folders.
  5. Start the SPT Server.

Configuration

Edit the included config.json to customize stack sizes.

Supported options include:

  • Default stack size
  • Per-caliber stack sizes
  • Custom calibers
  • Individual item overrides
  • Optional startup logging

Compatibility

  • SPT 4.0.13
