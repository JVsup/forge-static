About

Actually Found In Raid is a simple client side mod that will ensure all AI PMCs items are spawned as Found In Raid. Now when you loot a PMC, the items will be Found In Raid, like they should be, at least in my opinion.

The mod can be toggled on/off using Configuration Manager.

Place the dll file in your BepInEx/plugins folder.

DO NOT USE WITH FIKA, FIKA HAS IT’S OWN FIR SETTINGS
