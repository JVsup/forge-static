Career Log

Career Log keeps a personal raid history for your SPT profile: where you went, what you looted, who you killed, and how your stash grew over time. After each raid you get a RAID MAP and RAID DEBRIEF; from the main menu, open RECORDS for lifetime stats, raid history, and a Financial view of stash worth.

Github: FallegaHQ

Install

What you need

  • A working SPT 4.x install.
  • This mod.
  • The mod turned on in its config (see below).

If you use other mods that change session end screens, the main menu, or stash UI, list them when you report a problem.

Install

  1. Download the release ZIP — the filename looks like Softwyx.CareerLog-1.0.199.zip (the version number changes each release).
  2. Extract it so that your game folder contains:
    • BepInEx\plugins\Softwyx.CareerLog\Softwyx.CareerLog.dll
    • BepInEx\plugins\Softwyx.CareerLog\locales\
    • BepInEx\plugins\Softwyx.CareerLog\assets\
  3. Start the game.

First launch may create:

  • BepInEx\config\com.softwyx.careerlog.cfg

Edit while the game is closed, or use Configuration Manager in-game.

Usage

After a raid

  1. Finish a raid (extract, death, or MIA).
  2. Step through RAID MAP (path + markers) then RAID DEBRIEF (loot + counters for that run).
  3. Optional: enable vanilla Session statistics in config to see it after the debrief.

Main menu — RECORDS

  1. Click RECORDS on the main menu.
  2. Use Summary, Financial, and Raid history tabs.
  3. Pick a raid for detail and MAP.
  4. Filter PMC, Scav, or Combined as needed.

Data saves when the raid ends through the normal session flow. Force-quits may skip that raid.

Settings (overview)

Open Configuration Manager or edit com.softwyx.careerlog.cfg while the game is closed.

Section What it controls
1. General Master Enabled switch; JSON minify
2. UI Post-raid screens; RECORDS button; default side filter
3. Movement & maps Trail sampling and simplification; vanilla statistics toggle
4. Event collectors Map markers — kills, loot value, injuries, healing, merges
5. Financial Stash snapshots on menu; chart style; top-item exclusions

More details can be found here.

Delete the config with the game closed to restore defaults.

Support

Known issues / quirks

  1. Map missing for a location — Some maps may show a message that the image is unavailable; movement and markers may still be saved.
  2. Scav runs — Scav raids are recorded and tagged; they are stored under your PMC profile id (for convenience).
  3. Bring-in gear vs looted gear — Loot stats and markers try to ignore gear you brought into the raid; edge cases (stacks, containers, quest items) may still look odd in rare situations.
  4. Other session-end or menu UI mods — Best-effort compatibility. If something breaks, test with only Career Log + SPT essentials.

How to report a bug or ask for help

  1. Mod version — LogOutput.log, line with Career Log / [CLG] and version.
  2. Game / SPT — Version numbers if you know them.
  3. What happened — One sentence.
  4. Steps — Map, side, outcome, buttons clicked.
  5. Other mods — Especially UI, session end, economy, maps.
  6. Logs — BepInEx\LogOutput.log (game closed).

If the mod you are using is not signed by me then it isn’t from me and I can’t help you with it.

Use the download site’s issue tracker or comments. Do not email about mods.
