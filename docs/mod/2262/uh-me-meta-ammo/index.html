UH-ME: META AMMO

Turn any gun into a rail gun and shred all the sweat lords.

UHSpartan

Description Versions 1

As requested, UH-ME creates one new META cartridge for every gun! This is a lightweight mod that simply makes a high damage/high pen/highly accurate clone of each round (one per caliber). It also removes explosive characteristics of the grenade rounds so they act like a huge shotgun slug. It does not replace or touch the vanilla ammo. You will find it available for sale from Mechanic and on the Flea Market. Loot pools are disabled by default so you shouldn’t have any bots spawning with it. However, if you want some chaos you can simply edit the mod.js file to allow the bots to have some fun too. You can also tweak the stats of the rounds inside the mod.js file as well.

Installation:

Simply unzip and drag into your SPT folder to install. It uses the standard file path of user-mods-“mod name”.

Credits:

This mod was requested by HandGrade after they tried my UH-EX: Explosive Ammo mod.

I am happy to make this one for you and hope you enjoy it.

Feel free to tweak/edit/upload or do whatever you want with this mod. Have fun.
