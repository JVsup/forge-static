SPT Mod Manager

A Vortex/MO2-style mod manager built specifically for Single Player THE CITY. It came out of a real pain point: I got tired of having to hunt down files one by one just to uninstall a mod that was causing conflicts, so I decided to build a tool that would solve that for good.

What it does

  • Installs .zip, .7z, and .rar mods with automatic structure detection (Server, Client, or Hybrid)
  • Enable/disable mods without deleting anything
  • Rename, uninstall, and reinstall mods (reinstall works if you still have the original archive)
  • Export and import mod lists
  • Conflict detection by name (still basic, but improving)
  • Forge integration: browse and install mods directly from the app, view mod info, download the right version, and check for updates
  • Bilingual UI (PT-BR and EN)

Installation

Download the .zip, run the .exe. It installs everything automatically and creates a desktop shortcut.

Current limitations

  • Only tested with compressed archives (no folder-based installs yet)
  • Doesn’t modify any SPT core files (only copies/organizes)
  • Fully tested and supported only on the latest SPT version (older versions should work, but without guarantees)
  • Windows only for now (Linux/macOS support planned, but i need to refine the Mod Manager first)

Personal project, not affiliated with the SPT team or Big Silly Goose.
