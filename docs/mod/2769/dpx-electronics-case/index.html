DPX Electronics Case

Adds a dedicated electronics storage case to SPT.

The DPX Electronics Case is designed for players who want a cleaner stash without mixing CPUs, RAM sticks, SSDs, circuit boards, military electronics and tech loot into a general junk box.

Features

  • New custom container: DPX Electronics Case
  • Sold by Skier LL1
  • Price: 500,000₽
  • External size: 3x3
  • Internal storage: 10x10
  • Custom graphite / PCB-style texture
  • Strict electronics whitelist
  • No BepInEx plugin required
  • Does not modify SPT_Data

Accepted item types

The case is made for electronic and tech items, including:

  • CPU
  • CPU Fan
  • RAM
  • SSD
  • HDD
  • Powerbank
  • Printed Circuit Board
  • Military Circuit Board
  • Military Cable
  • VPX
  • Virtex
  • RFID Reader
  • COFDM
  • Microcontroller Board

Installation

Extract the ZIP into your SPT root folder.

Expected structure:

SPT/ user/ mods/ DPX-ElectronicsCase/
