Normalized Bots port ~3.11

Makes bots a little bit more fair by changing their health and character skills. (Each option can be enabled/disabled in the option) Simple port to 3.11.x of original mod Normalized Bots(by JustNU)

Features (Every option is toggable in the config):

- in depth configuration system that allows to change all of mod’s options PER BOT

- Health changes, by default set to default player health

- Give bosses that had no armor protection some of it (Reshala, Sanitar, Cultist Priest).

- Removes OP skills from all of the bots (such as instant reloads and infinite stamina).

SHOULD WORK WITH MOST MODS THAT CHANGE BOTS.
