Overview

LiveBitcoinPricesREDUX

This mod dynamically updates the in-game price of Physical Bitcoin in SPT to match live THE CITY pricing.

  • Supports SPT 4.0
  • Rebuilt in C# for SPT 4.0
  • Supports both PVE and PVP pricing modes through config
  • Uses cached fallback data if the live API is unavailable
  • Optional periodic updates can be enabled in config

Bitcoin price data is fetched live from THE CITY Dev.

Stay synced with live THE CITY Bitcoin pricing in your SPT setup.

Installation
  1. Download and extract the mod archive.
  2. Copy the included SPT folder into your main SPT directory.

Final structure should look like this:

SPT\user\mods\LiveBitcoinPricesREDUX\

That’s it. The mod will update Bitcoin pricing automatically on server start.

Configuration

The mod includes:

  • config/config.json — main settings
  • config/price.json — cached price data used as fallback

Main options

  • GameMode
    • "pve" = uses THE CITY PVE pricing
    • "pvp" = uses THE CITY PVP pricing
  • EnablePeriodicUpdates
    • false = update on server boot only
    • true = keep updating on the configured interval
  • UpdateInterval
    • update frequency in seconds when periodic updates are enabled
  • EnableLogging
    • enables console logging
  • Advanced.EnablePriceCaching
    • enables cached fallback pricing
  • Advanced.CacheExpirationHours
    • max cache age before it is ignored
  • Advanced.ApiTimeout
    • API timeout in milliseconds
  • Advanced.UserAgent
    • custom user agent for requests
Additional Info
  • Original mod by Shardbyte; this is an updated continuation.
  • Original mod available here.
  • This version has been converted from JavaScript to C# for SPT 4.0 compatibility.

Note: This mod focuses only on updating Physical Bitcoin pricing. It does not rebalance the wider economy.
