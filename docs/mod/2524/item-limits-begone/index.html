Item Limits Begone!

Removes in-raid, inventory, and flea listing limits for all items. Also changes back pack stack limit to 42.

acidphantasm

Description Versions 2

Features

  • Backpack stack limit
    • Limit Changed: 7 → 42
  • Remove In-Raid Item limits (How much of something you can carry in raid)
    • Example: 1m Roubles → No Limit
  • Remove Inventory Item limits (How much of something you can bring into raid)
    • Example: 500k Roubles → No Limit
  • Remove Flea Listing limits (How much of something you can list on the flea)
    • Example: 6 Virtex → No Limit
INSTALLATION

Installation

  1. Download Item Limits Begone
  2. Open the downloaded 7z file in 7-zip
  3. Select the SPT folder in the 7z file in 7-zip
  4. Drag the SPT folder from 7-zip into your root SPT folder

UNINSTALLATION
  1. Delete /ROOTSPT/SPT/user/mods/acidphantasm-itemlimitsbegone
  2. Done
