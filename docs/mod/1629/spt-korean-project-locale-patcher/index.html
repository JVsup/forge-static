Welcome to the SPT-Korean-Project.

This mod updates and improves the Korean localization for SPT.

How to Install:

  1. Download the SPT_Korean_Localization_G&M.zip file.
  2. Extract the contents into your main SPT folder. The files should be placed as follows:
    • SPT/user/mods/spt_korean_localization_G&M
    • SPT/BepInEx/plugins/GoLani.KoreanModFix.dll
  3. Enjoy it!
