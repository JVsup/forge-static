Description Versions 8

SPT4+ Important Note

⚠️ WARNING: If you use ANY other mod that adds weapons, attachments or any profile interaction that is saved under Hephaestus trader, and these mods don’t use static/stable mongo IDs between versions, you will get crashes.

Example: If you have another mod with a custom suppressor with _id: 12345 and you use it as a custom weapon build, then the suppressor mod gets updated and the _id becomes 78854 — everything will crash. You have to clear the defective item from your profile.

💡 Note: Hephaestus works ONLY with static/stable mongo IDs. Which means they dont change when the mod author updates their mod.

Compatibility

🔴 The C# version is only compatible with 4.0.3+ (you will get errors with previous versions)

Configuration

📢 Due to public “outrage” (one singular individual told me so), I’ve noticed that the presets are cheap and who even uses euros lol.

NEWSFLASH: There is a config file for price adjustment and currency selection!

External JSON Files

✅ You can add external JSON files now:

  1. Copy the desired userbuilds.weaponBuilds to an independent .json file
  2. Put the file in the presets directory
  3. The file format should match the expected structure

📝 You can have multiple files, and each file can contain multiple presets.

Troubleshooting

Issue Solution
🔸 Don’t want additional presets Delete all contents of the presets directory
🔸 Trader is empty Make sure your profile has weapon presets OR you have external files
🔸 Doesn’t show latest weapon changes Click the Refresh Store button next to trader thumbnail

Installation

Follow the standard installation guide as instructed.

💡 If you have many traders, you may need the Trader Scroller from KAENO
