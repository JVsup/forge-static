Description Versions 7

Adds a caliber label below the short name for ammo & ammo boxes.

It also adds caliber labels to weapons, magazines, in-raid items, along with AmandsSense support, alternative ammo sorting, and show names in trading.
It’s easier to check in the settings - you can turn off everything you don’t need.

Show Names in Trading:

Hold a key at a trader to show item names instead of prices.
Default: Left Alt. Containers are not supported.

Ammo Sorting:

Added primary and secondary sorting with ascending/descending selection.
Tertiary sorting is always alphabetical. Sorting also applies to traders.

Sort modes:

  • Caliber - sort by caliber type
  • Alphabetical - sort by ammo name
  • Count - sort by ammo/box count
  • Rarity - sort by rarity from Item Info (can be changed in advanced mode)
  • Damage - sort by ammo damage value
  • Penetration - sort by ammo penetration power
