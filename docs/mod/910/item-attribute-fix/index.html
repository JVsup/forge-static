Item Attribute Fix

A universal fix for item attribute tooltip not being updated when the attribute has changed while the inspection window is open.

IcyClawz

Installation:

Extract the ZIP to your SPT-AKI installation folder.

Description:

The tooltip shown when hovering over an attribute in the item inspection window is static by default.

In order to update it after an item has been changed (e.g. ammo added to a magazine, mods attached/detached to/from gear, etc.), the inspection window has to be closed and reopened.

This simple client-side mod updates the tooltip’s text the moment the attribute is being updated.

This fix can be used with any mod that utilizes the attribute tooltips (“FullStringValue” field of “ItemAttributeClass”).

This fix was initially made as a companion to my “Item Sell Price” and “Magazine Inspector” mods.
