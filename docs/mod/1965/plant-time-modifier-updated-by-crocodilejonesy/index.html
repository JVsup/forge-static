Plant Time Modifier - Updated by CrocodileJonesy

An update for the original plant time modifier mod that allows you to set the time it takes to plant items for certain quests, you can adjust it to be either quicker or slower.

Description Versions 4

This is the plant time modifier mod updated to work with the current SPT version, since I thought to have a go at modding I chose this mod to start since it is a very useful mod (and since it hasn’t been updated).

Credits go to the original creator Utjan, you can find the original mod here.

If Utjan would like me to remove this, or the original mod gets updated, then I shall do so.

I have tested it and it works as intended, if there are any issues let me know and I will look into it when I can. Enjoy

Installation is simple just extract the zip to your SPT installation folder.
