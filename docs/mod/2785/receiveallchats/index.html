Overview

A simple mod that makes the “Receive all” button in the messenger actually collect all attachments from all chats.
Particularly useful for users of the mod Stat Rewards by Chazut who constantly have to collect lots of attachments.

Thanks to the new server component, retrieval now happens instantly, regardless of the number of messages.

Installation

As usual, unzip to your SPT directory

Let me know if you run into any problems or have suggestions for improvement.
