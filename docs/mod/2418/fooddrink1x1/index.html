Description Versions 1

Simple mod that changes the size of all Food and Drink items to 1x1.

You can set certain items to be ignored — just add their IDs to the exclude.json file in the /config folder.

Example of an excluded item listed in exclude.json: Canister with purified water (5d1b33a686f7742523398398)

This mod also affects item sizes from other Food and Drink mods, like WTT - Corner Store.

❗NOTE: EFT caches your item icons. If something looks off, press the “Clean Temp Files” button in your SPT launcher to fix it.

📁Installation

  • Drag folder from zip file directly into your SPT install folder
