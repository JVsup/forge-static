SPT Mods Installer

A simple little application that allows drag-and-dropping mods in zip formats.

Description Versions 2

Simple installation guide:

  • Download the app from the blue button next to the title.
  • Extract SPT Mods Installer.exe to any existing SPT folder (same place as EscapeFromTarkov.exe).
  • Run SPT Mods Installer.exe.
  • Drag and drop any compressed archives into the application (supported extensions: .rar, .zip, .7z).

Caveat

This tool has no safeguards against how many mods you run through it. If it freezes while installing a mod, it is working as intended. Please be patient.
