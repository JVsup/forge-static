Overview

A full rework of the original CNN-Containers mod, ported and updated for SPT 4.0.X.

Adds 9 specialized containers for organizing your stash and taking essential supplies into raids, tiered across trader loyalty levels so new players get affordable starter storage while larger containers are gated behind higher loyalty.

All containers are configurable via a config file. You can enable/disable individual containers, adjust trader prices and loyalty levels, resize container grids, set custom flea market prices, add extra allowed/excluded item filters, and rename/translate containers.

Updating from a previous version? Check the Update Notes tab first — some versions have important warnings.

Installation

1. Download and extract the mod zip into your SPT directory.

2. Launch the game.

Updating

1. Download and extract the mod zip into your SPT directory, overwriting when prompted.

2. Open the SPT launcher’s settings and click “Clean Temp Files” before launching.

Before updating: read the Update Notes tab for any version-specific warnings, and back up your profile and config/config.jsonc if you’ve customized them.

Update Notes

v4.4.0

  • The Secure Mapbook’s internal storage changed (this fixes the map-duplication bug). Any maps left inside a mapbook will be permanently deleted on update. Move all maps out into your stash before updating, then put them back afterwards — empty mapbooks are unaffected. If you’ve already lost maps, they can only be recovered from a profile backup made before the update (restore it, downgrade to v4.3.0, empty the mapbook, then re-apply v4.4.0).
  • The Onyx can now be bought for dollars only (no Kappa needed), in addition to the existing Kappa barters.

v4.3.0

  • The config format was completely reworked. Each container is now a multi-line block instead of a single line, and settings from an older config.jsonc will not carry over — you’ll need to re-apply your customizations in the new format. Back up your old config for reference before overwriting, then edit the new one.
  • New config options were added: custom flea prices (fleaPrice), extra allowed item filters for mod compatibility (extraFilters — Pack ‘n’ Strap is pre-added to the Gear Box), extra excluded filters to block items (extraExcludedFilters, handy for the Wooden Box which accepts everything by default), and name / short-name / description overrides per container.
  • Containers were rebalanced. Trader prices, loyalty levels, and some grid sizes changed — containers are now properly tiered across loyalty levels 1–4 (previously most were sold at LL1).
  • Fixed vanilla case nesting so the containers sit correctly inside vanilla cases.
Configuration

Edit config/config.jsonc to customize the mod. You can:

  • Enable or disable individual containers
  • Change trader prices and loyalty levels
  • Resize container grids (except the Mapbook, whose cells are generated automatically, one per map)
  • Resize each of the Onyx’s 3 grids independently
  • Set the price of the Onyx dollars-only barter (optional dollarOnlyPrice; omit to use the default $501,437)

Example — changing the Onyx dollars-only price: this line isn’t in the config by default. To change it, add dollarOnlyPrice under the onyx block (a commented-out example is already there):

"onyx": {
    "enabled": true,
    "dollarPrice": 85259,
    "loyaltyLevel": 4,
    "grid1H": 2, "grid1V": 3,
    "grid2H": 3, "grid2V": 4,
    "grid3H": 1, "grid3V": 2,
    "dollarOnlyPrice": 750000   // <-- add this line to set your own price
}
  • Set custom flea market prices (separate from trader prices)
  • Add extra allowed item filters per container (for mod compatibility, e.g. Pack ‘n’ Strap)
  • Add excluded item filters (e.g. block specific cases from going inside the Wooden Box)
  • Rename or translate container names, short names, and descriptions

Optional settings are commented out below each container in the config - just uncomment and edit.

WARNING: Disabling a container or changing its grid size after you’ve already used it in your profile (items stored inside) can cause profile corruption or item loss. Only change these settings on a fresh profile or after emptying the affected containers.

Containers

Tier 1 — Starter storage:

  • Recycled Ammo Bag (2x2)

    • Holds ammunition, fits inside Secure Containers.
    • Trader: Prapor LL1 - 75,000₽

  • Recycled FAK (3x3)

    • Holds medical items, fits inside Secure Containers.
    • Trader: Therapist LL1 - 85,000₽

  • Small Portable Fridge (2x3)

    • Holds food items, fits inside Secure Containers.
    • Trader: Jaeger LL1 - 38,000₽

  • Small Toolbox (4x6)

    • Holds tools/barter items.
    • Trader: Skier LL1 - €500

Tier 2 — Mid-level storage:

  • Mod Case (6x5)

    • Holds weapon mod items.
    • Trader: Peacekeeper LL2 - $1,200

  • Secure Mapbook (per-map)

    • Holds one of each map, fits in Secure Containers and Special Slots. Cannot be insured (like all storage cases).
    • Trader: Therapist LL2 - 65,000₽

  • Ruined Wooden Box (8x6)

    • General-purpose storage crate that accepts any item.
    • Trader: Jaeger LL2 - 1,000,000₽

Tier 3:

  • Gear Box (10x8)

    • Holds clothing (vests, rigs, backpacks, etc).
    • Trader: Ragman LL3 - 850,000₽

Tier 4:

  • Secure Container Onyx (2x3 + 3x4 + 1x2)

    • Premium secure container with 3 grids. Follows default excluded items.
    • Trader: Peacekeeper LL4

    Offered three ways: barter with the Kappa + $85,259, barter with the Desecrated Kappa + $85,259, or dollars only for $501,437 (no Kappa required).

Known Issues
  • The Mod Case and Ruined Wooden Box models display with pink/purple textures (missing shaders). The bundles were built for an older Unity version and need to be recompiled for SPT v4.0’s Unity version. Functionally they work fine.
  • v4.4.0 reports its version as 4.3.0 in the server console (a hardcoded version string i forgot to modify). This is cosmetic only, the release is the correct v4.4.0 build. Already fixed in the code and will report correctly from the next release.

⚠️ PLEASE READ BEFORE UPDATING !! ⚠️

SECURE MAPBOOK STORAGE HAS CHANGED

EMPTY YOUR MAPBOOK BEFORE UPDATING!

The Secure Mapbook’s internal storage changed from slots to grid cells in this version (this is the fix for the map-duplication bug). If you have any maps stored inside a Mapbook in your profile - you MUST move them into your stash before updating. Failing to do so will result in those maps being deleted the first time the updated mod loads your profile. Only the Mapbook is affected this time - all other containers are untouched.

If you didn’t, and your maps have vanished - you have options:

  1. restore a profile backup from before the update, revert to CNN-Containers v4.3.0, move the maps into your stash, then update to v4.4.0.
  2. just re-buy them from Therapist / the flea, or send them to yourself with a dev profile - maps are cheap enough.

New Features

  • Onyx dollars-only barter. Peacekeeper now offers the Onyx a third way - for dollars only, no Kappa required ($501,437 by default). Added for players who need to keep their Kappa to prestige. The existing Kappa and Desecrated Kappa barters are unchanged.
  • Added optional dollarOnlyPrice config key (under onyx) to set the price of the dollars-only barter. You only need to add 1 line if you want to change it - see the config tab for a usage example, current configs remain unaffected.

Mapbook Changes

  • Fixed map duplication through insurance. The Mapbook is now a proper grid container (one cell per map) instead of slot-based. Slotted contents were being treated as attachments and duplicated on insurance return; grid contents are not.
  • Maps are now discovered automatically from the game, so maps added by other mods (e.g. DynamicMaps) get a cell without any manual setup.
  • As a proper storage case, the Mapbook can no longer be insured - this is expected EFT behaviour for all cases, and it’s what makes the duplication impossible.
  • Load order adjusted so map-adding mods are picked up before the Mapbook is built.

Config

  • Blanked or zeroed price / grid values now fall back to sensible defaults instead of 0, so a mistyped config can’t create a free or zero-size item.

Bugfixes / Maintenance

  • Removed dead code and corrected some internal comments (Gear Box trader label, Mapbook exclusion).
  • Release builds are now produced automatically, so every version ships a consistent, tested zip.
