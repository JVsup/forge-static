FikaSync

A simple tool for sync your game profile with friends via GitHub.

Description Versions 5

FikaSync is an automated tool developed for me and my friends. It allows you and your friends to easily synchronize game profiles when launching a server via a private GitHub repository. (The repository acts as cloud storage for all your profiles.)

Features

  • No Manual File Transfers: Eliminates the need to manually send profiles to the host or transfer them back to clients after the game. Each player’s progress is automatically updated on the server.
  • .fikaignore Support: Full control over your shared data. List specific profile files or directories in a .fikaignore file (similar to .gitignore) to prevent them from being uploaded to the shared repository (e.g., for keeping a solo profile private).

How It Works

  1. The host launches FikaSync. The tool downloads the latest profiles from the repository, ensuring that the host’s local profiles are up to date for all participants. It then automatically launches SPT.Server and SPT.Launcher.
  2. Play together enjoy the session. All local profiles are saved as usual.
  3. After the session, the host closes FikaSync. The tool automatically commits all changes made to the profiles and sends them back to the shared repository.
  4. If the host changes to another person, the host launches FikaSync. It will download the latest new profiles from the repository to your local computer, saving your progress.

Prerequisites

  1. Need to install .NET 9 (If you have a working SPT, you don’t need it.)
  2. A Private GitHub Repository to store the profiles. (Only one person needs to create a repository.)
  3. A GitHub Fine-grained Personal Access Token with Contents -> Read and Write permissions (scoped specifically to your repository).

How to Create Private Repository

  1. You need to be loggined in Github
  2. Go here Create repository
  3. Give any name to the repository
  4. Choose visibility to Private
  5. Click Create repository

How to get Fine-grained Personal Access Token

  1. You need to be loggined in Github
  2. Go here Personal Access Tokens
  3. Click Generate a new token
  4. Give it any name
  5. Select the token expiration date (usually 30 days, after which it will expire)
  6. Below, select Only select repositories and choose your repository (if you don’t have it, you need Create repository)
  7. Below, add the Contents permission
  8. For the contents permission, make sure that Read and Write rights are enabled!
  9. Click the Generate token button

FAQ

Q: Do my friends need to create repositories and configure FikaSync?

A: No, only one person needs to create the repository! When you first launch FikaSync, it will ask for a GitHub token and the repository URL (it will then be saved in the .env file, where you can edit it if necessary). Once everything is set up, you can simply send your friends the ready-made .env file, which will already contain the token and repository link. (The .env file is located in the same directory as FikaSync.exe.)

Q: Do I need FikaSync if my friends and I have a separate dedicated PC/VPS with SPT Server running 24/7?

A: No, you don’t need it. It’s necessary for those who have different hosts. Today, a friend with a powerful PC launches a server, tomorrow you want to play alone, but with up-to-date profiles, without transferring your profile from his PC to yours.

Getting Started

1. Installation

Download the latest FikaSync.exe Important: Place the executable inside your root game folder (right next to EscapeFromTarkov.exe).

2. Configuration

When you first launch the app, you will be prompted to enter your GitHub token and repository URL or you can create a file named .env next to the executable (.exe). Open it with Notepad and add your settings:

# Your GitHub Fine-grained Token
GITHUB_PAT=github_pat_...

# The HTTPS URL of your private repository
REPO_URL=https://github.com/YourUsername/Your-Repo-Name

Usage

  1. Run FikaSync.exe.
  2. Wait for the tool to sync profiles and launch the server.
  3. Play the game!
  4. When you are done playing, close the game and press [ENTER] in the FikaSync console window to upload your progress to the repository.
