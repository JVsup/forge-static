Auto Shoulder Swap

So, what is this?

Inspired by HollywoodCam which is created by the almighty Janky, I created this little offshoot mod as a standalone for those who, like me, only used HollywoodCam for the leaning. The configuration is more or less the same, with some variation; lean-shoulder-swapping works while you’re aiming with this mod. I have not noticed any problems with leaning during ADS, so I left it in.

Installation
  • Extract the BepInEx folder into your source / root SPT folder, where SPT.Server is.
Features & Showcase
  • Syncing of left leaning and shoulder swapping;
    • Works for going into and out of a lean, and sync can be disabled independently;
  • Disable leaning when in ADS;
  • Disable leaning when in ADS only if in ADS with a magnified optic
    • This feature only works if the first ADS feature is active
