Add Secret Exfil Notes to Caches

Simple mod that adds the Secret Exfil Code Notes to Barrel/Wood caches as well as dead PMC/SCAV bodies on maps that have Secret Exfils. At the configurable rate that you choose.

Description Versions 2

Very simply allows configurable chance for each maps specific Secret Exfil Code Note to spawn in certain containers.

Included containers are Barrel Caches, Wood Caches, and Dead PMC/SCAV bodies.

The Secret Exfil Code Notes will only spawn on the map that requires it to use the Secret Exfil.

Right now, you can really only get these if you hunt the boss for the map. That’s not very cool, and they should also be found in loot. Now they can.

Default Values

Chance: 5%

Installation
  1. Download Add Secret Exfil Notes to Caches
  2. Open the downloaded zip file
  3. Select the SPT folder in the zip file
  4. Drag the SPT folder from zip file into your root SPT folder

UNINSTALLATION

  1. Delete /ROOTSPT/SPT/user/mods/acidphantasm-addsecretexfilnotestocaches
