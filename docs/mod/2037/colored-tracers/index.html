Description Versions 6

In the heat of battle, quickly determine who poses the real threat. Red tracers from the right - just Scavs. Green tracers from the left - PMCs. But from the center, someone is firing violet tracers at you… It’s clearly Birdeye.

You don’t even need to see your enemies - just a split second, and you already know everything. Now you can plan accordingly… This raid is yours to win!

Features

  • Coloring tracers:
    • Based on either bullet damage or penetration
    • With linear rainbow color scale (red-worst, violet-best)
    • With 7-steps color profile with rainbow or customizable colors
    • Single color that can be added based on bullet category
  • Option to invert scales (violet-worst, red-best)
  • Option to color bullet to random color

Choose your preferred mode in the config file

Screenshots

Rainbow Color Scale

The mod uses a rainbow scale to represent bullet values:

Red → lowest value

Orange / Yellow / Green / Blue → average value

Violet → strongest value

This allows you to instantly judge ammo performance just by looking at tracer color!

Compatibility
  • Compatible with all mods that add new bullets or calibers
  • Realism compatibility is planned for a future update
