Original Mod by Tyrian: De-Hazardifier

Additional thanks to CJ for maintaining up until now.

How to Use - Everything is within the F12 Bepinex menu.

The de-hazardifier enabler must be enabled before going into a raid, it won’t gather the visual objects of the claymores and barbed wire if it’s not enabled upon map start.

Features:

  1. Sniper Zone Removal: Removes the auto-kill sniper boxes around extracts on maps like streets.
  2. Minefield Zone Removal: Removes the auto-kill minefield zones around on certain maps like lighthouse, woods, etc.
  3. Claymore Removal (Included Visual remover): Remove the physical claymores/directional mines on maps like streets, etc.
  4. Barbed Wire Removal (Included Visual remover): Remove the physical barbed wire hazards.
  5. Fire Damage Removal: Removes the damage taken while standing in fire hazards.

For any Issues, please leave a Comment, Create an Issue on the Github or message me via Discord: tetris
