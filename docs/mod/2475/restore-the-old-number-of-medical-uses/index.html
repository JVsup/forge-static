Description Versions 1

Restores the old number of uses of medicine, namely:

  1. CMS surgical kit (3 -> 5).
  2. Surv12 field surgical kit (9 -> 15).
  3. Ibuprofen painkillers (8 -> 15).
  4. Vaseline balm (3 -> 6).
  5. Golden Star balm (5 -> 10).
  6. Aluminum splint (3 -> 5).
