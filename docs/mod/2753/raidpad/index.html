RaidPad — Controller / Gamepad Support for SPT

Play all of SPT with a gamepad — in raid and in the menus. RaidPad brings full controller support to Single Player THE CITY: movement, aiming (with optional aim assist), shooting, leaning, stances, weapon handling, complete controller-driven inventory & UI navigation, and full control of the main menu and every out-of-raid screen. Put the mouse and keyboard down and run your whole session from the couch.

RaidPad is a community revival of the original AmandsController by Amands2Mello, updated and fixed to run on SPT 4.0.x — see Credits.

What it is

RaidPad maps a controller onto every part of the game.

  • In raid you get the full FPS control set — move, look, fire, ADS, lean & step-peek, crouch/prone, walk-speed, weapon switching and the whole weapon-handling suite, quick slots, grenades and healing.
  • In any in-raid window (your stash, gear, containers, grids, context menus, split dialogs, search, trading) the same pad drives the entire interface cell-by-cell, with on-screen button hints so you’re never guessing.
  • Out of raid — main menu, hideout, stash, traders, flea market, settings — your pad drives a cursor across the whole interface, so you never have to reach for the mouse to get into a raid in the first place. EFT’s own pointer is shown while the menu cursor is active, with an optional crosshair overlay as a fallback for exclusive-fullscreen setups.

It’s a client-side BepInEx plugin. No server module, no profile edits — install it, plug in a pad, and play.

Controller support

  • Xbox / XInput controllers work out of the box.
  • PlayStation pads (DualShock 4 / DualSense) work plugged straight in — no DS4Windows, no Steam Input required. A built-in raw-HID backend reads the pad over USB or Bluetooth and feeds it through the input system. DS4Windows and Steam Input still work if you prefer them.

Features

  • Full in-raid control — movement, look/aim, fire, ADS, lean & step-peek, crouch/prone, walk-speed, weapon switching and the whole weapon-handling suite (reload, check ammo/chamber, fire mode, fold stock, scopes, tactical devices, headlamp/NVG).
  • Quick slots & gear on modifiers — hold a shoulder button to reach med/stim slots, grenades, primary/secondary weapon selection, drop backpack, goggles and more.
  • Complete in-raid UI navigation — drive your stash, gear, containers, grids, slots, context menus, item split, search and trading entirely from the pad, including drag-and-drop with rotate & split.
  • Out-of-raid menu cursor — the pad drives the Windows cursor across the main menu and every out-of-raid screen, including drag-and-drop and item rotate.
  • Native PlayStation support — DualShock 4 / DualSense over USB or Bluetooth, no extra software.
  • Optional aim assist — magnetism, stickiness and auto-aim, each individually tunable (or fully disabled). Off by default.
  • On-screen button hints — contextual button-block prompts while in menus.
  • Xbox & DualSense icon sets — switchable in the config.
  • Fully configurable — deadzones, sensitivity, invert-Y, double-click/hold timing, UI stick assignments, cursor & scroll speed, rotate key, hint placement and more, all via the in-game F12 menu (BepInEx ConfigurationManager).

Requirements

  • SPT 4.0.13 (built and tested against this build; EFT 0.16.9.x).
  • A supported controller:
    • Xbox / XInput controllers work out of the box.
    • PlayStation pads (DualShock 4 / DualSense) work natively — just plug them in over USB or Bluetooth. DS4Windows and Steam Input are no longer required (though still supported if you prefer them). USB is the most reliable connection; Bluetooth is fully supported.
  • BepInEx (already included with SPT).

Installation

  1. Download the latest release.
  2. Extract the archive into your SPT install root so the BepInEx folder merges in. You should end up with: 
    <SPT>\BepInEx\plugins\RaidPad.dll
<SPT>\BepInEx\plugins\SharpDX.dll
<SPT>\BepInEx\plugins\SharpDX.XInput.dll
<SPT>\BepInEx\plugins\RaidPad\        (images, layouts, sounds, Default.json)
  3. If you have the old AmandsController installed, remove it — running both at once conflicts (they patch the same methods).
  4. Connect your controller, launch SPT — your pad drives the menus right away, and the full control set the moment you load into a raid.
  5. Press F12 in-game to open the config and tune deadzones, sensitivity, aim assist and cursor speed.

Configuration

All settings live under the F12 ConfigurationManager overlay, grouped into: RaidPad, Menu Cursor, Inputs, Aim, Aim Assist, Movement, UI, UI Selected Box, UI Button Blocks.

  • Aim assist is off by default — enable and tune magnetism / stickiness / auto-aim there if you want it.
  • User Index selects which XInput slot to read. Default 0 = Auto — scans all slots and picks the first connected pad (recommended; required for DS4Windows / Steam Input / virtual pads that may land on any slot). Set 1–4 to pin a slot. Native PlayStation pads are detected automatically and ignore this setting.
  • Menu Cursor — toggle out-of-raid cursor control, set cursor & scroll speed, the crosshair-overlay fallback, and the Rotate Key (the keystroke X / Square sends to rotate a held item — must match EFT’s “Rotate item” bind, default R).
  • Deadzones & timing — left/right stick, triggers, double-click and hold delays are all adjustable.
  • DualsenseIcons — switch on-screen prompts between Xbox and DualSense glyphs.
  • UI stick assignments — choose which stick scrolls, moves windows and skips through the interface.

Known notes

  • If a specific interaction misbehaves, please report it with your BepInEx\LogOutput.log.
  • A printable control-layout diagram isn’t bundled yet — contributions welcome.

Changelog

0.5.0 - Mounting, teammate-safe aim assist, menu rotate fix

  • Added weapon mounting on a controller. While aiming (ADS), click the left stick to mount on cover, windows and ledges.
  • Fixed aim assist no longer locks onto teammates. Players in your group (e.g. Fika squadmates) and downed players are excluded from aim assist. New toggle Aim Assist → ExcludeTeammates (on by default).
  • Fixed rotating items with the menu cursor. X / Square now reliably rotates a held item while you drag it in the out-of-raid menus. RaidPad now rotates the item directly instead of sending the R keystroke, which EFT ignores in menus.
  • Added interface navigation speed. New UI → InterfaceStickMoveDelay sets how fast stick-driven menu selection repeats (higher = slower), handy if you navigate the interface with a stick.
  • Note: clearing a weapon malfunction. EFT has no separate “fix malfunction” key; use the normal controls X (reload) for misfires, RB + X (check chamber / unload magazine) for jams.

0.4.7 — Rotate items in the menu cursor

  • Added: press X / Square while dragging an item in the out-of-raid menus to rotate it, so you can fit awkward items into your inventory without a keyboard. It sends EFT’s “Rotate item” keystroke (default R, configurable under Menu Cursor → Rotate Key). Right-click in the menus is now on RT only.

0.4.6 — Out-of-raid menu cursor

  • Added: the controller now works at the main menu and every out-of-raid screen. Out of raid, RaidPad drives the real Windows cursor — right stick moves, left stick scrolls, A/LT left-click (hold to drag), RT right-clicks, B is back/Escape. EFT’s own pointer is shown, with an optional crosshair overlay as a fullscreen fallback. Hands off to the native in-raid controls automatically on raid load, and resumes after.

0.4.5 — Bluetooth fix for native PlayStation pads

  • Fixed: a DualShock 4 / DualSense connected over Bluetooth registered no input (buttons and triggers did nothing). Over Bluetooth a PS pad powers up in a “simple” report mode and only sends its full report after the host requests a feature report — RaidPad now does this on connect, switching the pad into full mode. The report layout is also resolved per-report now, so a pad that changes mode mid-session is always read correctly. USB was unaffected. Confirmed working with a DualSense over Bluetooth.

0.4.4 — Native PlayStation controller support

  • Added: DualShock 4 and DualSense pads now work plugged in directly — no DS4Windows or Steam Input required. A new built-in raw-HID backend reads the pad over USB or Bluetooth and feeds it through the existing input system. DS4Windows / Steam Input still work if you use them. No extra files to install.

0.4.3 — Controller detection

  • Improved: controller slot detection is now robust. User Index defaults to 0 = Auto, which scans all four XInput slots and picks the first connected pad. This fixes pads that weren’t detected because a virtual Xbox pad (DS4Windows / Steam Input / ViGEm) landed on a slot other than the first.

0.4.2 — Grenade fix

  • Fixed: the grenade pull-out bind (hold LB + D-pad Up) only popped the on-screen grenade quick-select bar without actually pulling out a grenade. EFT 0.16.9 split the grenade input into two separate commands, and the old one no longer equips — the bind now sends the new “press throw grenade” command. Works with grenades in pockets or rig. Thanks to PapaCrawl and redlaser42 for reporting.

0.4.1 — Button fix

  • Fixed: in-raid buttons and controller UI navigation did nothing on 0.4.0 (only stick movement worked). The 0.4.0 rebrand renamed the binding classes but Default.json kept the old key names, so no button bindings loaded. Renamed the keys to match — all controls work again. Thanks to the players who reported it.

0.4.0 — SPT 4.0.x revival

  • Updated to build and run on SPT 4.0.13 (EFT 0.16.9.x).
  • Fixed: the input loop never ran on EFT 0.16.9 because the controller component was hosted on a standalone GameObject that got destroyed before Unity started ticking it — it now lives on the plugin’s persistent object. (This was the “loads but can’t move” bug.)
  • Fixed: discard-limit guard in quick-move/equip (ItemsDestroyRequired changed from a field to a property in 4.0.x).
  • Rebuilt against current SPT/EFT/Unity assemblies; verified all Harmony patch targets and reflection lookups resolve on 4.0.13.

0.3.9 and earlier

  • Original AmandsController releases by Amands2Mello (SPT ≤ 3.11).
