Ultimate Loot Editor

Ultimate Loot Editor is an in raid loose loot editor. It lets you visualize loose loot spawn points, inspect what can spawn there, adjust spawn chances and item weights, and add or remove items.

Features

  • View loose loot spawn points in raid as spheres.
  • Open a spawn point editor while standing and looking at a sphere.
  • Edit spawn chance.
  • Add or remove possible loot items.
  • Change individual item weights.
  • Compare edited loot against vanilla loot.
  • Revert a spawn point back to vanilla.
  • Edit supported items such as weapons, armor, and helmets.
  • Automatically handles compatible ammo for magazines/weapons.
  • Saves map edits as JSON files that can be shared or manually edited.
  • Supports modded items, weapons, armor, and helmets.

How to use

I recommend you configure the raid to disable AI first. Once in raid, the default bind is F9 to enable the visualization of spawn points. Find a spawn point you want to edit, and press Mouse button 4 by default to open the editor. The binds and the UI can be changed in the F12 menu. Once you have made the changes that you want to spawn points, you can extract and requeue into the map, there is no need to close the game for the spawn changes to take effect.
