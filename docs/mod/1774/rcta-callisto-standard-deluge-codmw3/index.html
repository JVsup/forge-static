Mod Description

  • I was considering porting ALL operator skins for Callisto but most have too much gear on, maybe at a later date I’ll look into it. Hope you enjoy! Sorry about the darker textures on some materials, it’s a cod thing. The “empty” head by the way is for wearing any head-gear to prevent clipping!
