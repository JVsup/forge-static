Hideout Automation

This mod automates hideout crafting, constructions, upgrades and installations. Stack crafts. Optionally choose which requirements to skip. FIKA is supported.

Description Versions 9

Tired of spending too much time in menus?

New Features (Experimental):

  • (Crafting) Production stacking (Queue multiple productions) When one finishes, the next starts automatically.
  • Requirements are paid upfront when stacking.
  • Automation only runs while in-game (and not in raid).
  • Tools are only required once for the full production stack.
  • Automatically moves produced items to stash.
  • Stack button instead of Start button.
  • Shows stacked amount and total amount in production.

This mod automates several hideout-related action to streamline your experience:

  • Automatically construct when requirements are met (default: on)
  • Automatically upgrade when requirements are met (default: on)
  • Automatically install construction or upgrade when completed (default: on)
  • Use a dialog window to accept the costs and requirements of the construction or upgrade (default: on)

Tyfon-HideoutInProgress (HIP)

  • (Experimental) HIP mod support. If you have HIP mod installed the HideoutAutomation mod will automate the contributions to HIP.
  • (Option) to enable the automated contributions to HIP. When disabled the mod wont do anything for HIP.
  • (Option) to only contribute when Area Requirements are met. (default: on) When enabled, automated contributions are made only after all required items are collected. Partial amounts will no longer be contributed.

Remove requirements

  • Inspired by the Skipper mod by Terkoiz (for tasks), the mod adds the ability to automatically remove requirements of the construction or upgrade costs.

You can toggle the following requirements types: (all default to on)

  • Remove other area requirements.
  • Remove currency* requirements.
  • Remove skill requirements.
  • Remove trader requirements.
  • Remove item requirements. *currency requirements are: Rubles, Dollars and Euros. Switching these settings pops up a dialog for your game to reload so the hideout shows the correct requirements.

Usage

The mod starts working from the start of the game.

Installation:

  1. Download the mod file using the button above.
  2. Open the downloaded archive.
  3. Drag the BepInEx folder into your SPT installation directory.
