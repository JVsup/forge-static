Description

Automatically adjusts your scope’s zeroing/BDC calibration to match the actual distance to whatever you’re aiming at while ADS — no more manually scrolling through zero distances mid-fight.

Features

  • Auto-detects distance via raycast while aiming down sights, updates your scope’s calibrated distance in real time
  • Manual mode available — disable auto-ranging and use a keybind instead (default Alt+R)
  • Master on/off toggle
Install Instructions
  1. Extract the archive
  2. Drop the BepInEx folder into your SPT root directory
  3. Press F12 to toggle Auto Range on/off, or switch to manual keybind mode
