Cultist Circle Improvements

Fine tune your Cultist Circle, change all the values and timers. Add new direct reward crafts! Also comes with a web config, which at this point is probably expected from me. Oof.

INSTALLATION

Installation

  1. Download Cultist Circle Improvements
  2. Open the downloaded 7z file in 7-zip
  3. Select the SPT folder in the 7z file in 7-zip
  4. Drag the SPT folder from 7-zip into your root SPT folder

Demonstration Video (yoink):

UNINSTALLATION
  1. Delete /ROOTSPT/SPT/user/mods/acidphantasm-cultistcircleimprovements
  2. Done
CONFIG

Configuration

To edit the configuration run your server after installing and go to:

  • https://127.0.0.1:6969/cci/

All configs can be updated and edited while the server is running.

If you are using Fika then put the appropriate IP and port instead.
