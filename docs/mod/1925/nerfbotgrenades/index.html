Description Versions 2

Tired of bots with insane grenade accuracy? This mod allows you to multiply their inaccuracy when throwing grenades. Each bot by default has a very small inaccuracy offset when throwing a grenade, however it is so minor that it is barely noticeable. This mod lets you tweak this value up to 10x.
