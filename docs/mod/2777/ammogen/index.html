AmmoGen - Custom Ammo Framework

AmmoGen is a server-side framework for SPTarkov that lets anyone create custom ammo, ammo boxes, and loot injections using simple JSON packs, no programming required.

What It Does

  • Loads ammo packs from user/mods/AmmoGen/ammo/
  • Clones existing ammo templates and overrides stats, names, prices, and stack sizes
  • Registers custom ammo with the item database, handbook, and flea market
  • Adds ammo to vanilla traders with optional custom ammo box listings
  • Adds workbench crafting recipes with searchable item requirements
  • Patches magazine and weapon filters so the new ammo fits existing gear
  • Injects custom ammo and boxes into container loot tables
  • Handles all item registration and validation internally

Web Tool

Create ammo packs visually with the AmmoGen Tool — pick a base ammo, tweak stats, configure traders/crafting/loot, and export a ready-to-use zip.

Installation

  1. Drag the SPT folder from the mod archive into your SPT installation directory.
  2. Start the server. AmmoGen loads automatically and waits for ammo packs.

Making an Ammo Pack

  1. Open the AmmoGen Tool.
  2. Select a base ammo template, set your custom stats, name, and description.
  3. Configure traders, crafting, magazine/weapon filters, ammo boxes, and loot as desired.
  4. Click Export to download a zip.
  5. Drag the SPT folder into your SPT install to test (ALWAYS use a new temporary profile when testing).

Tip: Always test on a new developer profile so you can verify trader purchases, crafting, and loot without affecting your main save.

Publishing an Ammo Pack

The AmmoGen Tool export zip is already structured for distribution, users just drag the SPT folder into their install directory.

When publishing:

  1. State the dependency: Your add-on pack requires AmmoGen v2.0.1 for SPT 4.0.13.
  2. Do not include the AmmoGen DLL or other authors’ packs in your zip.
  3. Test by extracting and running the server before publishing.

Dependencies

  • SPTarkov 4.0.13

New features

  • Ammo stats: added many more ammo properties to the mod (projectile, malfunctions, tracer, audio/visual, explosive, light & sound, and area effect stats). The tool now exposes these in the ammo editor with collapsible sections and dropdowns where appropriate.
  • Grenades: added grenades as a second item type, alongside ammo. Supports cloning base grenades, custom explosion/effect/throw stats, smoke/body colors, and smoke settings. The tool has a full grenade editor with matching tabs and a color picker.
  • Flares (WIP): added flares as a third item type. Supports handheld flares and signal pistol cartridges, with custom flare types, colors, and effects. The tool has a flare editor and a WIP banner because the in-game special/handheld slot behavior is still being worked out.

Tool improvements

  • New mode switcher in the header to swap between Ammo, Grenade, and Flare editing.
  • Grenade and Flare editors reuse the existing Economy, Trader, Crafting, and Loot tabs.
  • Color picker for tracer, smoke, body, and flare colors.

NOTE: Grenades or flares with custom emission color require the Color Converter API
