Description

Overview

Brings Tarkov’s recoil back to roughly how it felt pre-12.12.

The climb is hard and mostly vertical — the kind you learn to pull down through rather than get handed back. The lateral component is small, so the gun stops skating left and right under sustained fire. The first shot of a pull lands heavy, which means a tap still costs you something.

There’s nothing to configure and that’s on purpose. This isn’t the sandbox build with sliders on an F12 page. The values are the ones I landed on after a lot of raids and they’re compiled in. Drop it in and shoot.

How it works

It shapes the recoil impulse as each shot lands, then lets the game spring the weapon back on its own. That part matters. The usual failure mode for a recoil mod is leaving the weapon model undriven, and you end up with a gun that floats or detaches on screen. This doesn’t touch that path.

Only your own weapon is affected, and it’s all computed on your client.

Installation

Requirements

None.

Steps

  1. Download the archive.
  2. Extract it into your SPT folder — the one holding EscapeFromTarkov.exe and BepInEx.
  3. Merge when Windows asks. Pre1212Recoil lands in BepInEx/plugins.
  4. Launch.

Client-side only. Nothing goes in user/mods.

Configuration

None. No config file, no F12 page. The tune is baked into the build.

Compatibility

Other recoil mods

Don’t run it alongside another recoil mod that touches the same shot effect. They’ll both patch it and fight.

Fika

Fine in a group. Only your own weapon is affected and it’s computed on your client, so nobody else needs it installed.

Game version

Built against SPT 4.0.13 / EFT 0.16.9.

One of the two hooks lands on an internal method whose name isn’t stable between game builds, so a Tarkov or SPT update can stop it loading until it’s recompiled. Pin your install, or grab a build that matches your version.

A packaging fix. Nothing about the recoil has changed — if 1.0.0 is installed and working for you, there’s nothing in here you need.

1.0.0 was packed with Windows path separators, which meant:

  • On Linux and Proton, extracting the archive produced one oddly-named file instead of installing the plugin, so the mod simply never loaded and there was no error to tell you why. That’s what this fixes.
  • On Windows it installed correctly, but it also dropped a loose README.md and LICENSE into your SPT install root. Both are safe to delete.

If you’re on Linux and 1.0.0 never seemed to do anything, this is why.
