Overview

Did you ever accidentally hit Esc during a raid and got killed while you were staring and waiting for the Menu to open?
For whatever reason BSG decided to run the post-raid cleanup not on post-raid (why would you?) but upon entering the Main Menu.

This simple mod disables the cleanup process when opening the menu during a raid; afterwards, it runs as usual.
It won’t affect performance, since you likely wouldn’t open the menu during a raid anyway.

Not needed with Fika; if it is installed nonetheless, it simply does nothing.

Installation

As usual, unzip to SPT folder.

Let me know if you run into any problems or have suggestions for improvement.
