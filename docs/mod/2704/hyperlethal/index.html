HyperLethal

HyperLethal is a server-side SPT mod that adds overpowered custom ammo across multiple calibers.

If vanilla ammo balance says “careful”.. HyperLethal says “full send.”.

This is my first mod and it’s still evolving. If you run into issues or strange behavior, please let me know. Thanks for your patience while I keep improving it.

What It Adds

  • Custom high-power rounds for multiple calibers
  • Trader assort integration (currently configured for Mechanic)
  • Data-driven setup via JSON files
  • (Pretty basic) browser editor at: https://127.0.0.1:6969/hyperlethal

Included in v.0.1.0

  • HyperLethal M995+
    Built in a garage with zero regard for treaties, the HyperLethal M995+ turns cover into a suggestion and bad decisions into instant lessons.

  • HyperLethal 9x19+
    Overclocked 9x19 with absurd punch and penetration for close-range chaos.

  • HyperLethal 9x18+
    A vicious 9x18 round that turns compact sidearms into pocket railguns.

  • HyperLethal .45 ACP+
    Heavy .45 ACP pressure-loaded into a brutal close-range armor chewer.

  • HyperLethal 5.45x39+
    A screaming 5.45x39 round built to punch through armor like it owes you money.

  • HyperLethal 7.62x39+
    A brutal 7.62x39 round tuned for extreme penetration and stopping power.

  • HyperLethal 7.62x51+
    A savage 7.62x51 NATO load built for ruthless long-range armor deletion.

  • HyperLethal 12/70+
    An overpressured 12/70 slug that hits like a sledgehammer through armor and flesh.

Built-In Web Editor

You can edit ammo and assort values without digging through files by hand.

Item editing

  • Name / short name / description
  • Damage
  • Penetration power
  • Armor damage
  • Fragmentation chance
  • Initial speed
  • Price / handbook price

Assort editing

  • Trader offer price
  • Loyalty level
  • Unlimited count toggle
  • Stack size
  • Buy restriction max

Technical Notes

  • Built with WTT-CommonLib
  • Loads custom items from db/items
  • Loads trader assorts from db/assorts
  • Structured to scale with one JSON file per caliber/item

Future?

  • Support all available ammo calibers over time.
  • Add other custom items (armor, medicals etc).
  • Custom textures?

Intended Experience

This is not a realism mod. It is a “what if every round was a bad idea in the best possible way” mod.
