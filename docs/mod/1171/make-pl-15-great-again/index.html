Because “The PL-15{…} features removable front and rear dovetail sight posts, completely interchangeable with sights designed for Glock pistols.”
  • Change the deviation (MOA) of the weapon

Installation

  1. Drag and drop the .zip file directly into the root folder of your SPT installation.
  2. Right-click the .zip file and select “Extract Here”.
  3. The folders should merge automatically. If you get a prompt to overwrite files, say yes.
