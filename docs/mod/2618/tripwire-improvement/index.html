Tripwire Improvement

Infinite tripwire kit, customize count down (instant explosion grenade), longer and freer placement

Description Versions 1

Change everything in F12 menu

  • Infinite tripwire
    Use one tripwire to plant grenade unlimited times.
  • Reduce Explosion Delay = 0~5s
    Only for tripwire grenades. Changing this will affect those planted before.
    Beware of Partizan! His F-1 has “3.5s - thisvalue” countdown.
    If higher than grenade fuse, it will detonate instantly.
  • Max tripwire planting length = 3~10m
  • Max tripwire planting height difference = 0.2~3m
  • Effective Seconds = 3600
    EFT default=300, after this second the grenade will fall to ground like defused.
    Changing this won’t refresh existed tripwire.

Fika compatible

All the host (Headless) and clients should install this mod, and using the same settings.
You can copy the configured BepInEx\config\ciallo.inftripwire.cfg to other client (headless) in the same path.
A bug in Fika (not caused by this mod): If one defuses the tripwire, others will act strangely on it.

How to install

Download the zip and copy(drag) the BepInEx folder in package, to your SPT main folder (where EscapeFromTarkov.exe locates)

To uninstall

Just remove the dll file in YourSPT/BepInEx/plugins/TripwireImprovement.dll
