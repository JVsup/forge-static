DO NOT INSTALL INTO YOUR USER/MODS FOLDER

FAQ: https://github.com/SkiTles55/SPT-AKI-Profile-Editor/blob/master/ENGFAQ.md

Require you to install:

  • .NET 9.0 Desktop x64
  • .NET 6.0 Desktop x64 (Only for app version below 4.0.1)

Capabilities:

  • Level, nickname, character voice
  • Switching between regular\ large pockets
  • Hideout building levels
  • Trader relationship levels
  • Quest statuses
  • Skill\ Mastering levels
  • Examined items
  • Removing\adding items in stash (WIP), adding money
  • Import\ export\ removing weapon builds

Features:

  • Simple, intuitive interface
  • Multilingual, with the ability to edit localization
  • Automatic backups every time you save your profile

How to use it ?

* Extract to any folder outside your SPT folder and run SPT-AKI Profile Editor.exe.

* Select your SPT Server folder

* Choose your account

* Make the wanted edits

* Click the save button
