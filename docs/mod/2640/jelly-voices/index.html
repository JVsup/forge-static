Jelly Voices

This is a mod that adds various voices to SPT. Over time as i find good clips I’ll flush out the voices more. Do let me know if there are any problems also the voices are a bit loud. I get all my voice lines from recordings of the games their from or archived streams. There is no use of AI at all within this mod that includes the code and voices.

Showcase

Voice Request

You can leave a suggestion for a voice to add in the comments. Requirements:

  • Name
  • What there from
  • A video link to voice lines, with little background noise (optional)

Voice List

  • Jerma985
  • Hunk (RE9 & RE:Operation Raccoon City)
  • Leon (RE4 remake)
  • Ada Wong (RE4 remake)
  • Stalker Bandit (Stalker)
  • Talon (COD MW2019 & Warzone)
  • More to come!

Installing

Just extract the folder and drop it in the main SPT directory. Make sure to extract using winrar or 7zip.

Uninstalling

Before uninstalling make sure you change your voice back to a default. Then you can safely delete the “JellyVoices” folder in your “SPT/user/mods”.

Modding Guide

I made a guide on how to make voice mods on my Github page in the wiki section.
