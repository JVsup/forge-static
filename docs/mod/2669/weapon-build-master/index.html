THE CITY Weapon Build Master

Share your weapon build with your friends using a simple build code!

What does it do?

  • Import and export any of your customized weapon builds with just a single string of code.

  • Seamlessly integrated Import/Export buttons within the native game UI, backed by a robust and comprehensive error-catching system.

Installation

  • Download the latest version from the Releases tab on the right. Extract the archive and simply drop the BepInEx folder directly into your game’s root directory.

Compatibility

  • Fika: Fully compatible. I haven’t encountered any issues during actual testing.

  • Fika.Co-op: Same as above.

  • Fika.Headless: Same as above… Well, considering this is a strictly client-side UI mod that doesn’t even operate during active raids, theoretically, no other mod should break it.

How to Use

  • Exporting: Once in the game, open the Edit Build Screen. You will see the new Import and Export buttons located right below the default Delete button. Click the Export button, and your current weapon build will be automatically converted into a build code and copied directly to your clipboard.

  • Importing: Select a base weapon on Screen, ensure you have a preset code copied to your clipboard, and click the Import button. Your saved build will be assembled instantly with just one click!

Note About the Build Code

  • The exported code is a Base64 string that looks quite long (similar to a Hearthstone deck code). It starts with SPT-ProjectSpark-WBM-, followed by a line of human-readable text (e.g., “Player shared a weapon build…”). ﻿
  • The descriptive text at the end is completely optional and just for context—you can delete it when sharing if you prefer, or change it to explain your code, or named it, just by your favorite. ﻿
  • So if somewhere delete the line break in code when you share it, you can still delete the description text to use the build code also, it’s actually unnecessary.
