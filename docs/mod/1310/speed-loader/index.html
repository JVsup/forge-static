Description Versions 4

No more hiding in the corners like a little bitch reloading your mags….

All credits to Nootropix i just fixed it up for latest version nothing changed.

Allows large capacity magazines to be loaded/ unloaded with ammo faster. Works with SPT 3.9.x

This mod increases the speed with which the larger magazines can be loaded and unloaded with ammo,

and the magazine check speed for them.

Use the config file to adjust the speeds and minimum size magazine you want to adjust as you see fit.

The MAXIMUM change to speed is 100, meaning 100%. This gives near instant reloading of mags.

HOWEVER!! Your MagDrills skill will be taken into account too, so you need to adjust for that.

For example, if your MagDrills skill gives 30% reduction in load times, you can only set this mod at up to -70,

if your MagDrills skill gives 20% reduction in load times, you can only set this mod at up to -80, etc.

IF YOU SET IT TO TOTAL MORE THAN 100, YOU WILL NOT BE ABLE TO LOAD OR UNLOAD MAGS AT ALL!

INSTALL: Just drop the file in the “user > mods” folder
