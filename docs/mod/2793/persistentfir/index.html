PersistentFiR

Prevents FiR status from being stripped just for entering a raid.

Description Versions 1

Persistent FiR preserves the Found in Raid status of FiR items in your inventory when you enter a raid with them.

I made this mod because I enjoy playing with the Vagabond mod. In that setup, even if I found a specific FiR item needed for a quest, extracting to the Hideout could effectively make that item unusable for the normal quest or trader progression flow. This was because I had to play at least one more raid before I could access traders again. I felt this created an unintended balance conflict with the existing game systems, so I made this mod to address that issue.

Vagabond is not required. If you have ever accidentally brought a FiR item into a raid and lost the ability to sell it on the flea market, this mod may be useful for you.

This mod prevents FiR status from being removed simply because an item was brought into a raid.

It does not change FiR loss caused by Run Through, death, or other normal raid failure conditions.
