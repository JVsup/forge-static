Make THE CITY look less depressing

Comparison: Before/After

This mod tweaks some values in THE CITY’s default post-processing to make the game look more natural and less washed out. It greatly improves visibility in dark areas.

It was inspired by Amands’s Graphics which is sadly no longer updated.
