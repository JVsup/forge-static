Exfil Flare Notification

A small QoL mod for folks that are paranoid if their exfil flare was used correctly

Terkoiz acidphantasm

Description Versions 3

Have you ever used the Green Signal flare to activate the Klimov Street extraction point on Streets or Mira Ave on Ground Zero, but wasn’t sure if you used it in the correct location or at the correct angle? This tiny plugin will display a notification toast if the exfil unlock event is triggered, letting you know to rest easy and head safely for extraction.
