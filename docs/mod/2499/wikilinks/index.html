Adds in-game links to the EFT Wiki

Description

Features

Adds links to the wiki for items and quests.

  • For items, it adds a context menu button (which also shows up in the inspect panel).
  • For quests, adds a button to the quest description which will show up both in the Trader Tasks view as well as the Player Tasks view.

The Wiki supports many languages, but many pages only exist in English. By default the links will go to the English version, but you can opt-in to localized versions if you want. Besides English, the most supported languages are French, German, and Russian. There is a good amount of Czech, and some Korean. Besides those languages, there is very little content and I recommend sticking to English.

Disclaimers

The EFT Wiki is for the live game. SPT is not, and may never be, on the same version as live. There can and will be differences. Remember that you can see older versions of the wiki pages - however this mod will only open the current version of a page.

This mod only generates and opens links, it does not and cannot know whether the page actually exists.

Installation

Like almost every mod here, extract the zip archive into your SPT directory.

Example (thanks DrakiaXYZ for the gif)

Uninstallation

To uninstall, simply delete Tyfon.WikiLinks.dll from <your SPT folder>/BepInEx/plugins

Troubleshooting

Q: The link went to page that doesn’t exist!?

A: There’s a couple reasons why this might happen

  • There is no wiki page for that item or quest
  • You’ve enabled localized language in the F12 menu, and there’s no wiki page for that item in that language
  • That item or quest doesn’t exist in live Tarkov, either because it’s been removed or it’s from a mod.

If it’s none of the above, and the link is just wrong, let me know with a comment or issue and maybe I can fix it.

Q: I found a bug!

A: Open an issue or make a comment here. Please include logs if possible!
