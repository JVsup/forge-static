Description

You can now reach really far to open doors and containers, as well as picking up loot!

Helps to scrub in those hard to reach areas!

Config Options:

- Loot/Container Interaction Distance: How far away you can open containers and pickup loot.

- Door Interaction Distance: How far away you can open doors from.

Installation Instructions

- unzip the file into your SPT Game folder.
