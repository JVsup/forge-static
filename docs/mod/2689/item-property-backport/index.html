Config
  • ExcludeProperties: Each property can be individually excluded. See Properties tab or the included properties.md file for a list of property names.
  • IncludeItems: Apply changes only to specified items. Ignores ExcludeItems.
  • ExcludeItems: Apply changes to all items except specified.
  • AllPrices: Update prices for all items
  • UnblacklistedPrices: Update prices only for items that are newly available on the flea market
  • UpdateGunsmith: Apply changes to Gunsmith tasks

Use the SPT Item Finder to find item IDs for lists.

Compatibility
  • Fully compatible with WTT Content Backport
  • Supercedes RuKira’s AttachmentBackport
Recommended Mods
  • Live Flea Prices can keep item prices up to date with live.
  • Skipper may be required to complete some Gunsmith or similar tasks.
Data Source

Data is sourced from THE CITY.dev. I’ll do my best to keep the data up to date with notable changes, keep an eye on the date above. Feel free to comment if I’m over a week late to an update.

1.4.0

16 July 2026
SPT ~4.0 Fika: compatible 1,117 downloads125.6 KB

Changed item file format, new data is no longer compatible with older mod versions.

Added RemoveAmmoboxFleaLimit config setting. SPT limits ammo boxes to 0-3 offers while all other items are 7-30. Setting this option will remove the override so they match other items.

Added support for food, meds, and armor properties: MedUseTime EffectsDamage EffectsHealth Buffs MaxHpResource (meds) MaxResource (food) ArmorClass ArmorColliders ArmorMaterial ArmorType Durability RepairCost RicochetParams

Fixed properties.md typo (WeaponErgonomicPenalty) and missing properties (DeafStrength, BlocksEarpiece).

Version

1.2.0

27 May 2026
SPT ~4.0.0 Fika: compatible 724 downloads55.6 KB

Add a config option to modify Gunsmith quests to latest values so Skipper is not necessary, enabled by default.

This also makes an attempt to change the values listed in the quest description by simple replacement, only tested English. Some text may be misleading or confusing depending on value changed like “must weigh no more than 0 kg,” just ignore that condition.

Requires the new config file or just the new config value:

"UpdateGunsmith": true

Note: Quest data included at time of upload was written by hand using the Fandom wiki for reference as THE CITY.dev quests have not been updated with the April 20th ergo/recoil rebalance.

Version

1.1.0

18 May 2026
SPT ~4.0.0 Fika: compatible 760 downloads50.9 KB

Refactored to support many new properties. See the mod description for a list of all currently known/supported properties.

The config file has been changed with renamed keys that work largely the same, though excluding specific properties is now a list instead of simple toggles.

A properties.md file is also now present in the mod folder for offline reference of properties if you wish to exclude them. This is the same list that is in the mod description and also includes short JSON examples for anyone not familiar.

As the new properties include magazine check time and load/unload modifiers, it now provides all properties from AttachmentBackport.
