Disable Traitor Scavs

Disables Traitor Scavs. You can also, alternatively, adjust the chance they do spawn instead of disabling them. Stop getting shot in the back!

INSTALLATION

Installation

  1. Download DisableTraitorScavs
  2. Open the downloaded 7z file in 7-zip
  3. Select the SPT folder in the 7z file in 7-zip
  4. Drag the SPT folder from 7-zip into your root SPT folder

Demonstration Video (yoink):

UNINSTALLATION
  1. Delete /ROOTSPT/SPT/user/mods/acidphantasm-disabletraitorscavs
  2. Done
CONFIG

Config settings (\config\config.jsonc)

  • disableTraitorScavs
    • Default: true
    • Change this to enable/disable traitor scavs
  • traitorScavChance
    • Default: 15
    • Percentage chance to spawn a traitor scav if above setting is false.
