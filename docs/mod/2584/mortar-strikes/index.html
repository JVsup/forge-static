Mortar Strikes

Fika compatible random event were Mortar Strikes can hit on all maps, bots and players alike. Highly configurable.

Description Versions 1

This mod allows you do configure Mortar Strikes that will shoot barrages of mortar strikes at Bots/Players with a warning sound and smoke in advance. Every parameter is configurable in the config.

Works with SPT 4.0.12 and Fika 2.2.0. For Fika every Player needs the Mod.

The config will appear here after the first time starting your game: SPT\BepInEx\plugins\MortarStrikes

If you delete the Config it will be newly generated when starting the game.
