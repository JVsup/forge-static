Introduction

Hey guys,

This mod aims to add a large variety of configurability to THE CITY weapons in the form of way more gun parts, guns, and options for modding your weapons with the addition of a themed trader that has quests. Not many for now, but I do plan to make more.

The trader Badger unlocks at level 12 following the quest “Stranded” on Mechanic

This mod will be getting separated into packs that will not use the trader so that people can slim down the amount of items they are importing into the game. This will have more time allocated to it now that I am no longer adding items actively, so I will only have to do bug-fixes and upkeep will not take 33 hours a week with a full time job like it has up to this point to get here.

Starting with Version 2.0.0 I no longer am bundling a realism patch. Please use one of the patches available elsewhere on the hub.

KNOWN ISSUES:

  • Need presets for some of the new weapons added by the mod
  • Need to fix the starting loadout M4 preset
  • Texture remastering on some items
  • Bipods, but they’re not broken anymore

Glowing items left to retexture:

  • SAG MK3 handguards
  • Let me know if there are more, please

How To Install and Compatibility

How to install:

  1. Download the latest release by clicking the button above.
  2. Open the downloaded zip file with your choice of archive manager (DO NOT USE THE BUILT IN WINDOWS ONE)
  3. Put the contents of the zip file into your SPT folder
  4. Enjoy!

Compatibility:

  • Most other content mods work with this, report any that don’t.

Incompatibility:

  • If you are not using a patch for this mod with realism you will have many issues. Either make your own patch or wait for someone to make one. I do not have one.

The standard way to troubleshoot this mod is as follows:

  1. If you have issues when you install this mod, try making a new profile (preferably a dev bear profile) and make sure your game works. I do this by standard with my mod prior to release anyways, so it should always work.
  2. Add your previously used mods and boot the game and run a raid after each installed mod. This is to see if anything is conflicting with my mod. Tell me what is conflicting and what your error message is so that I can verify whether it can be fixed or if it just needs to be added to incompatibilities.
  3. If you are using something that is already listed as an incompatibility I am not going to help you.
