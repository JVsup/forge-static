FSR4 Bridge - AMD FSR4 for SPT

Routes the game’s FSR3 upscaler to AMD FSR4 (or the latest FSR 3.1.x as a fallback) via a native D3D11 -> D3D12 bridge. This is built using the latest FSR SDK, so it supports FSR 4.1.1 which works with RDNA3.

If your card does not support FSR4 and you select it, it will auto fallback to 3.1.x.

NOTE: Keep in mind, this is a bridge, which means it needs to convert dx11 output to dx12 and back to dx11. It is extra processing power to do, on top of FSR4 itself being heavier in general. You may notice performance drop compared to FSR3.0 especially if you are using an RDNA3 card

How to Use

  1. In the game’s Graphics settings, select an FSR3 quality mode
  2. In the BepInEx config (F12 ConfigurationManager, or edit BepInEx/config/com.matsix.fsr4bridge.cfg), set Enable FSR4 = true.

BepInEx Config

  • Enable FSR4 - the master toggle.
  • Sharpness (0–1) - RCAS post-sharpen. FSR4 is smoother than FSR3 by design (bypassing the game’s own FSR3 sharpen pass too), so raise this (~0.6–0.9) if edges look soft.
  • Native AA - Toggle between native resolution AA and upscaled AA

SPT-VR Support

You will need to be on version 1.3.1+ of SPT-VR for this bridge to work (will be available soon). I had to add special support for the VR mod since it changes a lot of upscaler code.

Changelog:

  • Fixes a TDR caused when enabling/disabling settings in bepinex config

Regarding performance - this is not a complete direct FSR4 implementation because that’s not possible due to THE CITY being DX11 and FSR4 does not support DX11. So this is doing the same thing optiscaler does pretty much except built into THE CITY directly to work best with THE CITY. This converts DX11 output to DX12 and back to DX11 so it needs to do extra processing. RDNA3 cards, I imagine would have an even harder time with this.

Another thing to note - if you’re testing performance in hideout, that is not a good representation. After a lot of testing, enabling this mod costs about 0.5ms frametime on my 9070 xt (on flatscreen). So the higher your FPS is, the bigger of a drop you’ll see. Go into a raid, look towards the middle of the map and enable/disable and see if it affects FPS. Let me know if you’re still seeing big drops in those cases.
