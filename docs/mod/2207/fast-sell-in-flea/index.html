Fast Sell In Flea

Quickly add items on the flea market with automatic fitting of the current price

Description

Mod for those who are tired of every time to enter the price offer to sell an item.

Specially when there are many items….
How it works:
  • In the context menu of item, a price is added to the Add Offer button if you hold LeftShift (default keybind).
  • If you press the button with the keybind held down(price show), the offer is added instantly, without going to the add offer screen.
  • The price is automatically setup from the current prices of the flea market.
  • You can select a preset target price(Min, Arg, Max) on the market, as well as set an amount to subtract Value OR Percent from that base price(Configurable)
  • Supports multi-selection from UIFixes

If Shift is not held, the button works as a normal add-offer action.
