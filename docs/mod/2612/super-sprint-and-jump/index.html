Super Sprint and Jump

Adjust run speed and jump height with hotkey. Move faster or jump higher up to 20x

Description Versions 4

All functions in F12 menu

Won’t affect bots.

  • Multiply sprint speed x1.0~20.0
    Due to physical effect, actual speed is limited to not higher than 1.5~2.0x.
  • Sprint speed overlimit
    Break the physical limit but buggy:
    Speed >5x will get uphill obstacled sometimes, and downhill floated that can’t jump.
    Speed >10x could break physical collision, may run into ground and die (please stop sprint before hit on hill or wall).
  • Walk acceleration
    Also speed up normal walking.
  • Multiply jump height x1.0~20.0
    Sprinting jump distance depends on Sprint Speed coef, which is recommanded higher than jump coef*0.5.
    Speed overlimit won’t affect jump, you could set high sprint speed but disable overlimit.
  • No fall damage
    Fall damage is automatically divided by jump height coef, and you can further remove it by this.
  • Hotkeys and HUD
    You can set hotkey for +- speed or height conveniently.
    The current multiplier values are shown on bottom left (near stamina HUD)

Suggestion

If you just want to play normally but travel faster between position, only set sprint speed x2.0 is good.

Compatible

  • Conflict with JiangHu, or other mod changing sprint speed or jump height. I don’t know which one will cover another. Test on your own!
  • In Fika server, this only affect your client

How to install

Download the zip and copy(drag) the BepInEx folder in package, to your SPT main folder (where EscapeFromTarkov.exe locates)

To uninstall

Just remove the dll file in YourSPT/BepInEx/plugins/SuperSprintJump.dll
