Armor Reversion

Description Versions 1

First and foremost, the code for this mod came from the Sakura_Yuki’s “GearProtection” mod (i.e. they are the original author), so show’em some love!

With that out of the way, this mod changes the hitboxes/ colliders of armor plates so that they cover the following areas:
- Thorax (ribcage_upper)

- Stomach (ribcage_lower)

- Upper back (spine_upper)

- Lower back (spine_lower)

This mod is intended for people who want the hitbox changes introduced in the 3.9.0 update but don’t want to update to 3.9.0 (like me).
