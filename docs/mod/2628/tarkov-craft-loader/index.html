What is this?

A simple mod that lets you add custom hideout production recipes by placing JSON files in the recipes folder — no coding required.

Use the TarkovCraft website to generate your recipes easily!

Features
  • Automatically loads all .json files from the recipes folder
  • Supports multiple files — organize your recipes however you like
  • Logs loaded recipes and errors in the server console
  • Seamlessly integrates with the existing hideout crafting system
Usage

Place your recipe .json files inside user/mods/TarkovCraft-Loader/recipes/.

You can have as many .json files as you want — any name works!

Need help creating recipe JSON files? Use the TarkovCraft website.

Installation
  1. Download the latest release .zip
  2. Drag and drop the files directly into the root folder of your SPT installation
  3. The folders should merge automatically. If you get a prompt to overwrite files, say yes
Notes
  • Malformed JSON or invalid item IDs will be skipped and logged as errors in the server console
  • Adding many recipes to one hideout area may cause a brief freeze when first opening that station — this is a client-side limitation
