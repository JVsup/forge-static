Description Versions 2

Loot Highlighter transforms your looting experience in SPT-AKI by making valuable items, containers, and corpses instantly visible with customizable highlights and clear labels. Items are color-coded by rarity, with ultra-rare items popping in purple, rare items in yellow, and uncommon items in blue.

The intuitive debug menu (press F12) gives you complete control - adjust detection radius, refresh rate, toggle categories, and customize highlight colors to your preference. Enable distance indicators to see exactly how far away each item is.

The mod intelligently identifies container types, showing whether you’re looking at medical supplies, ammo boxes, weapon crates, or other specialized containers.

Designed with performance in mind, Loot Highlighter runs smoothly and integrates well with other mods by using the standard F12 debug key.

Never overlook valuable items again - spot that rare key card across the room or find that hidden stash without pixel hunting!

(warning its still in beta !)

Key Features (Bullet Points)

  • Visual highlights for loot items, containers, and corpses

  • Optional distance indicators
  • Container type identification
  • Fully customizable settings via F12 debug menu
  • Optimized for performance
  • Compatible with other mods

  1. Download the Loot Highlighter zip file
  2. Extract the contents to your SPT/BepInEx/plugins/ folder
  3. Start the game
  4. Use F1 to toggle highlighting and F12 to access setting
