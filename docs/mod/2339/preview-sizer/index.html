Preview Sizer

Primarily required if you are using StatTrack or Realism, especially so if you use both. This will allow you to customize the preview icons and window sizes by removing fields.

Description Versions 4

Fix your item preview windows so they show up on the screen properly. Customizable in F12.

INSTALLATION

Installation

  1. Download Preview Sizer
  2. Open the downloaded zip file in 7-zip
  3. Select the BepInEx folder in the zip file in 7-zip
  4. Drag the BepInEx folder from 7-zip into your SPT folder

Demonstration Video (yoink):

UNINSTALLATION
  1. Delete /ROOTSPT/Bepinex/plugins/acidphantasm-previewsizer
  2. Done
