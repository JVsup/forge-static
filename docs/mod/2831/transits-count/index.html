Transits Count

Because BSG does what BSG does and doesn't update everything. Make transits count.

Description Versions 1

Add Transit as a valid condition to quests who require survival from a location. Does not add it to quests that require a specific exfil name or zone.

Adds transit to the following vanilla quests:

  • Supply Plans
  • Health Care Privacy - Part 2
  • Health Care Privacy - Part 3
  • Signal - Part 1
  • The Survivalist Path - Zhivchik
  • Hustle
  • Tourists
  • Immunity
  • Against the Conscience - Part 1 PVE ZONE

It will also add it to any Mod Quest that has the same requirements as long as they are in the database prior to this mod loading.

INSTALLATION

Installation

  1. Download Transits Count
  2. Open the downloaded 7z file in 7-zip
  3. Select the SPT folder in the 7z file in 7-zip
  4. Drag the SPT folder from 7-zip into your root SPT folder

UNINSTALLATION

  2. Done
