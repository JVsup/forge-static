Map Editor Lite - Custom Map Editor Framework

Map Editor Lite is a server-side framework for SPTarkov that lets anyone create and share custom map content - loot spawns, loot zones, static objects, interactive objects, bot spawn points, extract zones, and light zones - using an in-raid editor and simple JSON packs, no programming required.

What It Does

  • In-raid editor: press F8 while in a raid to place markers, preview items, and build custom map packs.
  • Custom markers: loot spawns, loot zones, static objects, interactive objects (doors & containers), bot spawn points, extract zones, and light zones.
  • Pack system: export your map edits as shareable JSON packs.
  • Web tool: import and tune exported packs, adjust spawn chances, mark quest/forced items, and finalize them for release.
  • Server injection: the server mod reads pack JSON and injects the content into SPT raid loot tables, exfiltration points, bot zones, and lighting.
  • Forced spawns: quest and guaranteed spawns are registered through WTT-CommonLib.
  • Modder friendly: other mods can ship pack JSON files in their own MapLoot/ folders; the server mod loads them automatically.

MEL Prefab Hub

Anyone can make a prefab within the editor and submit them to the prefab hub for others to use.

Web Tool

The mod also includes a web tool, however it is mainly to be used for making micro adjustments to your existing packs, rather than for pack creation, that’s to be done with the client mod.

Installation

  1. Drag the SPT and BepInEx folders from the mod archive into your SPT installation directory.
  2. Make sure WTT-CommonLib (com.wtt.commonlib) is installed as a server mod.
  3. Start the server. Map Editor Lite loads automatically.

On first launch the client creates:

  • SPT/BepInEx/config/com.shaneeexd.mapeditorlite.cfg — BepInEx configuration (editor toggle, hotkeys, etc.)
  • SPT/user/mods/MapEditorLite/ — client read/write data folder
    • editor/ # in-raid editor saves
    • spawns/ # built-in spawn directory
    • imports/ # files imported into the tool
    • cache/ # cached item data
    • prefabs/ # saved prefabs
    • exports/ # packs exported from the in-raid editor
    • packs/ # final user packs for the server to load

Configuration

Edit SPT/BepInEx/config/com.shaneeexd.mapeditorlite.cfg:

[General]
EnableEditor = false
EnableDebugVisuals = false
  • EnableEditor — set to true while developing. Default is false, so the F8 editor is disabled until you opt in.
  • EnableDebugVisuals — show extra debug visuals in raid.

Creating a Map Pack

  1. Install the client plugin and server mod.
  2. Set EnableEditor = true in the BepInEx config.
  3. Enter a raid and press F8 to open the editor.
  4. Place markers for loot, zones, objects, bot spawns, extracts, or lights.
  5. Enter a pack name and click Export Pack in the editor.
  6. The exported pack is written to SPT/user/mods/MapEditorLite/exports/.
  7. Open the Map Editor Lite Tool, import the pack, tune anything you need.
  8. Move the final pack into SPT/user/mods/MapEditorLite/packs/.

Tip: Always test on a new developer profile (and clear temp cache) so you can verify spawns, loot, extracts, and lighting without affecting your main save.

Publishing a Pack

The final pack is a JSON file that can be distributed as a standalone add-on.

When publishing:

  1. State the dependency: Your add-on pack requires Map Editor Lite v1.0.0 for SPT 4.0.13.
  2. Do not include the Map Editor Lite DLL or other authors’ packs in your zip.
  3. Test by extracting and running the server before publishing.

Users install your pack by dragging the SPT folder (containing SPT\user\mods\MapEditorLite\packs) into their SPT install.

v1.1.0 Changelog

  • Pressing F8 now automatically enters freecam editor mode so the menu no longer opens over the game UI and the cursor unlock works consistently.
  • The mod EventSystem is now activated whenever the editor cursor is unlocked (including in freecam), so editor UI buttons and inputs can be clicked.
  • Freecam now spawns a dedicated MLE_FreeCam camera by cloning the player camera GameObject, so it inherits the full rendering/post-processing stack (Prism, PostProcess, HBAO, SSAA, grading, etc.).
  • A render controller attached to the custom freecam fixes render distance/culling: far clip and layer cull distances are set to 10000, occlusion culling is disabled, and LOD bias is raised while in freecam.
  • The player is no longer teleported every freecam frame; they are only teleported to the freecam location when exiting freecam.
  • New Output tab in the bottom panel shows a rolling log of user-visible messages (e.g., door ID dumps, export confirmations) with the full output path, so players don’t need the BepInEx console open.
  • Door ID dumps and pack exports now write their success/failure messages to the new Output tab.
  • The Output tab has Copy and Clear buttons; Copy puts all log lines on the system clipboard.
  • Copy/paste (Ctrl+C/V) and prefabs now support all marker types, including LightZone, ExtractZone, BotSpawnPoint, BotSpawnZone, and TriggerZone.
  • Custom light zones now support configurable shadow settings (None/Hard/Soft, shadow strength/bias/normal bias) to reduce light bleeding through walls.
  • The light inspector has a Force Shadows button that enables shadow casting/receiving on all renderers within the light’s range.
  • Translate/rotate/scale gizmos now scale with camera distance so they stay a usable size when the camera is far from the selected marker.
  • Added scene object removal to allow deleting existing GameObjects within a raid.
  • Scene object removal is non-destructive: the editor only disables the object as a preview, records its name/path/position/rotation/scale in removedObjects, and exports it with the pack. The actual destruction only happens when the pack is loaded in a raid via RuntimeInteractiveObjectSpawner, and packs are only loaded from the published ServerModPacksDirectory (not exports).
  • Added a new Removed tab that lists every vanilla object marked for removal, with Restore and Restore All buttons to re-enable them in the editor, plus Apply Preview and Refresh buttons.
  • Picked scene objects are shown in both the GameObjects right panel and the main Inspector tab.
  • All JSON serialization (map save, prefab save, pack export, door dumps) now uses CultureInfo.InvariantCulture so files are written correctly regardless of the user’s Windows locale.
  • Game view no longer appears shrunk on non-standard resolutions/aspect ratios (e.g., 2560x1600 16:10); the camera now fills the full screen behind the editor UI.
  • Freecam camera now uses the correct full-screen viewport instead of inheriting a smaller game viewport.
  • Reduced console noise: removed informational logs from keybind presses, cursor toggles, copy/paste/undo/redo, and preview spawning. Warnings and errors remain.
  • Cursor unlock button is now configurable in BepInEx config (UnlockCursorMouseButton, default 2 = middle). Set to 3 or 4 to use mouse button 4 or 5 instead.
