Description Versions 1

Allows you to start ITAR? early, and with no fence standing required. Get your box of goodies filled up before Collector way before you need it.

I personally think Collector should be something you build up to, but it should be a task you “start” long before you start. Thank you to the Get Collector Early dev for giving me the idea for this one.

This mod has just one config option, the level at which it is available to you.

Default value is 1, but after running the server for the first time with the mod, the config will generate for you and you’ll be able to edit it.
