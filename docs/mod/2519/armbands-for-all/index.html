Armbands For All

Nothing against people with no arms, but all bots have arms...why not armbands?

Mod Features

  • Allows all bots to have an armband slot

This mod does not change the behaviour of the slot, nor any armbands. Nor does it actually ADD any armbands to bots.

If you actually want bots to have armbands, might I suggest using APBS.

By default, it can put armbands on scavs, rogues, raiders, and boss guards.

INSTALLATION
  1. Download Armbands for All
  2. Open the downloaded zip file in 7-zip
  3. Select the BepInEx folders in the zip file in 7-zip
  4. Drag the BepInEx folders from 7-zip into your SPT folder

Demonstration Video (yoink):

UNINSTALLATION
  1. Delete /ROOTSPT/Bepinex/plugins/acidphantasm-armbandsforall
  2. Done
