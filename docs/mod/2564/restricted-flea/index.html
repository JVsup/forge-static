Restricted Flea

  • Restrict what’s available on flea based on category
  • Disable selling to the flea
  • Remove default blacklist

Whitelist works on parent categories as well as direct item IDs.

The default config only allows you to buy:

  • Barter Items
  • Keys
  • Weapons
  • Attachments
  • Food & Drink
  • Other
  • Info

Also disables selling to flea and removes the default flea blacklist.
