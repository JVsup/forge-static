Description Versions 1

Want to store ALL your ballistic plates, masks, mandibles, face-sheilds, and helmet add-ons in the ballistic storage box?  Now you can!  

This is a server side filtering change to allow the aforementioned items into the case.  It started with the SLAAP plate & Bastion armor plate, and ended with the ballistic face shields, Death Shadow & Atomic Defense masks.  Enjoy!
