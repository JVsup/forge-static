Basics

An update to JustNU’s Insurance+ for the latest version of SPT!

Changes the insurance system to allow you to keep your insured items equipped upon death.

Item’s dropped in raid will be handled normally through the vanilla game’s return system.

Make sure you insure container’s with insured items. If the container the item is in isn’t insured then it’ll be lost.

If you’d like to increase insurance prices you can do so with this mod TraderQoL

How To Install

Simply extract mattdokn-insuranceplus.zip into your game folder

How To Config
  • LoseInsuranceOnItemAfterDeath
    • Default: false
    • If this is enabled, after dying in raid. The insured items you kept equipped will lose their insured status.
  • LoseAmmoInMagazines
    • Default: false
    • If this is enabled, ammo that is chambered or loaded into an insured magazine/weapon will be removed.
Known Issues

If you see anything that stands out to you, please let me know in the comments or submit an issue on github.

  • Insured items inside an uninsured container will not be returned to you on death.
  • Bullets in magazines stay after death. (Round in chamber gets removed though lol)
  • You are able to insure items that are needed to be placed for quests and get them back after the raid, this won’t be fixed as it would require adding a client component to see if you planted an insured item. link
