SPT Item Creator Wiki

The accompanying Wiki systematically organizes data resources and offers complete API references and item creation guides, helping developers and players efficiently utilize the mod and rapidly expand SPT's item database.

Description Versions 7
English

This plugin serves as the centralized release of the Wiki system, documenting the evolution of its structure and content optimization. Key improvements include restructured organization of update logs, corrected descriptions of fields and constants, and expanded examples, usage guides, and item creation tutorials, along with ongoing refinement of documentation formats for IDs and enum values.

Each version update specifies the minimum required mod version, ensuring synchronization between documentation and mod functionality. The entire documentation framework is built on Python MkDocs, featuring a clear structure and support for bilingual constants, aiming to provide developers with accurate and practical technical references.
