Description Versions 1

Mr. Kerman joins the game! This mod adds Mr. Kerman as a trader and quest giver.

The following quests are currently implemented:

Main storyline: The Message, The Investigation, and Hunt for the “Unknown”.

Side storylines: The Return of the “Ghost”.

Side quests: Help – Psychotyk, Help – AttilaDuran, My Name Is Jordani Yovanovich, Working for “RUAF”, The First Guy in the Village, Large-Caliber Mayhem, The Bushes Have Eyes, Showdown at the Sawmill.

Loyalty levels:

Level 1 – suppressed pistols, pistol ammunition, chest rigs, backpacks, class 3 helmets, class 1–3 armor plates.

Level 2 – suppressed submachine guns, pistol ammunition (armor-piercing), chest rigs with built-in class 2 protection, backpacks, class 4 helmets, class 4 armor plates.

Level 3 – assault rifles with Magpul and Zenit furniture, rifle ammunition, chest rigs with built-in class 3 protection, backpacks, class 5 helmets, class 5 armor plates.

Level 4 – rifle ammunition (armor-piercing), Black Division gear, boss weapons and items (after completing quests), and much more.

Plans for the future:

Release of a version that does not require dependencies on items from WTT. New story quests.

How can you help with development?

Share your ideas in the comments. I welcome both bug reports and new quest suggestions. Also, let me know if you think something is too expensive or, on the contrary, too cheap.
