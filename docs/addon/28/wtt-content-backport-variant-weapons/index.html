WTT-Content Backport compatibility and variants addon for Definitive Weapon Variants

Requires

  • Definitive Weapon Variants version 4.1.0 or higher
  • WTT-Content Backport version 1.0.4 or higher

Features

This add-on includes configuration files for Backport weapons to being easily used in Definitive Weapon Variants mod, and is adding:

  • 29 new variants to existing types
  • 1 new variant type with 8 new variant weapons
    Baseline Variant type - Dragunov
    Weapon variant chambered in 9.3x64mm caliber with matching TKPD magazines
  • 3 new unique variants with unique presets
    MXLR >Endless Quick-scope<
    AK-308 >Meta HMG<
    NL545 GP >Larger Laser Rifle<
  • 1 variant to existing unique variant with their own preset
    AS VAL MOD.4 >Unbreakable P&C<

Install

Extract to the main folder of the game

Uninstall

Remove files from mod folder (SPT 4.0/SPT/user/mods/DefinitiveWeaponVariants):

  • db/01_Variants/20_BackportVariants.json
  • db/01_Variants/21_BackportUniqueVariants.json
  • db/02_Items/20_BackportItems.json
  • db/02_Items/21_BackportUniqueItems.json
