CAMOS—————————––

-ERDL Woodland -Kryptek Raid -Kryptek Transitional -Multicam Black -100+ Camos from CODMW19

-Modular camo layers for custom variations -Airmesh -Dirt, drops and dust -Disc (for overwriting glass on scopes being textured for exemple)
