APBS Realistic and Extended PMC Loadouts Preset

A preset mod that makes pmc's loadouts more live-like and reasonable.

mip01
Downloads
4,475
Description Versions 4

Been testing and modifying this for a while with my friend our aim was; making pmc’s loadouts more likely to live THE CITY and changed lots of stuff on the config, the weapon and gear pool is extended, less chance to pmc’s have pistol, loot generated on their backpacks and much more.

Installation

  1. Paste the mod into your spt folder and override the files. (https://imgur.com/a/9jxeSHW)
  2. Set the preset from the web config. (https://imgur.com/a/NS5sTCB)

DISCLAIMER

If you dont want to lose your config file please backup before you install the mod so if you dont like the mod you can use your old config again.
