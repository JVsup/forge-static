Description Versions 5

This adds Fika support for SamSWAT’s Helicopter Crash Sites.

NOTES

  • This addon must be installed on the host (headless and non-headless) and all clients!
  • This addon REQUIRES the original mod to be installed too!

Installation instructions:

  1. Download the addon
  2. Open the .7z file with 7-Zip
  3. Drag and drop the BepInEx folder into your game folder (Not the SPT folder inside your game folder!)

Please see the main page for more information about the mod itself!
