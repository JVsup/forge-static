CAG Scribbles!

Hand-drawn markings for the high speed PMC!

Description Versions 3

This addon contains content with strong language

A collection of 60+ markings, symbols and more that I’ve recreated by hand from viewing photos of real life operator weapons and other video games (CoD 4, BF6 etc).

I drew everything in the style of paint markers such as posca for a more fielded look. I’ll occasionally be updating this sticker pack as I see more cool markings and such overtime, I am also open to user suggestions.

If you want to add more wear and tear to your markings, try using a mask texture.

How to install

To install addon, drag and drop BepInEx folder into your SPT install directory.
