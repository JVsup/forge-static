Arena Sniper Ammo Port for AmmoGen

EFT: Arena (ammo) in SPT? No way man.

Description Versions 1

As the title describes, this is simply a port of the 7.62x54mmR Tungsten Carbide AP and the 7.62x51mm NATO Ball 11 Long Range from EFT: Arena for use in SPT. Both rounds are NOT limited to just snipers.

Both rounds have been added to Traders +Ammo Boxes
  • TC AP: Jaeger LL4 for 2675 Roubles
    • Buy Restriction is 120 rounds per trader reset.
    • Ammo box (20 pcs) Jaeger LL4 for 49130 Roubles, 7 Boxes per trader reset
  • Ball 11 LR: Mechanic LL4 for 2245 Roubles
    • Buy Restriction is 120 rounds per trader reset.
    • Ammo box (20 pcs) Mechanic LL4 for 43265 Roubles, 7 Boxes per trader reset

Both rounds are Flea Restricted

Loot Spawns

You can also find both the rounds and boxes of both rounds spawning in Airdrops, buried caches, weapon boxes, ammo boxes and some others, though they aren’t very common to come across. I have also seen bots use the ammo as well.

Installation
  1. Make sure you have AmmoGen installed
  2. Drag and Drop the SPT folder into your SPT install directory
