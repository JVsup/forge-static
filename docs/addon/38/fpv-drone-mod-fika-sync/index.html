Introduction

Fika sync for FPV Drone Mod. That’s about it. My first actual attempt at making Fika sync for any of my mods so it could be a bit jank here or there. This has to be installed by everyone playing. Should work fine with headless, let me know if it doesn’t!

Installation

First install FPV Drone Mod and then just drag and drop.

Known Issues

  • Explosions are sometimes not synced properly. Packets are arriving out of order?
  • Dropping a drone before other players have loaded in will not sync them properly
