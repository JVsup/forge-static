General

AMQWR version 2.20 or higher is a HARD requirement, this mod is just bunch of configs for AMQWR. If version is lower - things won’t work in proper way!

You have dozens of new guns for your SPT setup? New hundreds of quests? And still you have to use the very same vanilla guns for quest progression? Here we are, presenting precise configs to match your new shiny guns with quests!

Main goal of that mod is to precisely match weapons from mods with quests having “Eliminate with xxx” conditions without adding extra weapons that are not matching. And ONLY that type of condition. Any other quest conditions like “find”, “stash” and etc currently are not supported by AMQWR logic.

Currently 100% covered next quest mods:

  • Vanilla EFT quests
  • Lotus quests 1.7.2
  • Ref - SPT Friendly Quests 2.0.3
  • WTT-Armory 2.0.5
  • AES 0.7.9
  • Scorpion 1.0.0
  • Legs 2.1.2

Next weapons and weapon packs included:

  • Massivesoft weapons
  • C11 - True North
  • Epic’s All in One
  • Eco’s Attachment Emporium
  • Echoes of Tarkov - Requisitions
  • SOCOM armory
    • some overrides for vanilla weapons (like adding to another weapon group)

Weapon mods are not hard requirement: if you don’t have some of them - things will still work!

Installation
  1. Install AMQWR if you don’t have it
  2. Unpack addon archive with patches into SPT root directory, confirm overwrite.
Support

IF YOU DON’T HAVE ANY OF QUEST MODS FROM THE LIST - YOU WILL RECEIVE “Mod: (XXX) is missing”. IT’S TOTALLY FINE, YOU HAVE NOTHING TO DO WITH IT

Some quests are added into processing blacklist. It’s not a bug, it’s by quest design and/or AMQWR logic and/or available weapon mods.

Also wanna notice that >95% of quest have very precise patching, but some things are… opted in I guess, as, for example, AEK-973 really isn’t an AK platform gun (well, it is, but it’s deeply modified) so there are some weapon groups a bit wider than it should be, though I’ve did it with intention to cover as much weapons as possible without totally ruining “spirit” of quest.

For assistance about issues (like not counting gun XXX into progression of quest YYY) please do next:

  • first of all carefully read conditions, in some cases kills won’t count towards progression because of wrong weapon modules. Ultra reminder: modded silencers, scopes and tactical devices/flashlights are also added into conditions, but only in cases where it sounds like “do x kills with silenced weapon” or “use EOtech scopes”, if u see exact attachment names - use things that are in list.
  • In some quests you need to do kills with xxx or yyy guns and then stash it somewhere. You are able to do kills with extended (modded) guns suiting the condition, but still have to stash vanilla ones. Sad, but true.
  • If you are not sure about real quest conditions, you may enable Debug mode in mod config and after first server start there will be good site to check things xxx\SPT\user\mods\GuiltyMan-AddMissingQuestRequirements\AddMissingQuestRequirements-debug-report.html. Open it, watch things, UI is very convenient, thanks to GuiltyMan.
  • send me html debug file and carefully describe the problem if you can’t handle it by yourself

WARNING!!! Giving zero support for mods that are just duplicate existing weapons with minor changes (like caliber, upper and etc) as those mod owners often doing cursed naming/descriptions which leads to total mess. I’ve already spent dozens of hours for NEW guns and precise quest patching for them. You are free to use any weapon mod you wish, but I leave an option to ignore your request if you are using one of those cursed things.

HAPPY KILLING!

P.S. Feel free to order new quest mods to add as well as gun mods.
