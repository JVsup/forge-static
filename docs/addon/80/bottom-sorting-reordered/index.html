Bottom Sorting Reordered

A custom config for sorting to the bottom.

redlaser42
Downloads
66
Description Versions 1

Stash Management Helper is an awesome mod with a great feature that will place auto-sort items from the bottom up. This is a custom sorting strategy config that I find works best for sorting in that order.

Money, meds, food, ammo, and mags are all near the top for easier gear up, bulky items, containers, and junk go to the bottom.

This gives you a nice workspace at the top of the stash. I suggest pining small containers at the top for easy unloading.
