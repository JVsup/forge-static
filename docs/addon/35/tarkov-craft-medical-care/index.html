What is this?

An addon for TarkovCraft Loader that adds new hideout production recipes focused on medical supplies — craft essential meds directly from your Medstation instead of relying solely on traders or the flea market.

Installation
  1. Download the latest release .zip file
  2. Drag and drop the files directly into the TarkovCraft Loader folder, merging with the existing folders
  3. The folders should merge automatically. If prompted to overwrite files, click Yes
Requirements
  • SPT 4.x.x or higher
  • TarkovCraft Loader 1.x.x or higher
