Addon

PropertyAnalysis

A tool that provides a GUI interface for viewing all attributes and their values for a category of items, offers certain statistical functions, and facilitates balance adjustments when creating new items.

English

Requirements

Minimum: Users need to have Python environment setup and the ability to execute scripts (able to run scripts using PyCharm or VSCode, and install missing dependencies based on error messages).

Optimal: Users possess Python virtual environment management skills, understand which libraries need installation, and can independently or with AI assistance identify and install missing libraries.

Warning: To minimize file size, this package includes only Python source code, configuration files, a pre-loaded item dataset, and a bilingual README file.

The curls directory contains instructions for running the Flask server and its API endpoints (not applicable to the GUI interface). Run python main.py: Launches the GUI interface with adjustable language settings (language can also be modified in config.yaml).

1. Data Loading

  • Load data from the StatsCache folder generated by the SptItemCreator mod
  • Asynchronous file loading for improved data reading efficiency
  • Configurable cache folder path via configuration file

2. Data Analysis

  • Attribute Statistics: Collect all available attribute names for items
  • Value Analysis: Display specific value ranges for each attribute
  • Data Aggregation: Organize and categorize cached data

3. Data Management

  • Persistent data storage support (StatsManager.plk)
  • Provide local logs (PropertyAnalysis.log file)

4. Interface Features

  • Tkinter-based graphical user interface
  • Menu bar operations (File menu → Load Data from Folder)
  • Visual display of attribute data

5. Network Interface (Optional)

  • Flask server support
  • Local network API endpoints

Main Applications

  • Analyze item cache data generated by SptItemCreator
  • View complete lists of item attributes
  • Understand attribute value ranges
  • Assist in creating new item configurations
中文

要求说明

基础要求：用户需要具备Python环境安装与脚本执行能力（能够使用PyCharm或VSCode运行脚本，并根据报错信息安装缺失的依赖包）。

进阶要求：用户具备Python虚拟环境管理能力，理解所需安装的库，能够自主或借助AI辅助识别并安装报错缺失的库。

注意事项：为控制文件大小，本工具仅提供Python源代码、配置文件、预加载的物品数据集以及中英双语README说明文件。

curls目录包含Flask服务器的运行说明及API接口文档（不适用于GUI界面）。 运行python main.py：启动支持语言切换的图形界面（语言设置也可在config.yaml中修改）。

1. 数据加载功能

  • 支持从SptItemCreator模组的StatsCache缓存文件夹加载数据
  • 采用异步文件加载技术，提升数据读取效率
  • 可通过配置文件自定义缓存文件夹路径

2. 数据分析功能

  • 属性统计：全面收集物品的所有可用属性名称
  • 取值分析：清晰展示每个属性的具体取值范围
  • 数据汇总：对缓存数据进行系统整理与分类

3. 数据管理功能

  • 支持数据持久化存储（StatsManager.plk文件）
  • 提供本地日志（PropertyAnalysis.log文件）

4. 界面功能

  • 基于tkinter开发的图形用户界面
  • 菜单栏便捷操作（文件菜单 → 从文件夹加载数据）
  • 属性数据可视化呈现

5. 网络接口功能（可选）

  • 集成Flask服务器支持
  • 提供本地网络API接口服务

主要用途

  • 分析SptItemCreator生成的物品缓存数据
  • 查看物品属性的完整清单
  • 掌握各属性的取值范围
  • 辅助创建新的物品配置，便于平衡性调整
