Description Versions 1
English

Some item data files suitable for the SPTItemCreator mod.

Simply ensure all new item data files are located in the /game folder/SPT/user/mods/SptItemCreator/data directory, and that the file extensions conform to the types specified in the Wiki (e.g., .sic.jsonc). The system supports traversing files within subdirectories of this folder.

Installation Method

Extract to the game folder.

To avoid generating too many plugins from different types of item data files, all the items I create will generally be released under this single plugin.

安装方式

解压到游戏文件夹

为了避免不同类的物品数据文件创建的插件过多，一般情况下所有我做的物品都将在这一个插件下发布
