Description Versions 4

This addon is required for proper synchronization between clients in Fika. The server host now has the authority on keeping track of all devices and draining batteries.

Installation

Applicable to the server host, all clients, and headless if available.

  • Install Batteries Not Included
  • Extract the contents of the .zip archive into your SPT-Fika folders
